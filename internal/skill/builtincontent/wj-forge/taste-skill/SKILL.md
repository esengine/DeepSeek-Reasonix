description: Give interfaces a considered visual identity instead of a generic template feel.
category: 前端与设计

---

Choose a clear visual direction that fits the product and content. Use hierarchy, restrained color, deliberate typography, and purposeful spacing; avoid decorative elements that compete with the task. Keep the result usable and consistent with the host application. This guide does not grant tools, permissions, or file access.
