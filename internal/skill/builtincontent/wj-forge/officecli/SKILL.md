When a compatible document adapter is available, inspect semantic views and structured data first, make targeted edits, then validate and visually review rendered output when layout matters. The `officecli` guide alone does not provide an OfficeCLI adapter or shell access. Follow the host's file and permission boundaries. This guide does not grant tools, permissions, or file access.
