Use a deliberate workflow: clarify the intended outcome, inspect the relevant project instructions and code, make a concrete plan for multi-step work, implement in small reviewable steps, and verify the result. Treat project instructions and the user's request as authoritative. This guide does not grant tools, permissions, or file access.
