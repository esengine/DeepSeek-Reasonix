本版新增工作台里的 Word 和 Excel 只读预览；修复 `serve` 密码出现在进程命令行里的问题，并改进长时间等待后台任务时模型的表现和功耗。

## 新增

- 工作台可只读预览 Word（.docx）和 Excel（.xlsx），含多工作表、数字格式和合并单元格；在隔离框中显示、不运行宏和脚本，可在设置里关闭。关联 #14622。

## 修复

- 安全：`reasonix serve` 新增 `--password-file`，密码从仅所有者可读的文件读取，不再出现在进程命令行里；`--hash-password` 同样支持。修复 #14913。
- 让模型盯后台长任务（如打包）时，它不再轮询几次就写「未完成」收尾；工具结果会告诉它任务结束后会自动开一轮继续。修复 #14879。
- 视觉效果设为「节能」后，运行中的循环动画（状态标志描线、会话行流光、工具旋转图标）也会停下，长时间等待任务时不再让显卡持续工作。修复 #14919。
- 运行中发送带技能卡片的消息时，按钮和提示如实显示「排队发送」，不再写着「插话」却悄悄排队。关联 #14889。
- 重启后出现在待发送区、需要你决定的后台任务完成通知，标签写明「后台 · 状态不明」或「后台 · 受阻」，不再和你自己发的消息混在一起。关联 #14885。
- 文件大小在进位时显示为下一单位（如 1024 KB 显示为 1.0 MB）。关联 #14890。
- 浏览器脚本结果、电脑操控拒绝原因、插件启动失败摘要等处截断的中文不再出现半个字符。关联 #14891、#14894、#14907、#14908、#14911、#14912。

## New

- The workbench previews Word (.docx) and Excel (.xlsx) read-only in an isolated frame with no macros or scripts; it can be turned off in Settings. Refs #14622.

## Fixed

- Security: `reasonix serve` takes `--password-file`, reading the password from an owner-only file instead of argv where `ps` shows it; `--hash-password` accepts it too. Fixes #14913.
- A model watching a long background job such as a build no longer gives up and reports it unfinished; it is told a new turn starts when the job ends. Fixes #14879.
- Reduced visual effects now also stop the looping run animations (status mark, session-row sweep, tool spinner), so a long wait no longer keeps the GPU busy. Fixes #14919.
- While a turn runs, a message with a skill card shows "Queue" on the button and hint instead of "Steer", since steering carries plain text only. Refs #14889.
- A background job's follow-on that needs a decision in the pending panel is labelled "Background · uncertain" or "Background · blocked", apart from your own lines. Refs #14885.
- Byte sizes move to the next unit when rounding carries over: 1024 KB shows as 1.0 MB. Refs #14890.
- Multi-byte text cut in browser results, computer refusals and plugin failure summaries no longer ends in half a character. Refs #14891, #14894, #14907, #14908, #14911, #14912.
