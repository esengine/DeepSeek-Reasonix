三个新面板（用量、记忆编辑、单文件回滚）、工具并行调用带来的往返下降，以及 DeepSeek 价目表的修正。自 2.3.0 起 62 个提交。

## 破坏性变更

- **成本显示上调 2.25–4.5 倍**。DeepSeek v4-pro 输出价此前记为 6 元/百万 token，实际为谷时 13.5、峰时 27。峰谷时段（北京时间 9–12、14–18，以及 2026-08-23 起的全周末）现已计入。自填价格不受影响——仅确认为厂商官方的价目表套用峰谷。
- **移除会话分叉**：TUI 的 `/branch <轮次>`、回退面板的 Fork 项、`POST /fork`。`/branch [名字]`（从当前位置建分支）保留。
- **移除 CLI 命令** `catalogs reindex sessions` 与 `doctor sessions`。二者重建的索引无任何读取方；历史搜索与用量汇总两个索引保留。
- **厂商识别改为按 endpoint 主机判定**，不再按连接名称。名字带厂商字样的中转站不再套用该厂商价目表；未识别厂商的连接使用你自己的价格表。

## 新增

**用量面板**（设置 › 用量）
- 按天展示 token 与花费，数据来自 `~/.reasonix/stats` 已累积的记录。
- 成本按币种分列，不做汇率换算；图表每币种一张。
- 无价格记录的日期显示为「无」而非 0（金额字段是后期才开始持久化的）。
- 缓存命中率按输入侧 token 计算。

**记忆编辑**（设置 › 记忆）
- 可直接修改已保存事实的标题、描述、正文、生效方式、关键词。
- 每次保存产生新版本，不覆盖旧版本。
- 身份、版本号、时间戳由服务端从存储读取，不接受前端提交。
- 编辑在会话中途生效，通过下一轮注入，不改动已缓存的系统提示前缀。

**单文件回滚**（差异卡片标题栏）
- 将单个文件恢复到**该会话最早的版本**，不回退对话。会话对该文件的其它编辑一并撤销。
- 分两步：先校验文件是否仍是检查点记录的版本，仅在你手动改过时才要求在两个版本间选择。
- 不触发会话重载。

**上下文预算**
- 距压缩阈值 75% 与 92% 时各提醒模型一次。
- 新增 `context_budget` 工具，模型可主动查询剩余空间（占用前缀 147 token）。

## 性能

- **提示模型可并行调用工具**。执行器一直支持单轮并行 8 个独立调用，此前未告知模型。9 个任务 × 2 轮实测：

  | 指标 | 变化 |
  |---|---|
  | 回复数 | −14.6% |
  | 调用数 | −18.3% |
  | 墙钟 | −31.4% |
  | 提示词 token | −15.3% |
  | 成本 | −9.5% |

  该提示占用缓存前缀 66 token。升级后各会话首次请求会 cold-start 一次。
- **压缩时丢弃已被取代的状态块**。目标、语言、工作区等每轮重述的块，旧副本在每次折叠时清除；一次性事实（记忆写入、已完成任务、单轮策略）保留。
- **目标契约从每轮重述改为引用**。1255 字节降至 442，约每轮节省 235 token。

## 界面

- **内嵌 Inter 与思源黑体（可变字重）**。Windows 的 Segoe UI 与微软雅黑无 500/600 字重，导致三档字重塌成两档。子集化后总计 1.6MB。
- **等宽字体栈补充中文字面**，终端输出、diff、行内代码中的中文不再回退到平台默认衬线体。字符宽度比不变（1.662）。
- **浅色主题对比度达标**。11 个设置分区中 5 处低于 AA 4.5:1，已修正；`--accent` 与 `--ghost` 色值调整，14 处将底色用作文字色的位置改用对应墨色。深色主题原本合格。
- **补齐 79 处未翻译文本**：JSX 内联中文 31 处、动态 key 11 处、内核拒绝文案 37 条。
- 900px 窄窗下插件行与服务行不再塌陷，名称保留最小宽度并省略。
- 9 处截断文本补充 `title`，可读取完整内容。
- 从菜单选取后焦点归还触发按钮（此前仅 Esc 有此行为）。

## 修复

- **TUI 退出时的记录丢失**。文件锁被其它实例占用时，退出会丢失自上次自动保存以来的全部内容且无提示。现改用退出专用快照，先将内存记录写入恢复分支。
- **待办列表无法结束**。系统要求完成待办，而完成守卫拒绝对应操作，形成死循环，此前只能强制停止。现明确给出三个可用出口（`complete_step`、移除条目、`conclude_blocked`）。
- **侧边栏出现未创建的会话**。保存冲突产生的恢复副本不再列为会话（仍保留在磁盘并被索引）；GC 回收链条中间节点后不再拆成多行。
- **小米 MiMo 无法选择思考档位**（旧版本表现为 500）。该端点实测支持 none/low/medium/high，`max` 与 `xhigh` 返回 400，选择器已相应调整。
- **子代理计数错误**。嵌套步骤被计为子代理数量（显示「64 个子代理」），同时委派面板显示为零。批量派发现在分别报告批次大小与步骤数。
- **能力 id `task:subagent` 被目录否认**，导致隔离静默失效、无任何报错。
- 内核不可达时发送失败，消息内容退回输入框（含引用），错误提示不再显示 `/submit: 500`。
- 被拒绝的开关显示拒绝原因，此前仅弹回原位。
- 声明了验证命令的运行可将输出通过管道传递（如 `| tail`），主机读取被声明段的退出状态。
- 首屏 provider 配置显示各厂商控制台地址；探测失败细分为 9 种带编码的结果。
