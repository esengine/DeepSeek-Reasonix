本版让终端能把 diff 排成可读的差异视图，市场可以在明确信任后安装未固定版本的已批准包，更新优先走镜像并支持续传，并补上模型服务空闲超时。

## 新增

- 终端里的 diff 或 patch 代码块、以及整段输出就是 diff 的命令结果，会渲染成差异视图，也可用 `[cli].diff_formatter` 指定外部格式化命令 (#11201)
- 可以为每个模型服务单独设置流空闲超时 `idle_timeout_seconds`，超时后中止等待 (#11258)
- 市场里已批准但未固定版本的包，在你明确表示信任后可以安装 (#11317)
- 市场优先展示可安装的条目，并标出已安装的能力 (#11292)
- 新会话默认使用的沙盒与终端姿态取决于沙盒声明和文件夹信任 (#11298, #11256)
- 对话内查找改为 Ctrl+F 能真正触发 (#11236)
- 可以在「记住的规则」里撤销项目规则 (#11177)
- 可以在模型服务设置里给服务改显示名，不影响它的标识和已有会话 (023f20e97)
- 技能名称支持 Unicode，MCP 标识不受影响 (42e9c7ce2)

## 变更

- 更新下载优先走镜像，镜像不可用时才回退 GitHub (#11322)
- 完整安装包下载可以断点续传，增量更新文件放在另一个磁盘卷时也能正常使用 (#11325)
- 市场信任徽章的文案更清楚，翻页不再出现重复条目 (#11335, #11337)
- 终端里以 ! 开头的命令只在本地运行，不再触发一轮模型对话 (#11262)

## 修复

- 打开 1.x 写的会话不再丢掉它的上下文压缩摘要 (ac30722a7)
- 命令实时进度中的非 UTF-8 输出（如 Windows 中文代码页）不再乱码 (#11327)
- 不带终端直接运行 `reasonix` 时退出码为 0，与 1.x 一致 (#11278)
- 无头模式在模型正常结束时退出码为 0，结论写进结果里 (#11285)
- 无头模式恢复 1.x 的 stream-json 与 events-jsonl 行格式 (#11277)
- npm 包来源可以使用精确的语义化版本固定 (#11351)
- 模型服务拒绝连接时立即报错，不再空等 (c906f3cd4)
- 无头运行的错误输出保持干净，诊断信息放到 `run --debug` 后面 (a062240d9)
- 从 macOS 程序坞点击图标可以恢复已关闭的窗口 (#11221)
- 回复可以从它自己所在的轮次重新生成 (#11279)
- 过期的提问卡片会在恢复历史前清掉 (465d7e7dd)
- 空草稿不再显示发送箭头 (78a67947e)
- 项目菜单里过长的工作区路径会自动换行 (d1a27868e)
- 保存用户配置时只改写你改过的键，并保留项目服务商的来源 (3e5607272, 162ee3edb)
- Windows 命令行过长时会明确指出长度限制 (9f789f9ab)
- 终端每一行都按终端的宽度完整绘制 (34ef4b033)
- 医生检查不再误报缺少 use_capability (fb7e7c381)
