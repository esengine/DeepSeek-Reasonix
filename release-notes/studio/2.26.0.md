本版让 Studio 终端界面补齐 1.x 的连接引导、排队与引导命令、设置命令和 YOLO 模式，设置里新增社区与贡献者入口，并修复已保存的默认模型不在配置里时 Studio 启动失败、DeepSeek 请求偶发连接错误、子代理状态一直显示运行中等问题。

## 新增

- 终端界面：没有可用密钥时启动即打开「配置连接」面板，随时可用 `/setup`（别名 `/auth`）再打开；支持筛选连接、掩码输入密钥、Ctrl+T 测试、Enter 保存 (#11682, #11493)
- 终端界面新增 `/queue`、`/steer`、`/takeover`、`/status`、`/export` 和 `/copy`，名称与用法同 1.x (#11683, #11493)
- 终端界面新增 14 个设置命令，名称与用法同 1.x：`/cls`、`/rename`、`/todo`、`/forget`、`/reload`、`/effort`、`/verbose` 等 (#11685, #11493)
- 终端界面的设置命令还有 `/diff-fold`、`/sandbox`、`/output-style`、`/reasoning-language`、`/theme`、`/language`、`/currency` (#11685, #11493)
- 终端界面：YOLO 加入 Shift+Tab 的模式循环，Ctrl+Y 只需按一次即生效；底栏显示 `工作区@分支`；大段粘贴自动折叠 (#11687, #11493)
- 设置的「版本」页新增「社区与贡献者」：QQ 群（群号可复制、加群按钮、二维码）、Discord、GitHub 问题页，以及可展开的贡献者列表 (#11660)
- 「版本」页在版本下方新增「作者与维护者」一行；抖音号放在社区区块最下方，二维码默认折叠 (#11660)
- 已安装插件的详情里，提示模板显示可直接输入的完整调用名，例如 `/插件名:模板名` (#11688)
- 已安装插件的详情里，打包的子代理会列出数量和调用方式 (#11658)
- 新增插件作者示例包：只读子代理示例 `repo-map-kit` 和原生提示模板示例 `work-note-kit` (#11663, #11694)

## 变更

- 插件的目录式主题按所在目录命名，同一插件里的多个主题不再都显示成「theme」 (#11684)
- 插件的主题文件格式不受支持或内容有误时，已安装列表和 `plugin doctor` 会说明原因，被丢弃的主题项也会提示 (#11674)
- 插件的钩子事件名拼错或工具匹配规则无效时，已安装列表和 `plugin doctor` 会给出警告 (#11695)
- 插件安装时重名，提示里现在也会告诉你可以用替换方式更新 (#11670)
- `reasonix plugin --help` 里的移除用法补上必须的 `--yes` (#11648)
- 插件指南改为对应当前界面：设置 > 扩展 > 已安装、两步式添加与安装流程、更新与导出操作、重载运行时 (#11681)

## 修复

- 启动失败：已保存的默认模型不在当前配置的服务商里时，Studio 不再启动失败，而是改用已配置的模型并提示；配置文件不会被改写，命令行仍会给出明确的报错 (#11718)
- 已退役的 `deepseek-v4-flash` 作为默认模型时，会随模型列表一起迁移到 `deepseek-flash` (#11718)
- DeepSeek 请求在部分网络上因 HTTP/2 握手顺序而偶发 `PROTOCOL_ERROR`，现在可以正常发出 (#11686, #11679)
- 子代理面板里的行会一直显示运行中，直到子代理真正结束；已结束的不再停在「运行中」 (#11712, #11706)
- 排队的消息被「取回」后，原文会放回输入框 (#11713, #11707)
- 顶栏的「引导待处理」计数改为与队列面板同源，不再显示面板里已经没有的项 (#11714, #11708)
- 多个子代理并行时，各工作者的工具调用留在自己的卡片里，不再散到主列表 (#11691, #11338)
- 多题提问框退回后点「下一题」，不再跳过已答的题，两题时第一题也不再直接变成「确认」 (#11640)
- 触屏设备上回车键保持换行，发送用按钮 (#11637, #11616)
- 自己发布的插件包安装失败后，可以点「重试」重新预览，不再只能返回 (#11655)
- 技能的「用户不可调用」和「禁止模型调用」设置现在会反映在技能管理列表里 (#11649)
- 内置场景技能的头部信息改为合法格式，不再带着无效头部的提示 (#11646)
- 用链接方式安装插件后移除，不再残留旧链接，之后可以正常重新安装 (#11668)
- 插件含有 `themes/*/theme.json` 且同级有 README 等文件时，现在可以安装 (#11677)
- 经过别名目录（例如 macOS 的 `/var`）指定的本地链接来源，不再被误判为工作区之外 (#11664)
