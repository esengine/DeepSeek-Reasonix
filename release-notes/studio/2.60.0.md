本版让内置浏览器可以点选页面元素并把修改直接存回本地网页，会话之间的消息不再需要批准，工作台可并排显示文件树。

## 新增

- 内置浏览器新增「点选页面元素」：点一下页面上的元素，就能看到它的选择器、文字和颜色 (6c9c6851a)
- 从工作区本地文件打开的网页，可以直接改所选元素的文字、文字颜色、背景色和字号，并保存回文件；文件源码里对不上的元素会说明原因，不会写入 (6c9c6851a)
- 工作台在打开的文件旁边显示文件树 (2ff95dbc5)

## 变更

- 「让模型把任务交给其他会话」开关打开时（默认开启），你自己的其他会话发来的消息直接交给模型，不再出现批准卡；关闭开关则仍需批准 (4dc2b1938)
- 保存会话时不再为每条消息复制一份数据，长会话的保存更快、占用更少内存 (e19fc12a5)

## 升级须知

- 会话间消息默认不再需要批准：同机其他会话写进消息目录的内容，会在开关打开时直接进入模型；不想要请在设置的「会话间消息」里关闭派发开关 (4dc2b1938)

## New

- The built-in browser can pick an element on the page: click it to see its selector, text and colors (6c9c6851a)
- On a page opened from a workspace file, the picked element's text, text color, background and size can be changed and saved back to the file; an element the file's source cannot place is refused with the reason and nothing is written (6c9c6851a)
- The workbench shows the file tree beside the open file (2ff95dbc5)

## Changed

- While the switch that lets the model hand tasks to other sessions is on (the default), a message from your other sessions reaches the model without an approval card; with the switch off it still waits for approval (4dc2b1938)
- Saving a session no longer copies every message, so long sessions save faster and use less memory (e19fc12a5)

## Upgrade notes

- Messages between sessions no longer need approval by default: anything another session on this machine writes to the message directory goes straight to the model while the switch is on; turn the dispatch switch off under Messages between sessions in Settings to keep the card (4dc2b1938)
