本版改为全屏设置页、统一界面图标、默认开启跨项目任务派发，修复思考计时、下拉框与工具注册表卡死等问题，并移除安卓版。

## 变更

- 设置改为全屏界面，左侧固定导航、右侧单列卡片铺满可用宽度；各分类的设置直接展开，通过胶囊定位，保留正在编辑的内容，并区分页面、卡片和字段标题（#15050）。
- 侧栏底部保留带文字的「设置」和「发送反馈」入口；已开启的快捷入口集中在图标与名称并列的卡片中，支持悬停、点击和键盘操作，沿用显示开关与排序（#15050）。
- 会话间消息与跨项目任务派发默认开启；显式关闭的用户配置继续保留（#15066）。
- 界面中文改用随包的 Noto Studio 字体，不再落到系统字体：Windows 上不再由只有常规和粗两档的微软雅黑渲染，500 和 600 字重在中文上也能呈现层次（3844e7e55）。

## 修复

- 发送、停止和浏览器导航按钮统一使用标准图标，修正停止方块过小的问题；手机端使用明确的停止符号，并正确弱化不可发送状态，外部打开按钮更易辨认（#15050）。
- 导航栏选中态改为主题浅底色、清晰图标和轻边框，修复主题包下突兀的实心色块（#15050）。
- 修复更新说明的语言按钮显示 `settings.text` 的问题，正确显示「简体中文」和「English」（#15050）。
- 修复语言等下拉框的文字偏上问题，让文字与箭头垂直对齐（#15050）。
- 切换模型或重载扩展后，仍可派发任务、打开项目并接收配对会话的回信（#15066）。
- 优化模型选单的拥挤布局：模型名单独一行，协议和「读图」标签放在下一行，连接状态保持完整；长服务商地址不再撑出横向滚动条（#15040，关联 #15012）。
- 合并工作台新标签页中重复的「资源管理器」和「文件…」入口；打开资源管理器即可直接搜索文件（#15040）。
- 修复模型服务设置中容量数值、继承提示及计费方式被裁切的问题；价格输入框与币种选择框统一高度，按实际可用宽度和字号调整列数，铺满表单区域。订阅计费选项使用简短名称，并保留完整说明（#15054）。
- 修复任务完成后旧思考卡片仍显示「思考中」并持续计时的问题。工具开始调用时停止思考计时，同一段回复中的交错事件不再拆出遗留卡片；后台会话确认结束前会先处理缓冲文字，重新打开会话时保留已记录的耗时（#15057）。
- 将界面中的字符、emoji 和通用手绘图标统一为 Lucide 图标，覆盖导航、设置、模型菜单、工具卡片、附件、预览和窗口操作。搜索、读文件、列目录、等待、终止、编辑与删除使用对应的图标；自定义服务和打开程序的入口不再使用首字母占位，并统一图标尺寸与对齐（#15063）。
- 修复对话向下滚动、展开的「执行过程」标题吸在顶部时，背景是透明的，导致标题和下面滚上来的执行内容叠在一起、两行文字重叠显示的问题：吸顶的标题现在用对话区的底色盖住它下面的内容（#15044）。
- 修复设置里的下拉框（比如「按用途选择模型」里的「使用模型」）选中很长的名字时，文字自动换成好几行、溢出下拉框的问题：现在名字保持在一行里，放不下就截断，不再撑出框外（#15041）。
- 修复设置、模型服务、用途选模型等页面里所有下拉框中，已选的文字偏向框的上沿、没有在垂直方向居中的问题（Windows 和 macOS 上都出现过）：现在文字在框里上下居中（#15041）。
- 修复技能目录里的文档文件（比如 `skills/某技能/README.md`、`skills/某技能/子目录/README.md`）被误报成"没有描述，会加载但不会出现在技能索引里"的警告弹窗：这些嵌套的文件本来就不会被当成技能，现在只对真正保留下来的技能说这句话（#15045）。
- 修复工具注册表的读锁被重复获取、在另一处同时注册或移除工具时可能整体卡死的问题；此前启用 MCP 或延迟加载能力的会话偶尔会一直显示「任务正在运行」（发现于 d09a7c557c 的测试）。

## 移除

- 移除安卓版：发布页不再提供 `ReasonixMobile-<版本>.apk`，已安装的安卓应用不会再收到更新（dcee062）。

## Changed

- Settings fills the application window with fixed desktop navigation and full-width cards in one column. Category controls stay expanded, pill navigation preserves drafts, and page, card and field headings have distinct levels (#15050).
- The sidebar footer keeps labelled Settings and Send feedback rows. Enabled shortcuts appear in an icon-and-name card available by hover, click and keyboard, preserving saved visibility and order (#15050).
- Session messaging and cross-project task dispatch are enabled by default; explicit user opt-outs are preserved (#15066).
- Chinese text in the interface now uses the bundled Noto Studio face instead of the system font. On Windows it is no longer drawn in Microsoft YaHei UI, which has only regular and bold, so the 500 and 600 weights show on Chinese text too (3844e7e55).

## Fixed

- Send, stop and browser navigation controls use standard icons with balanced sizing. Stop keeps the same square on phones, disabled Send looks inactive, and opening a page externally has a clearer icon (#15050).
- Selected navigation items use a subtle theme tint, readable icons and a light border instead of a solid accent block in theme packs (#15050).
- Release-note language buttons display their language names instead of the untranslated `settings.text` key (#15050).
- Text in language and other drop-down controls aligns vertically with the arrow (#15050).
- Keep cross-project dispatch, project opening and paired replies available after model switches or extension reloads (#15066).
- Model names have their own line; protocol and image badges sit below without squeezing connection status. Long provider endpoints stay within the menu (#15040; refs #15012).
- The workbench's duplicate Explorer and Find a file entries are merged. Opening Explorer focuses the file search (#15040).
- Provider settings display complete capacity values, inheritance hints and billing choices. Price inputs and currency pickers share a consistent height, and their columns fill the form while adapting to its width and text size. Subscription billing uses a shorter option label with the full explanation underneath (#15054).
- Completed thoughts no longer keep counting as if they were still running. Thinking stops when a tool call begins, interleaved events keep one response together, and background panes drain buffered text before adopting an idle status. Reopened sessions retain the recorded duration (#15057).
- Replaced character, emoji and hand-drawn interface icons with Lucide across navigation, settings, model menus, tool cards, attachments, previews and window controls. Search, file reads, directory listings, waiting, stopping, editing and deletion now have distinct semantic icons. Custom services and program launchers use icons instead of initials, with consistent sizing and alignment (#15063).
- When an open "Work" heading stuck to the top while the conversation scrolled, its background was transparent, so the rows scrolling beneath it showed through and two lines of text overlapped. The stuck heading is now painted in the conversation's own colour (#15044).
- A long chosen name in a Settings drop-down, such as the model in "Choose a model for each purpose", wrapped over several lines and spilled out of the box. It now stays on one line and is cut off when it does not fit (#15041).
- The chosen text in every drop-down in Settings, model services and the per-purpose model table sat against the top edge of its box instead of the middle, on Windows and macOS alike; it is now centred vertically (#15041).
- Documentation files inside a skill folder, such as `skills/some-skill/README.md` or one a level deeper, no longer raise the warning that a skill "has no description: it will load but won't appear in the skills index". Such nested files are never loaded as skills; the warning now appears only for a skill that is kept (#15045).
- The tool registry no longer takes its read lock twice while building a turn's tool list. A concurrent tool registration or removal could deadlock it, leaving sessions with MCP or deferred capabilities stuck on "task running" (found by the test in d09a7c557c).

## Removed

- The Android app is discontinued: releases no longer carry `ReasonixMobile-<version>.apk`, and installed copies receive no further updates (dcee062).
