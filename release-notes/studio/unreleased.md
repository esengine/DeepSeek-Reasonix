## 变更

- 工作台浏览器标签菜单支持关闭右侧标签和键盘打开；关闭页面沿用控制器路径，批量关闭保留文件 (#12348, #12067)。
- Workbench browser-tab menus add close-to-the-right and keyboard access; page closing uses the controller and bulk closing preserves files (#12348, #12067).

- 图标栏可见时，侧栏底部不再重复显示「钱包与用量」「发送反馈」「账号／个人工作空间」和「设置」；隐藏图标栏、仅折叠时显示或窄窗口下仍保留侧栏入口 (#12478)。
- Visible icon navigation now owns Wallet and usage, Send feedback, Account/workspace and Settings; the sidebar footer retains these entries when navigation is hidden (#12478).
