本版让输入框可以直接切换工作区的本地分支，界面缩放改用统一范围并支持 Ctrl/Cmd +/-/0，电脑操作能判断每一步是否生效，并修复回退冲突、旧版会话导入、模型切换、GLM 思考参数和多处终端界面的问题。

## 新增

- 输入框的分支标签读取真实的 git 状态，并可直接把工作区切换到另一个本地分支；有进行中的回合、后台任务或未提交改动时会明确拒绝并说明原因 (#12092, #12171)
- 界面缩放只有一个声明范围 0.8 到 1.8（步长 0.05），滑块显示的值就是实际保存的值，并可用 Ctrl/Cmd 加 `+`、`-`、`0` 调整 (#12035)
- 电脑操作的每一步会标明效果是否可信，并带上占住输入的模态对话框；Windows 上输入文字会读回确认，被错误框挡住时不再假装成功 (#12541, #12542)
- 自动压缩因上次摘要失败而被暂缓时，界面和终端界面会显示一条中英文提示，不再静默 (#12083)
- 终端界面输入框为空时按回车，回到最新输出并继续跟随，与 1.x 一致；`Ctrl+Z` 把终端界面挂起到命令行，`fg` 后恢复 (#12510, #12511)
- 思考参数面板按协议声明的字段命名，Responses 协议的服务商不再显示成只支持 Chat (#12498)

## 变更

- 侧栏底部的用量、反馈、账号和设置，在图标栏可见时不再重复显示；图标栏隐藏、仅折叠时显示或窄窗口下仍保留 (#12482)
- 显式声明 `glm` 协议的服务，glm-5.2、glm-5.3、glm-5.3-flash 的请求现在带 `reasoning_effort`：5.2 选 high 真发 high，选 none 真关思考；5.3 的「关闭」发 `thinking=enabled` 加 low (#12552)
- 决策来源不再出现在输入框的模型切换器里，选它会得到明确错误，而不是不可预期的失败 (#12553)
- 已保存的决策来源点「测试连接」时，改走它自己的协议并给出分类错误，不再提示「加 /v1」 (#12546)
- 配置编辑锁目录改放在用户主目录下，遇到属于他人的目录时给出明确错误，不再报一个裸的权限错误 (#11374)
- 权限规则写成不对应任何已注册工具的裸命令（如 `ask = ["rm"]`）时会被报告并拒绝，不再静默失效 (#12536)
- 安装计划里来自软件包的文字（版本、名称、路径、警告等）现在限长并清除控制字符，`.mcp.json` 声明的服务数超限会被拒绝 (#12037, #12512)

## 修复

- 代码回退之后再次回退同一回合或更早的回合，不再误报文件冲突；回退确认里的文件数按整个回退范围统计 (#11572, #11692)
- 打开 1.x 会话时不再多出一份同名副本 (#12506)
- 导入 1.x 目录时，读不了的会话会逐条列出并附带原因，不再只给一个警告数量 (#12538)
- 模型切换被拒时区分是回合仍在运行还是只剩后台任务，并说明各自的处理办法 (#12505)
- 模型切换后，已接入的拦截器类扩展不再失效，也不再误报其服务已停止 (#12367)
- Windows 上通过注册表里的安装路径找到 Git Bash，回退到 PowerShell 时明确告知；外壳探测有时限且结果会保存，不再拖慢启动 (#12486, #12539)
- Git 低于 2.31 时，工作区不再被误判为「不是仓库」而丢失状态、提交和分支标签 (#12518)
- 压缩摘要因输出上限被截断时，自动用加倍的上限重试一次 (#12469)
- 计划模式拒绝调用时，说明被拒的命令、原因类别和可行的出路 (#12517)
- 本回合只改了 `.md`/`.rst` 文档时，不再被要求运行验证命令 (#12520)
- 交付卡片不再把主机自己的任务快照、工具缓存和 `.git` 当作改动，也不再给中文用户显示英文句子 (#12465)
- 后台任务完成、终止、失败的提示改为按界面语言显示 (#12476)
- 提问卡片的自由文字输入框始终可见，运行状态明确写为等待你的回答 (#12540)
- 图标栏的悬停提示不再被裁掉或被遮住 (#12468)
- 重写已发送消息的输入框与队列行的编辑框随文字长度调整高度，长段落不再只露出两行 (#12477)
- 记忆页保存时，较新的草稿不会被先前的保存完成而清掉，各条记忆的写入按钮分别保持禁用 (#12135)
- 切换设置里的连接后，软件包安装表单和更新锁不再沿用上一个连接的内容 (#12126)
- 技能安装和注册的结果只报告所选来源自己的文件，同名技能被遮蔽时给出警告，目录别名也会被跟随 (#12107, #12109, #12110)
- `memory` 工具的搜索和列表在丢弃结果时会注明丢了多少条，模型不再把截断当作完整 (#12104)
- 宿主日志不再被例行请求刷满，内核异常退出时留下可读的崩溃记录 (#12523)
