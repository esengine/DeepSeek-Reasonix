本版重做服务商编辑表单、让模型的 render_chart 在对话里直接画成图表，并新增已完成未查看标记与技能 paths 门控；同时修复多会话并发卡顿、压缩触发偏晚和一批设置面板草稿丢失问题。

## 新增

- 服务商表单：编辑页有未保存提示、还原按钮和「已保存」回执，测试结果显示在对应按钮旁，新增「测试已启用模型」按钮与汇总行，底部固定保存栏支持 Ctrl/Cmd+S (#12189, #12193, #12196, #12202)
- 服务商表单：有未保存修改时切换服务或新增会产生询问，整体连接检查失败时会给出分类后的原因 (#12185, #12191)
- 模型调用 `render_chart` 后，对话里直接画出柱状图、折线图或饼图；终端界面显示为对齐的数据表 (#12179, #12181)
- 技能支持 `paths:` 声明：只有会话碰过匹配的文件后，该技能才会出现在模型的技能列表里 (#12192, #12195, #12199)
- 会话完成但还没看过时，侧栏和标签页会显示标记，重启后仍在，打开该会话才清除 (#12231, #12233, #12234)
- 手机网页端可以只读查看代理正在使用的浏览器标签页 (#12209)

## 变更

- 压缩触发改为参考服务商上次报告的提示词大小，带截图等本地估算偏低的会话不再拖到超窗口才压缩 (#12222)
- 压缩之后，模型自己写的任务清单、已全部完成的清单、折叠期间改过的文件和已通过的检查会重新随请求带上 (#12216)
- 附件被拒绝时，附件条直接显示原因（类型不支持、过大、为空、无法读取、写盘失败） (#12239)
- MCP 提示词获取失败时，提示会写明是哪个提示词、为什么失败，模型下一轮也会知道这次调用失败了 (#12241)
- 市场在注册表连不上时，显示上一次成功的浏览结果并标明是缓存 (#12210)
- 命令行：Ctrl+L 清屏，与 `/cls` 相同；补全菜单和 `/resume` 选择器支持 Ctrl+P/Ctrl+N 上下移动 (#12223, #12217)
- 添加服务商的探测被拒绝时保留错误代码，不再把对端回显的内容（可能含密钥）带进提示 (#12212)

## 修复

- 在后台启动的命令不再被画成红色失败；之后读取到后台任务失败或超时时，该调用会正确标为失败 (#12198, #12213)
- 同时开着多个会话时，被其他窗格遮住的窗格不再按流式输出速度重绘，界面明显更流畅 (#12237)
- 打开反馈对话框时背景不再做模糊，运行中的回合不再让 GPU 持续满载 (#12220)
- 连接远程机器时会接入已经在运行的服务，不再另起一个争抢会话租约，也不再删掉它发布的端口文件 (#12229)
- 保存服务商后编辑器在列表重新读取之后才重建，不再显示旧值 (#12177)
- 服务商编辑和添加在保存期间锁定草稿，保存期间的修改不会再静默丢失；改地址后会丢弃旧地址的探测结果，模型检查沿用表单里的代理绕过设置 (#12167, #12170, #12174, #12175)
- 备份面板在创建、恢复和删除进行中锁定输入，不会重复提交删除；取消全部类别后重新加载仍保持为空 (#12178, #12180, #12183, #12184)
- 记忆面板保存、恢复或遗忘后，历史版本列表随即更新 (#12133)
- 移除插件包后，设置里显示最新的重载结果；包详情的钩子行不再重复或残留 (#12155, #12163)
- 登录或退出后，市场详情页的投票面板会随账号刷新 (#12169)
- 首次打开带令牌片段的链接时，页面资源在认证完成后重新加载，不再因 401 而空白 (#12190)
- 选择无效模型失败后，已在运行的扩展进程和流式回调保持可用 (#12205)
- 历史恢复期间，已显示的扩展卡片不再消失 (#12206)
- 扩展在回合之外提问并回答后，状态标签恢复为空闲，不再停在「运行中」或「等待确认」 (#12194)
- 在没有剪贴板接口的环境复制后，焦点仍留在原按钮上，键盘用户可以继续 Tab (#12071)
- 发布表单的版本提示改为如实说明：只有三段数字版本才会自动递增 (#12162)
- 辅助功能：优化提示词按钮由其提示框描述，常驻扩展面板的进度条有了名称 (#12186, #12187)
