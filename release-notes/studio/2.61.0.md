## 新增

- 工作台的文件树可以拖动边缘调整宽度，宽度会被记住，双击边缘恢复默认 (376376843)
- 新增「进程」按钮，点开列出本会话正在运行的后台任务和子智能体 (3807e411d)
- 新增设置「允许模型直接打开工作区内的文件夹」，默认关闭；打开后模型把本工作区内的文件夹加入项目时不再弹批准卡 #15090

## 修复

- 公式不再被裁掉上标的顶部 #15092
- 没有伪控制台的 Windows 上，终端会说明原因，而不是报"shell 启动失败" #15091
- 在 Cygwin 或 MSYS 终端里运行时，会提示界面无法在这里运行以及该怎么办 #15091
- Windows 上安装前端依赖（pnpm install）不再失败 #15067
- 操作被拒绝时的原因不再被输入框盖住 (f4b815ecd)
- 读取内核失败时，窗口会说明内核无法连接以及是哪一次读取，而不是只显示"Failed to fetch" #15070
- 窄栏里「更改」标题行的按钮换行显示，不再挤成竖排并出现横向滚动条 (a717dcd34)
- 提交历史会在新提交出现、分支变化时自动刷新 (803583e4a)
- 选了资源管理器后，右边不再留着已经打开的启动菜单 (0a17f7774)
- 归档长会话时不再逐个规范化其他会话的路径，归档明显更快 (5cd38fde8)
- Homebrew 安装不再因为 cask 无法读取而失败 #15071

## 移除

- 移除软件内的反馈与建议入口、崩溃报告上传和匿名统计；项目不再维护 (21ffa334b)

## 升级须知

- 本版之后项目不再维护。软件不会再向维护者发送任何报告或统计，`reasonix report send` 会被拒绝；更新检查和扩展市场仍会访问原有服务，服务停止后将不可用 (21ffa334b)

This is the last release: it removes the in-app feedback, crash report upload and anonymous statistics, and fixes a batch of issues in the file tree, commit history and more.

## New

- The workbench file tree can be resized by dragging its edge; the width is remembered and a double click restores the default (376376843)
- A new Processes button opens a list of this session's running background jobs and sub-agents (3807e411d)
- A new setting, "Let the model open folders inside the workspace directly", is off by default; when on, the model adds folders inside this workspace to the project without an approval card #15090

## Fixed

- A display formula no longer loses the top of a raised exponent #15092
- On a Windows without a pseudoconsole, the terminal says so instead of reporting that the shell failed to start #15091
- Run from a Cygwin or MSYS terminal, it says the UI cannot run there and what to do instead #15091
- Installing the frontend dependencies (pnpm install) on Windows no longer fails #15067
- The reason an action was refused is no longer painted over by the composer (f4b815ecd)
- When the kernel cannot be reached, the window says so and names the read, instead of showing only "Failed to fetch" #15070
- In a narrow explorer the Changes header wraps its buttons instead of squeezing into a vertical stack with a horizontal scrollbar (a717dcd34)
- The commit history refreshes when a commit appears or the branch changes (803583e4a)
- Choosing the explorer no longer leaves the start menu beside the tree it just opened (0a17f7774)
- Archiving a long session no longer canonicalizes every other session's path, so it is noticeably faster (5cd38fde8)
- Homebrew installs no longer fail because the cask cannot be read #15071

## Removed

- The in-app feedback and suggestion entry, crash report upload and anonymous statistics are removed; the project is no longer maintained (21ffa334b)

## Upgrade notes

- The project is no longer maintained after this release. The app sends no report or statistic to the maintainers, and `reasonix report send` is refused; update checks and the extension market still use the existing services and will stop working once those are shut down (21ffa334b)
