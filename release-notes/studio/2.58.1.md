本版是修复版：修好 2.58.0 里设置页版面错位、会话行置顶按钮常驻、模型菜单标签折行、思考「展开」被限高等问题，修复 Windows 启动闪控制台窗口、命令行 `mcp --help` 误执行和 Linux 终端选择。

## 变更

- 桌面壳的 Electron 升到 45.2.3（Chromium 156，含上游的安全与稳定性修复）。关联 #15027。

## 修复

- 修复 Linux 上「在终端中打开」不管你把哪个终端设成默认，总是按固定顺序挑一个（比如装了 konsole 就先用它，而不是你的 kitty）。现在如果装了 `xdg-terminal-exec`（桌面规范里读取默认终端的启动器），就由它按你机器声明的默认终端打开；没装的话仍按原来的顺序（#15031）。
- 修复命令行里 `reasonix mcp import --help`（以及 `mcp remove --help` 等其他子命令）不会显示用法，反而把 `--help` 当成参数真的去执行：`import` 会直接改写 MCP 配置。现在所有 `reasonix mcp` 子命令的 `--help` / `-h` 都只打印用法并退出，什么都不改；`mcp import` 带多余参数时会报错而不是照常导入（#15022）。
- 修复 2.58.0 里，开着「会话行快捷按钮」时，侧栏每一行会话都一直显示一个置顶图标（不管有没有置顶）：现在这个按钮只在鼠标移上去或键盘聚焦时才出现；已置顶的会话在没悬停时会一直显示一个小图钉，方便一眼看出（#15012）。
- 修复输入框右下角的模型选单里，模型名字较长时，右边的「读图」标签被挤成两行竖着排的问题；现在标签始终在一行里完整显示（#15012）。
- 修复 2.58.0 里设置的「模型」「连接」等单栏页面：顶部「本页包含」目录和下面的标题、卡片没有对齐，卡片左边多出一大块空白（现在三者对齐到同一条左边线）（#15008）。
- 修复从「操作与性能」点开「导航入口」这类二级页时，顶部多出几条空白的横条；现在二级页里只显示它自己（#15009）。
- 修复设置里「思考过程」选成「展开」后，模型思考时仍然只显示最新六行、要等整段思考结束才一下子全部显示的问题：选「展开」时，运行中的思考块现在随内容一直完整展开；「进行中展开」仍是最新六行的滚动窗口（#15013）。
- 修复 Windows 上每次启动 Reasonix Studio 都会先闪一下黑色控制台窗口的问题：启动时用来确认"是不是同一个 Studio"的内核探测，以及启动内核本身，现在都隐藏控制台窗口（#15016）。

## Changed

- The desktop shell moves to Electron 45.2.3 (Chromium 156, with upstream security and stability fixes). Refs #15027.

## Fixed

- On Linux, "Open in terminal" picked a terminal by a fixed order rather than the one the machine declares as its default (konsole before kitty, for example). When `xdg-terminal-exec` is installed, it now starts the machine's default terminal; without it the old order still applies (#15031).
- `reasonix mcp import --help` (and `--help` on the other `mcp` subcommands) did not print usage and ran the command with `--help` as an argument, so `import` rewrote the MCP configuration. Every `reasonix mcp` subcommand now prints usage for `--help` / `-h` and changes nothing, and `mcp import` refuses extra arguments instead of importing (#15022).
- With "Quick buttons on session rows" turned on, every session row in the sidebar showed a pin icon all the time, pinned or not (2.58.0). The button now appears only when the pointer is over the row or it has keyboard focus, and a pinned session keeps a small pin on the row while nothing is hovered (#15012).
- In the model menu next to the message box, the "reads images" tag was squeezed into two stacked characters beside a long model name; it now stays whole on one line (#15012).
- In Settings, single-column pages such as Model and Connection no longer draw the "On this page" index out of line with the title and cards, which left a wide empty strip beside the cards in 2.58.0; all three now share one left edge (#15008).
- Opening a sub-page such as Navigation entries from Operation and performance no longer leaves a few empty bars above it; the sub-page shows only itself (#15009).
- With Thinking set to "Open", a thought still showed only its latest six lines while the model was thinking and then jumped to the full text when it finished. In "Open" the running thought now grows with its text; "Open while running" keeps the six-line rolling window (#15013).
- On Windows, launching Reasonix Studio no longer flashes a console window first: the kernel probe that tells whether this is the same Studio, and the kernel launch itself, now run with their console hidden (#15016).
