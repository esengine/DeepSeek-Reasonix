本版新增视频壁纸、查找框的大小写与正则开关、快捷键一览和长对话分页加载，正文栏可拖得更窄，并修复多处保存、粘贴与显示问题。

## 新增

- 壁纸可以选 MP4 或 WebM 视频，作为静音循环的动态壁纸；窗口隐藏或失焦、系统减弱动效或精简效果下停在第一帧。关联 #14357。
- 对话里的查找框多了两个开关：区分大小写，以及把查询当作正则表达式。关联 #14198。
- 设置的外观页增加「快捷键」一栏，列出窗口里所有可用按键，可以搜「快捷键」「Ctrl」「Esc」等词找到。关联 #14198。
- agent 浏览器的网页可在「设置 → 外观」开启空闲休眠：15 分钟无人使用后整页收起省内存，再用时恢复为同一标签页。默认关闭。关联 #14332。
- 版本列表里的下载和后台自动下载现在都可以取消；取消会停止传输，并删除这次下载留下的部分文件。关联 #14338。
- 新增可选的历史接口，按页读取正文并保留稳定的消息位置和跨页工具上下文；现有客户端继续全量读取。关联 #14048、#14087。

## 变更

- 壁纸不再有 12 MB 上限，原样使用你选的图片；上传改为边收边写入磁盘，读取支持分段，大文件不再占满内存。关联 #13980。
- 正文字宽现在可以连续拖到 640px，不再停在「适宜阅读」的 760px；按 Home 或不拖动时仍是 760px。关联 #14384。
- 阅读栏左右两侧的拖动把手平时不再显示，鼠标移到栏边缘才出现，拖动和键盘调整不变。关联 #14352。
- 移除工作台的「加宽」按钮、独立加宽模式及 Ctrl/Cmd+Shift+B；可拖动分隔条或聚焦后用方向键调宽。关联 #14324。
- 轮次多的对话里，右侧提问细条会把相邻几条折成一组，悬停显示涵盖的范围；右键某条可加书签。关联 #14198。
- 「运行分析」入口变成图标加文字，分析页标题左侧多了返回箭头；点已在屏上的会话会回到正文。关联 #14198。
- 导出会话多了 Markdown 格式：只保留提问与回答，按发生顺序；JSON 仍保留全部字段。关联 #14198。
- 开启「派发」后，把任务派到侧边栏里你自己的项目时，不再因该项目尚未决定信任而停在信任卡上。关联 #13341。
- 没有选过项目也没有记住的项目时，首次启动不再打开用户主目录，而是打开应用自己管理的一个小目录，它不会被记成项目。关联 #14363。
- 输入 `/` 后可继续输入描述中的关键词查找技能和命令；名称匹配仍优先于描述匹配。关联 #14323。
- 工具参数缺必填项、待办列表规则不符、diff 证据被拒时，报错会直接给出合法示例或改用 files 证据的出路。关联 #14311。
- 支持分页的服务端优先显示最近消息；读取旧页保留阅读位置和控件，搜索会提示历史覆盖不完整。关联 #14048、#14087。

## 修复

- 切回「发送反馈」标签或点击反馈窗口标题后，Ctrl+V 也能添加截图；打开窗口后立刻粘贴也不再被偶尔忽略。关联 #14205、#14333。
- 新对话第一次保存前在右侧提问细条上加的书签，保存后不再消失，重启后也不会出现在另一段新对话里。关联 #14296。
- 接口报告「缓存命中 0」时按完全未命中计算，缓存命中率不再虚高；异常的超额命中被截断，99.5% 以上不再写成 100%。关联 #14313。
- 后台任务启动时的提示按界面语言显示为「后台任务已开始：…」，不再是唯一的英文。关联 #14308。
- 正文字宽的两个手柄在第一次拖过之后不再失效；拖动时两侧栏按各自比例让位，输入框跟随正文变宽。关联 #14320。
- 展开待办计划时，右侧消息细条和「跳到最新 / 回到顶部」按钮不再被顶起；计划面板浮在输入框上方。关联 #14321。
- 上下文压缩完成后的诊断行按界面语言写成一句话，不再是英文 key=value。关联 #14307。
- 工作台右键菜单合并编辑操作与「加入对话」；阅读和只读视图不显示修改操作，未选中文字时不显示引用。关联 #14326。
- 还没确认的提问卡片滚出视野再回来后，已勾选的选项、自填文字、补充说明和所在题目会保留。关联 #14336。
- 用智能体预设建的会话，升级后因内置工具变化不再变成只能查看；按当时记录的工具继续，并提示一次。关联 #14360。
- 执行过程那一行的「N 项运行中 / 失败 / 操作」和标题现在字号、字重一致。关联 #14364。
- 自动命名时标题模型把输出额度都花在思考上，程序会放宽额度重试一次，而不是直接失败。关联 #14374。
- 设置「存储」里「导入原生会话」的卡片不再露出浏览器自带的文件选择框，改用应用风格按钮。关联 #14378。
- 子代理以及计划者、Guardian 的文件读取各用独立记录，不再刷新执行代理的过期文件保护而覆盖你的修改。关联 #14025、#14133。
- Guardian 自身的 `use_capability` 调用对真实目标做只读检查，拒绝写入和已声明的宿主变更。关联 #14025、#14133。
- 重启后 Git 暂时不可用时保留隔离结果的文件和 ID；恢复前核对托管目录与仓库身份，错配的记录保留且不会被清理或应用。关联 #14025、#14133。
- 乐观模式下的任务写入会检查兄弟任务占用，包含动态本地工具；不相交的写入仍可并行。关联 #14025、#14133。

## 升级须知

- 派发到侧边栏里没决定过信任的项目时，该项目会被记为已信任并直接发出任务；家目录等不可整体信任的文件夹仍会询问。关联 #13341。
- 乐观模式下，同一文件被兄弟任务占用时，后到的写入会以 write.path_busy 被拒绝，而不再静默覆盖。关联 #14025。

This release adds video wallpapers, case and regex switches in find, a shortcut sheet and paged loading of long conversations, lets the reading column go narrower, and fixes several saving, pasting and display problems.

## New

- A wallpaper can be an MP4 or WebM video, played muted and looping; it stays on its first frame while the window is hidden or unfocused, under reduced motion or reduced effects. Refs #14357.
- The find bar gained two switches: match case, and read the query as a regular expression. Refs #14198.
- The appearance settings gained a keyboard shortcut sheet listing every chord the window answers to, reachable by searching "shortcut", "Ctrl" or "Esc". Refs #14198.
- Agent browser pages can sleep when idle (Settings → Appearance): a page nobody drives for 15 minutes is folded away and wakes as the same tab. Off by default. Refs #14332.
- A version download, started from the version list or by automatic download, can now be cancelled; cancelling stops the transfer and removes the partial files. Refs #14338.
- An optional history API reads the transcript in bounded pages with stable positions and cross-page tool context; existing clients keep full reads. Refs #14048, #14087.

## Changed

- Wallpapers have no 12 MB limit and are used as chosen; the upload is written to disk as it arrives and served in ranges, so a large one no longer fills memory. Refs #13980.
- The reading column can be dragged continuously down to 640px instead of stopping at 760px; Home and an untouched window still give 760px. Refs #14384.
- The reading column's resize grips no longer draw at rest; they appear under the pointer or on keyboard focus, and dragging and keys are unchanged. Refs #14352.
- Removed Widen mode, its button and Ctrl/Cmd+Shift+B; use the divider or the arrow keys on it to resize. Refs #14324.
- A long conversation folds neighbouring questions in the rail into one line and names the range on hover; right click stars one. Refs #14198.
- The run analysis entry reads as words beside its icon, the page has a back arrow, and picking a conversation already on screen returns to reading. Refs #14198.
- A conversation can be exported as Markdown, keeping only the questions and answers in order; JSON still carries every field. Refs #14198.
- With dispatch on, a task sent to a project in your sidebar no longer stops on its trust card because you hadn't decided about it yet. Refs #13341.
- With no chosen or remembered project, a first launch opens a small folder the app owns instead of your home directory; it is never remembered as a project. Refs #14363.
- Type description keywords after `/` to find skills and commands; name matches still rank first. Refs #14323.
- A tool call missing a required field, a todo list breaking a rule, and a diff citation for command-made changes now show a valid example or the files-evidence way out. Refs #14311.
- Paging servers show the latest messages first; older pages keep your reading position and controls, and search says when history is incomplete. Refs #14048, #14087.

## Fixed

- Pasting a screenshot works after returning to the Send feedback tab or clicking the dialog heading, and a paste right after opening is no longer sometimes ignored. Refs #14205, #14333.
- A question starred in the rail before a new conversation is first saved stays starred, and no longer reappears in another unsaved conversation after a restart. Refs #14296.
- A request reported with zero cache hits counts as a full miss, so the hit rate no longer drifts up; over-reported hits are clamped and 99.5% no longer shows as 100%. Refs #14313.
- The notice shown when a background job starts is worded in the interface language instead of staying the one English line. Refs #14308.
- The reading column's grips no longer stop after the first drag; sidebars give way while dragging and the composer follows the width. Refs #14320.
- Opening the todo plan no longer pushes the message rail or the jump buttons up; the panel floats above the composer. Refs #14321.
- The line shown after a context fold is one sentence in the interface language, not an English key=value dump. Refs #14307.
- Workbench text menus combine editing and Add to conversation, respect read-only views and selection, and keep focus and undo/redo. Refs #14326.
- An unanswered ask card keeps its picks, typed text, notes and current question when it scrolls out of view and back. Refs #14336.
- A conversation bound to an Agent preset no longer turns read-only after an upgrade changes a built-in tool; it continues with the recorded tools and says so once. Refs #14360.
- The running / failed / action counts on the activity line now share the title's size and weight. Refs #14364.
- When the title model spends its whole output budget thinking, automatic naming asks once more with room for the title instead of failing. Refs #14374.
- The "Import a native session" card in Settings → Storage no longer shows the browser's own file input; it uses an app-styled button. Refs #14378.
- Reads by child tasks, the Planner and the Guardian use their own records and no longer refresh the executor's stale-file guard and overwrite your edits. Refs #14025, #14133.
- The Guardian's own `use_capability` calls enforce read-only execution on the real target, refusing writes and declared host mutations. Refs #14025, #14133.
- After a restart with Git unavailable, an isolated result keeps its files and ID; recovery checks managed paths and repository identity, and a mismatched record stays untouched. Refs #14025, #14133.
- Optimistic task writes honour live sibling claims, including dynamically resolved local tools; disjoint writes stay parallel. Refs #14025, #14133.

## Upgrade notes

- Dispatching to a sidebar project you have not decided about records it as trusted and sends the task; folders that cannot be trusted whole, such as your home directory, still ask. Refs #13341.
- In optimistic mode, a write to a file a sibling task holds is refused with write.path_busy instead of silently overwriting it. Refs #14025.
