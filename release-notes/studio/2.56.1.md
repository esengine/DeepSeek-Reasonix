本版是修复版：收紧只读命令判定中 `python -v` 的漏洞，限制模型同时打开的网页数量，并修复手机窄屏布局、定时运行按钮空白、待发送区误显示按钮、中文路径导致会话读不出等问题。

## 变更

- 工作区在网络盘（如 SMB 映射盘）上时，运行无法判断写入范围的命令前的目录遍历改为并发读取，大目录树上等待大幅缩短。关联 #14813。
- 启动环境摘要优先复用当前数据目录的可信快照，避免其他目录的探测结果改变系统提示、降低首次请求的缓存命中率。修复 #14676。

## 修复

- 安全：只读命令判定现在只把 `node` 和 `python` 单独的版本探针（如 `python3 -V`）当作只读；`python3 -v 脚本` 这类会运行代码的调用需要批准。关联 #14886。
- 模型同时打开的网页上限为 12 个，超过时会提示它先关闭用完的页面，避免一次搜索开出几十个页面占用数 GB 内存；你自己打开的页面不受限。修复 #14844。
- 手机窄屏：侧栏菜单按钮不再紧贴标志；设置页「关闭」与放大按钮并排，设置标签按内容宽度排列。修复 #14865、#14867、#14868。
- 「自动化 → 定时运行」的「预览」和「确认创建」按钮不再显示为空白。修复 #14870。
- 待发送区里已被当前轮接收的插话只显示「立即发送」与「取回」，不再出现点了就报"当前状态不允许此操作"的「改」和移动按钮。修复 #14875。
- 会话的分支信息含中文路径时，不再因编码误判丢掉反斜杠、导致整个会话读不出来。关联 #14841。
- 内置浏览器拾取元素时，属性名按属性值同样的上限裁剪。关联 #14580、#14849。
- `/migrate` 读不到旧会话目录时会报出目录和原因，不再说没有需要迁移的会话。关联 #14823。
- `doctor repair` 读不到配置时报告 unreadable 并以非零退出，`--apply` 不再改写它；`doctor runtime` 没有可询问的 runtime 时显示 unknown。关联 #14824、#14825。
- 完成报告、步骤提示和能力诊断里截断的中文等多字节文字不再出现半个字符。关联 #14842、#14843、#14851。

## Changed

- With the workspace on a network drive such as an SMB share, the walk before an unclassified command reads concurrently, much faster on big trees. Refs #14813.
- Startup summaries prefer the current data home's trusted snapshot, so another directory's probe no longer changes the system prompt and cold-starts the cache. Fixes #14676.

## Fixed

- Security: the read-only check treats only a bare `node` or `python` version probe (such as `python3 -V`) as a read; `python3 -v script` and other calls that run code need approval. Refs #14886.
- The model can have at most 12 pages open; past that it is asked to close finished ones, so one search no longer opens dozens. Your own pages are not limited. Fixes #14844.
- On a phone, the sidebar menu button no longer touches the logo, Settings puts Close beside expand, and its tabs fit their content. Fixes #14865, #14867, #14868.
- The "Preview" and "Confirm" buttons of Automation → Scheduled runs no longer show blank. Fixes #14870.
- Guidance the running turn already accepted shows only send-now and withdraw in the pending panel, not the edit and move buttons that always failed. Fixes #14875.
- A branch record holding a CJK path no longer loses a backslash to a wrong charset guess, which made the whole session unreadable. Refs #14841.
- When the built-in browser picks an element, attribute names are clipped to the same limit as values. Refs #14580, #14849.
- `/migrate` names the directory and the cause when it cannot read the legacy sessions, instead of saying there was nothing to migrate. Refs #14823.
- `doctor repair` reports an unreadable config and exits non-zero, `--apply` leaves it alone; `doctor runtime` says unknown with no runtime to ask. Refs #14824, #14825.
- Multi-byte text cut in completion reports, step hints and capability diagnostics no longer ends in half a character. Refs #14842, #14843, #14851.
