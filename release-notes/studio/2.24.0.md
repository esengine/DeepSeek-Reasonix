本版加入应用内反馈和每个模型单独的上下文设置，并修复重启后首次启动误报、远程中转断线原因不明等问题。

## 新增

- 应用内反馈：可附截图和昵称，得到受理编号，并在「我的反馈」里查看进度、维护者回复和追问 (#11432, #11435, #11445, #11446)
- 终端支持 `/feedback`，可提交反馈、查看进度并回复 (#11432, #11445)
- 每个模型可单独设置上下文窗口和最大输出，未设置的沿用服务商的值 (#11422)
- 技能支持 `disable-model-invocation`（禁止模型调用）和 `user-invocable`（不出现在斜杠列表） (#11439)
- MCP 服务器可单独禁用其中的某个工具 (#11468)
- 市场插件可以来自 GitHub 仓库的子目录 (#11449)
- 终端问答在答完最后一题时可自动提交，默认关闭 (#11357)

## 变更

- 远程中转连接失败时分别提示来源被拒、被限流、离线、网关不可达等具体原因 (#11438)
- 启动等待延长到 60 秒，3 秒后显示「正在启动」窗口，提前退出时自动重试一次 (#11479)
- 市场读取失败可重试，并在重试后保持焦点 (#11442, #11444, #11465)
- 安装信任披露按界面语言显示，自动化事件名称也一样 (#11453, #11454)
- 更新或安装进行中，对应的行和设置导航会被锁定，避免并发操作 (#11450, #11460, #11469)

## 修复

- Git Bash 不在默认位置时也能被找到，并排除 WSL 转发程序 #11421
- 删除项目后重启不再因为启动目录而重新出现 #11418
- 重启电脑后首次打开不再直接报「内核没给握手」 #11434
- 切换连接后，市场和发布表单不再沿用另一个连接的状态 (#11466, #11478, #11480)
- 插件包里的 MCP 服务显式连接时保留所属的包 (#11476)
- 存储面板遇到超大目录不再拖慢 (#11389)
- DNS 解析失败不再被报成连接重置 (#11394)
