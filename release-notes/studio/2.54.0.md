本版新增全局显示 / 隐藏快捷键、用量页的上传量、隐藏服务商共同前缀，并把设置拆成子页、壁纸移到外观，修复多处预算与界面问题。

## 新增

- 桌面设置提供默认关闭的全局显示 / 隐藏快捷键，支持按键录制与清除；仅 Studio 运行时有效，不会启动已退出的应用。关联 #8290。
- 服务商设置里可以「隐藏共同前缀」，路由类服务给每个模型加的同一段前缀（如 group/）在各处显示时省略，只改显示。关联 #14573。
- 设置 → 用量里多了「上传量」，显示今天和近 30 天发给模型服务商的请求内容大小、次数、平均每次多大，并按服务商列出。关联 #14670。
- 反馈窗口会记住上一次成功提交的联系方式并自动填入，仍可修改，清空后不会再冒出旧的。关联 #14610。
- 主题可以按深色 / 浅色分别设置导航、图标栏、顶栏、侧栏和输入框在背景图上的不透明度。关联 #14589。
- 新增默认关闭的「连接检测」授权开关，只有你打开后才会向服务商发起后台检测请求。关联 #14620。

## 变更

- 设置里「模型偏好」的「看图」下拉框只列出已声明支持读图的模型；已选的旧模型仍会显示，并标明"未声明读图"。关联 #14418。
- 「壁纸」及其选择、替换、移除、导入、浓度、压暗和焦点控件移到「外观」的独立区块，已选壁纸的预览直接显示。关联 #14470。
- 待发送队列与输入框共用外框和底色，采用紧凑透明行与轻量图标操作；现有操作与快捷键保持不变。关联 #14497。
- 较长的「工具与权限」和「外观」拆成几个子页，在左侧导航里直接点选；搜索或链接会自动切到设置所在的子页。关联 #14625。
- 设置页文字统一成同一套样式，字号从 10 种减到 5 种，字重和灰色也收成固定几档。关联 #14625。
- 关闭工作台里最后一个页面后，留下"新建页面"的启动器，不再把整列收起。关联 #14037。
- 「柔和」对比度改为真正更低对比、仍达 AA 的内置配色，不再比默认更强。关联 #12019。

## 修复

- 打开设置时不再每次遍历磁盘统计「存储」大小；这个数字延后读取，十分钟内沿用上次结果。关联 #14315。
- 用量总额会说明其中有几笔调用未定价、以及原因，不再只由一个标志暗示。关联 #14522。
- 压缩上下文时摘要请求的连接被中途重置（比如本地网关重启），会自动重试一次，不再直接失败。关联 #14643。
- 压缩后“较早的消息过长，只通过摘要保留”的提示在中文界面下也用中文显示。修复 #14651。
- 命令或同一批调用被宿主拦截时，工具卡片用中文说明原因，不再显示英文的 blocked 提示。修复 #14652。
- 历史超过读取上限的会话不再只报英文错误，会说明文件完好，并可「从最近的内容继续」另存为新会话。修复 #14660。
- 删除来自 Reasonix 1.x 的会话后，同一会话不再重新出现在侧栏；删除状态重启后保留，且不修改 1.x 的原始存储。修复 #14632。
- 在弹窗里放大查看截图时，按 Esc 只退出大图，不再关掉整个反馈弹窗。修复 #14609。
- 点“继续派发”后，输入框上方“待发送已暂停”的提示会随之消失。修复 #14616。
- 鼠标点开设置等弹窗后按 Esc 关闭，左侧图标栏按钮不再带着焦点环停在“悬停”样子。关联 #14624。
- 工作区里有多个 Git 仓库时，改动列表不再撑出面板，有自己的滚动条。修复 #14628。
- 文件工具栏的保存按钮保持紧凑，启用和禁用状态都清晰可读。关联 #14231。
- 同一个网关拒绝 stream_options 的结论按进程只学一次，不再让每个新会话都多发一次失败请求。关联 #14606。
- 显式子代理技能调用遵守已有任务根预算；恢复 Goal 时规划与执行一起获得新的预算切片；本地费用门禁采用发生时刻的权威报价；Windows 跟踪命令保留已发布的 Job Object owner。关联 #14025。
- 文件大小和修改时间未变时，候选快照不再复用 Git 缓存中的旧内容，私有索引重建保留用户暂存区。关联 #14025。
- ACP 的 inbox 拒绝带机器码：`-32020` 队列拒绝，`-32021` 该工作可能已执行、不要重试。关联 #14551。

## New

- An opt-in global show/hide shortcut in desktop settings, with key recording and Clear; it works only while Studio runs and never launches a stopped app. Refs #8290.
- A provider can hide the prefix all its models share (such as group/ from a router) everywhere the model name is drawn; display only. Refs #14573.
- Settings → Usage has "Upload volume": request bodies sent to model providers today and over 30 days, count, average size, and a per-provider list. Refs #14670.
- The feedback form remembers the last successfully submitted contact and prefills it; it stays editable and a cleared field stays cleared. Refs #14610.
- Themes can set per-scheme (dark / light) opacity for the navigation, rail, chrome, side and composer surfaces over a background image. Refs #14589.
- A default-off connection-health consent setting: background provider checks run only after you turn it on. Refs #14620.

## Changed

- The vision row in Model preferences lists only models declared to read images; a model chosen earlier stays visible, marked as not declared. Refs #14418.
- Wallpaper, choose/change/remove, import, strength, dim and focus move to Appearance; the selected preview is visible directly. Refs #14470.
- Pending messages share the composer frame, with compact transparent rows and icon actions; existing queue actions and shortcuts are unchanged. Refs #14497.
- The long Tools & permissions and Appearance sections are split into pages in the left navigation; search and links open the page a setting is on. Refs #14625.
- Settings text follows one set of styles: 5 font sizes instead of 10, with fixed weights and grey tones. Refs #14625.
- Closing the last page in the workbench leaves the new-page launcher instead of folding the column away. Refs #14037.
- The Soft contrast level is a genuinely lower-contrast built-in palette that still meets AA, instead of reading stronger than the default. Refs #12019.

## Fixed

- Opening Settings no longer walks the disk for the Storage total each time; it is read after the window is up and reused for ten minutes. Refs #14315.
- A usage total says how many of its calls were never priced, and why, instead of only carrying an incomplete flag. Refs #14522.
- When the connection of a context-summary request is reset mid-stream, compaction retries once instead of failing at once. Refs #14643.
- The "earlier messages were too large to keep whole" notice after a compaction reads in the window's language. Fixes #14651.
- When the host stops a command or a call in a batch before it runs, the tool card explains why in your language instead of an English "blocked:" line. Fixes #14652.
- A session over the read limit no longer stops at an English error; the file stays intact and "Continue from the most recent part" saves its newest part as a new session. Fixes #14660.
- Deleted 1.x conversations stay out of the sidebar after restart; the original store stays unchanged. Fixes #14632.
- Pressing Esc on an enlarged screenshot closes only the screenshot instead of the whole feedback dialog. Fixes #14609.
- The "queue paused" notice goes away once dispatch resumes instead of lingering. Fixes #14616.
- After a mouse-opened dialog is closed with Esc, the icon rail button no longer keeps a focus ring as if hovered. Refs #14624.
- With several Git repositories in a workspace, the workbench changes list no longer grows past the panel; it scrolls on its own. Fixes #14628.
- The file toolbar's Save button stays compact and readable in both enabled and disabled states. Refs #14231.
- An endpoint's refusal of stream_options is learned once per process, so each new session no longer sends one extra failing request. Refs #14606.
- Explicit subagent skills share the existing root budget, and resuming a Goal renews planner and executor budget together. Refs #14025.
- Local cost gates use the occurrence-time quote, and tracked Windows commands keep their published Job Object owner. Refs #14025.
- Candidate snapshots no longer reuse stale Git-cached content when size and mtime are unchanged, and private index rebuilds keep the user's staging area. Refs #14025.
- ACP inbox refusals carry machine codes: `-32020` for a queue refusal, `-32021` for work that may already have run and must not be retried. Refs #14551.
