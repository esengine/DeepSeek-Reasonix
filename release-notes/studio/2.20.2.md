本版让 Studio 有了独立的匿名遥测，图片多的会话不再把自己写坏，评测报告会写明是哪类未完成义务导致分歧。

## 修复

- Studio 启动时没有开启遥测报告，服务端只统计到 1.x；现在以 `studio` 单独计数，仍遵守现有的隐私开关与 `DO_NOT_TRACK` (#10982)
- 图片改为按内容哈希存进会话目录，事件日志只存引用，不会再超过 128 MiB 后无法读取；超限的旧会话可以重新打开 (#10970)
- 评测分歧不再只显示笼统的 `obligation.outstanding`，报告会带上未完成义务的类型（不含内容） (#10980)

## 升级须知

- 带图片的会话改用 schema 3 格式，旧版 Studio 和 1.x 会拒绝打开它，避免把看不懂的图片引用存坏；纯文本会话格式不变 (#10970)
- 遥测不上传对话、项目文件、提示词、账号邮箱或模型内容，启动统计按匿名安装标识每天去重 (#10982)
