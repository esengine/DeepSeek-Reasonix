本版正式打通 Web Studio 与桌面 Studio：手机或其他浏览器可通过同一账号安全连接家中电脑，看到并操作同一套会话；桌面端会明确显示谁正在远程控制，并可随时断开。

## 新增

- Web Studio 现在使用完整的 Studio 界面，通过端到端加密的远程通道访问电脑上的同一内核、工作区、会话与模型配置，不再是另一套简化控制页 (#11054, #11053)
- 桌面端顶部新增统一的「设备访问」状态：显示互联网远程设备数量、稳定的设备编号、Web Studio 在线状态，以及连接和离开提示 (#11058)
- 桌面端可对互联网远程设备执行两步确认断开；中转服务只允许同账号的电脑端关闭对应控制连接 (#11057, #11058)
- ACP 客户端可收到上下文用量和会话费用 (#11083)
- 发往模型服务的请求带上 `Reasonix/<版本>` 标识 (#11063)

## 变更

- 从 Web Studio 发出的消息在桌面端标注「来自 设备 N」，两端看到同一条会话和回复，便于确认当前操作来源 (#11058)
- 即使没有开启局域网手机访问，桌面端仍会持续显示互联网远程设备状态；局域网开关不会影响同账号 Web Studio (#11058)
- 远程请求超时、连接断开和身份校验错误改为中文可操作提示；请求错误固定在右下角悬浮显示，主动断开后提供「重新连接」入口 (#11058)
- 只有完成端到端加密握手的 Web Studio 才会出现在桌面设备列表；中转服务只转发密文，无法读取会话和文件内容 (#11054, #11058)
- 断开命令由本机窗口发起，并同时校验账号和单次连接标识，不能跨账号关闭其他人的连接 (#11057)
- 打开 Web Studio 时授权请求与页面加载并行进行，连接更快 (#11067)
- 计划里写明要改的文件时，这一轮什么都没改就不会判为完成 (#11060, #11056)
- 计划步骤的检查命令在最近一次改动之后跑通即可放行，不再要求额外引用；没有检查命令的步骤不再阻塞 (#11046)
- `edit` 找不到 `old_string` 时会指出是空行数量不同；空行数量不同但其余一致时也能匹配 (#11064, #10946)

## 修复

- Windows 上 Studio 启动失败时弹窗说明原因，并在日志目录写下 `shell.log` 与 `host.log`（敏感参数已打码） (#11069)
- Windows 安装包内的全部 exe 和 dll 都已签名，开启智能应用控制的电脑不再因未签名的组件拒绝启动 (#11080, #11091)
- 重新打开会话后，已回答的提问仍可阅读 (#11078)
- 写文件的工具调用返回后，资源管理器立即刷新 (#11068)
- 只包含一个网址的行内代码可点击打开 (#11070)
- `PATH` 缺少 `%SystemRoot%` 时也能打开主题文件夹 (#11084)
- Anthropic 模型在结果增量里返回的网页搜索结果能正常显示 (#11087)
- 在 Studio 里通过 ACP 输入的技能调用保持原样发送 (#11045)
- 无法归类的计划检查命令不再让自己永远等待下一次运行 (#11090)

## 升级须知

- 使用 Web Studio 完整远程控制与桌面端在线提示，需要电脑上的 Reasonix Studio 升级到 2.20.4；旧版仍会显示为不支持完整桌面能力 (#11058)
