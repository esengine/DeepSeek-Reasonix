本版带来与 1.x 聊天界面一致的终端界面，并能打开 1.x 保存的会话；bash 外连可限制到指定域名；「模型服务」设置独立成页；另修复一批用户报告的问题。

## 新增

- 新的终端界面：在终端里直接运行 `reasonix`（或 `reasonix tui`）即可打开，外观和操作与 1.x 聊天界面一致 (d58a02719, c5b651bea)
- 终端界面默认全屏，带滚动条、滚轮和拖选复制；`--inline` 则把对话写进终端的回滚区 (6146fb508, 7519957fb, 6cd950890, a7ffbd48e)
- 终端界面接受 1.x 的会话选项：`--effort`、`--permission-mode`、`--yolo`、`--add-dir`、`--allowed-tools` 等 (a7ffbd48e)
- `--permission-mode` 也认得 1.x 的 `workspace-write`、`danger-full-access` 等名称 (3047105ea)
- 终端界面：`-r` 或 `/resume` 可挑选要继续的会话；Ctrl+V（Windows 上为 Alt+V）可粘贴截图；Ctrl+B 可展开长的 shell 输出 (4ad09c665, 4b9ec9298)
- 终端界面：提问逐题作答；输入 `/` 或 `@` 弹出补全；显示任务列表；需要你处理时发出系统通知 (3579dbbd3, 5ff9d7a0f)
- 终端界面全屏时，点击或按 Ctrl+O 可展开回答的思考过程 (#10917 by @esengine)
- 终端界面新增 `/version`，显示当前构建版本 (#10793 by @onionviolet, #10828 by @onionviolet)
- 终端界面和 ACP 编辑器里，以 `!` 开头的一行直接运行你自己的命令，模型会读到命令、退出码和输出后接着回答 (72e5d8ddb, e86fd8f88, ed499c4ca)
- 可列出并打开 1.x 保存在 sessions-v4 中的会话，以及 1.38.2–1.38.7 保存的 schema 2 会话；继续对话时另存为新的 2.x 会话，1.x 的原文件保持不变 (454d1da76, 2c63162b6)
- `--continue` 找不到已保存的会话时改为开启新会话，不再直接退出 (#10815 by @BuGlessRB)
- `[sandbox] allowed_domains` 可把 bash 的外部网络限制到指定域名；名单外的域名会询问你是否放行，可选仅本次或本会话；macOS 与 Linux 生效 (45f28b677, a250e3139, ebb278cec)
- Agent 读过的文件若之后被你或其他程序改过，`write_file` 会拒绝整体覆盖并要求先重读；可用 `[tools].protect_changed_files` 或 Studio 沙盒设置关闭 (79c984b32)
- 开启 `[agent] worktree_isolation` 后，`task` 可让负责写入的子代理在独立的 git 工作树中运行，结果由你决定应用还是丢弃 (9da268b76)
- 设置中的「模型服务」独立成页，左侧列出服务、右侧直接编辑；「模型偏好」改为一张按用途选模型的表 (a11c9bf95, 186e75abb)
- 资源管理器可在系统文件管理器中显示文件或文件夹 (#10862 by @esengine)
- 新增「只看改动」折叠方式：只展开改动过文件的步骤 (#10875 by @esengine)
- 输入框下方新增眼睛按钮，可隐藏钱包余额和会话花费，方便共享屏幕 (#10959 by @esengine)
- 在侧栏选中会话后按 Delete（macOS 为 ⌘+Backspace）可删除，同样需要确认 (#10960 by @esengine)
- 窗口变空白时可按 Ctrl+R / ⌘R 或 F5 重新加载；渲染进程崩溃时自动重新加载 (#10940 by @esengine)
- Linux 与 Windows 上按 F11 进入全屏 (#10899 by @esengine)
- 后台任务可在列表中停止 (74ae5a337)
- 编辑消息、重新生成或回退时，被截掉的对话保存为一个版本，挂在侧栏该会话下，可随时打开 (a7986e6ea)
- 主题包可为对话中的加粗文字单独指定颜色 (#10944 by @esengine)
- 打开的 Markdown 预览和文件预览会随磁盘上的改动自动刷新 (#10829 by @KHG420, #10879 by @esengine)
- `@` 引用可按字母顺序模糊匹配，例如 `@proinf` 能找到 `ProjectInfoNew.tsx` (#10910 by @esengine)
- 单选题选中选项后仍可附上一段文字 (#10958 by @esengine)
- 使用独立的规划模型时，规划模型能看到执行模型上次规划之后做了什么 (#10897 by @esengine)
- `multi_edit` 一次报告所有失败的步骤 (#10854 by @esengine)
- 新增 `SubagentStart` hook；`SubagentStop` 在子代理失败或取消时也会触发 (#10905 by @esengine)
- 提问等待回答时触发 `Notification` hook (#10812 by @scrappylabsai)
- MCP 服务器配置可用 `${REASONIX_WORKSPACE_ROOT}` 或 `${CLAUDE_PROJECT_DIR}` 指代当前工作区 (#10903 by @esengine)
- 可读取 OpenRouter 的 credits 接口作为余额 (#10935 by @esengine)
- ACP 客户端可暂停、恢复已有的 Goal (#10943 by @esengine)
- 新增 `[skills].suppress_warnings`，启动时可隐藏非致命的技能警告 (#10795 by @onionviolet)

## 变更

- 审批模式在权限菜单、设置和工具栏中统一为「不询问 / 询问 / 自动批准 / 全部放行」，窄屏时菜单不再超出屏幕 (eab809e16)
- 请求失败的提示浮在输入框上方，不再把输入框顶上去 (f3274a324)
- 模型长时间不出数据时，等待五分钟才判定连接断开，适合较慢的本地模型 (#10901 by @esengine)
- 技能过多时，列表改为列出全部技能名称，不再截掉末尾 (b2ddd0c91)
- 环境信息写明所报告的 shell 是 bash 工具所用的，不再被当成你的登录 shell (#10895 by @esengine)
- 写入工作区之外被拒时，说明原因是写入范围，而不是沙盒 (#10907 by @esengine)
- 正在运行的步骤带有动画，步骤行去掉多余空白 (#10859 by @esengine)
- 侧栏只突出当前会话所在的工作区；项目行的 × 改为「···」菜单 (c9ebc5815)
- 终端界面原生鼠标模式下去掉滚动条和代码块竖线 (#10816 by @BuGlessRB)
- 终端界面支持 Shift+PgUp/PgDn 翻页、Shift+Insert 粘贴 (#10873 by @esengine)
- 终端界面遵守 `ui.show_turn_usage` 和用户级 `[statusline].command` (#10894 by @esengine, #10936 by @esengine)

## 修复

- 仓库自带的配置不能再给自己授予 `host_authorities`（如 docker 套接字） (e07df2ed8)
- `reasonix review` 不再执行被审查仓库自己配置的搜索程序和技能 (#10850 by @esengine)
- 已配置的工具 hook 在子代理、规划器、守护模型和 `reasonix review` 中同样生效 (#10846 by @esengine)
- 编辑 UTF-8 中文文件时，未改动处的字节不再被错误改写；被截断在半个字符处的输出、MCP 服务器的 GBK 错误输出不再显示为乱码 (#10889 by @esengine, #10947 by @esengine, #10911 by @esengine)
- 长时间高强度思考不再因客户端的思考字节上限而中止 (#10913 by @esengine)
- DeepSeek 思考模式在工具轮次后只留下思考、没有回答时，自动重试一次 (#10820 by @esengine)
- Goal 的完成判定在思考模型上不再因回答为空而暂停 (#10785 by @esengine)
- 响应头超时会重试，不再直接结束本轮 (#10882 by @esengine)
- Anthropic 在尚未输出时返回的错误（如 overloaded）会重试 (dae42027c)
- 某些中转站因工具 schema 中 `required: null` 拒绝整个请求的问题 (d31823235)
- 通过 OpenAI 兼容中转使用 Gemini 时，每次请求都返回 400 (#10931 by @esengine)
- OpenCode Go 服务因缺少 `x-opencode-session` 报 400 (#10954 by @esengine)
- `request_url` 只是重复 `base_url` 时被当作未设置，修复部分中转站返回 404 (#10937 by @esengine)
- Responses 中转漏发结束事件时，工具调用不再被丢弃 (#10923 by @esengine)
- 子代理只写模型名时，留在父会话所用的服务上 (#10928 by @esengine)
- 新增模型服务时，不再覆盖或读到其他服务的密钥 (#10932 by @esengine)
- 修改模型服务的上下文窗口等设置后，正在运行的会话立即生效 (#10915 by @esengine)
- TypeSafe 模型的检查改为通过 System One 实际发起请求 (#10952 by @KHG420)
- 中国法定节假日按 DeepSeek 低峰价计费 (#10758 by @nanami-0713)
- 切换模型会等正在进行的 `/compact` 完成，不再丢失压缩结果 (#10880 by @esengine)
- 回合开始时即保存对话，进程被中途结束也不会丢失刚发出的消息 (#10824 by @esengine)
- 重新打开会话时，主机写给模型的指令不再显示成你输入的内容 (#10927 by @esengine)
- Goal 在两轮之间重启后，高风险改动仍需审查，已取得的验证不必重跑，原有的检查不会被改写的声明绕过 (acc273a31, 5521459d2, 7a8b720bc)
- 独立工作树中的子代理结果在重启后仍可应用；会话关闭时中断的后台任务显示为「已中断」而非「已终止」 (09d281160, 56b24652d)
- Linux 包不再依赖较新的 glibc，glibc 2.31 系统上能启动 (#10810 by @esengine)
- Wayland 下有 XWayland 时改用 X11 启动，避免窗口出现前崩溃 (#10823 by @esengine)
- 工作区在 Box 等云盘挂载目录下时，配置能正常加载 (#10900 by @esengine)
- 连接 OpenSSH 默认 shell 为 Git Bash 的 Windows 远端机器 (#10906 by @esengine)
- Clash 等 fake-ip 模式下 `web_fetch` 不再拒绝所有公网站点 (#10908 by @esengine)
- Windows 系统代理的例外列表中 `127.*`、`192.168.*` 等通配符生效，本机和局域网模型不再绕经代理 (bf4edd280)
- 分页返回工具列表的 MCP 服务器，第一页之后的工具不再丢失 (29ecacc74)
- ACP 客户端发来的图片能传给模型 (#10920 by @esengine)
- 读图时的拒绝说明写清谁能附加图片 (628163e0f)
- `complete_step` 能认出以工作区相对路径引用、以绝对路径写入的文件 (#10896 by @esengine)
- 粘贴的附件和后台任务状态不再出现在 `git status` 里 (#10941 by @esengine)
- 没有沙盒的主机上，沙盒设置的其他字段仍能保存 (e4fc2b0e1)
- 启动时文件夹列表显示「加载中」，不再误显示「尚无文件夹」 (#10963 by @esengine)

- 进度条（curl、pip 等）在工具卡片中原地刷新，不再只显示 0% (#10874 by @esengine)
