本版的主线是**界面的可交互动作成为一个被声明、被普查、被 CI 约束的集合**：每个控件在源码处写下自己的动作 id，`actions.ts` 再独立声明一次，`tools/ui-census` 从源码结构判定哪些输入会写入宿主状态，十六条不变量在 CI 中拦截——一个被证明会写、却没有任何动作声明的输入不能进入主干。同期收拢回合边界：一个回合只开始一次，`turn_started` 携带它所属的消息，一次工具调用记录发起方，一份轨迹声明自己覆盖了会话的哪一段。压缩侧改为按实际发生的调用记账：一次折叠的回执覆盖它发出的每一次摘要请求，`/compact` 不再因重复调用而重复付费。自 2.13.0 起 89 个提交。

**升级路径**：无需人工步骤。三平台照旧自更新——Linux 走 `.deb`，Windows 运行下一个安装器，macOS 替换自身 bundle。

## 新增

### 界面动作：一份注册表，一套普查，十六条不变量

- **界面声明 132 个动作 id**。id 形如 `<界面>.<意图>`，在控件处写一次、在 `actions.ts` 中再写一次，两处可以不一致并因此被检出——共用同一个常量会让检查退化为把一个值与它自身比较。属性只承载归属：涉及哪一条记录由 `data-target` 表达，给出哪一个答案由 `data-value` 表达，因此一行渲染七十次仍然是同一份契约，而「取消」这类文案不会成为身份。
- **`tools/ui-census` 从源码结构判定输入的效果**。426 个交互根，每一条判定或者带有正面证据，或者带有阻断它的开放边；无法判定即为 UNRESOLVED，不按「未被识别」归入只读。十六条不变量在 CI 中运行，`UNDECLARED_MUTATION == 0` 是其核心约束，并已在三次真实缺陷下亮红——一个掩盖 prop 链的 memo 别名、一个掩盖另一条链的 JSX 展开，均非装饰性的绿灯。
- **重命名与阈值调整改为回车提交**。会话重命名、压缩起点、面板重命名此前仅在失焦时写入，而失焦由点击别处、Tab、窗口失活、元素卸载等无意图的原因触发，普查因此将其计为运行时事件而非交互根——三处宿主写入没有对应的根，seal A 成立于一个看不见它们的集合之上。失焦仍然保存，因为点击别处确实是一种回答。
- **Promise 的判定先于续延的解读**。只有源码显式声明的 `Promise<T>` 成立；可能不是的联合类型、无法追踪的别名、`PromiseLike` 与 `any` 均不构成证明。落在已证明 Promise 上的 `.then`/`.catch`/`.finally` 才被视为执行边，且标记为延后——请求返回时才发生的写入不是当前发生的写入。
- **按下反馈的归属由标记决定**。改动前的测量：页面上 42 个接受指针的控件中，21 个在 mousedown 时没有任何视觉反馈。成因是归属而非意图——同一条按下规则列举了九个类名，降低动效的块中存在第二份副本，更上方还有第三份拼写不同的副本。归属现改为由标记语义决定（`button`、`summary`、`a[href]` 等）。

### 回合边界与回放

- **一个回合只开始一次**。此前一个回合有几次模型运行就产生几个开始：协调器在计划前开启一个，执行器在工作前开启另一个，回合中批准的计划再开启第三个。该路径是生产可达的——当计划方判定无需改动时，执行器根本不会运行。
- **`turn_started` 携带它所属的消息**。此前该事件不带任何标识，自行生成用户行的客户端只能按位置配对、以提示词文本确认，两条相同的提示词无法区分，而一条插入其间的引导会使其后每一次配对错位。
- **工具调用记录发起方**。模型发出的调用、宿主代为铸造的调用（为已批准的计划铺设清单、推进步骤、关闭目标、将一次委派展开为条目）、供应商在其侧执行的调用，此前共用同一个 id 空间与同一种形状。真实语料统计：51 个候选执行片段中有 5 个以 `plan-seed` 开头——那是宿主自身的记账，任何按步骤计数的折叠都会将其计入模型。
- **重开会话可从落定的 `message` 帧重建卡片**。记录中不保留流式增量，回放只有一帧落定的 `message`，而此前的归约器只能为流已经开启的卡片封口，因此重开会话会丢失计划方写过的全部回答。
- **`/trajectory` 声明覆盖范围**。此前返回裸数组，三种状态产生同一个空结果：未被记录的运行、被容量上限停止追加的日志、确实未产生帧的会话。读取方将最后一帧当作运行终点时，三次中有两次正确，且无从分辨是哪一次。

### 压缩：回执与经济性

- **压缩回执覆盖它发出的每一次摘要调用**。此前读取的是被保留的那个答案的用量；一次需要覆盖修复的折叠会产生两次计费而只保留一次，因此上报的数字从来不是这笔交易本身。
- **`/compact` 只免除触发条件与尾部长度**。此前该命令设置一个 `Force` 标志，而该布尔承担五项职责，其中只有两项对应用户请求的语义。另外三项是重复调用会产生两份摘要的原因——本机历史中自动压缩约每五千次调用触发一次，而 `/compact` 按定义每次都触发。
- **覆盖修复改为从宿主回执补全**。此前的做法是对同一次折叠再做一次摘要，以恢复摘要遗漏的改动文件；而这些事实是宿主自有的——回执已经记录哪些路径被写入、哪些命令失败。
- **压缩不再提升本地原始工具输出**。

### 计费、上下文与运行时指标

- **会话报告计费完整度的四种状态**。此前是一个布尔值，而聚合需要区分四种情形：未产生计费、每一轮均已定价、部分定价、全部未定价——其中第一种与第四种的金额合计同为零。Studio 侧另有一个原因：该字段声明在页面自己的 `CostQuote` 中且无人读取，会话投影并不携带完整度。
- **上下文表盘以折叠点为分母**。决定何时折叠的是两个界限中较低的那个，而绘制在界面上的是模型窗口：一个 1M 会话在维护实际发生的时刻只绘出 16% 的进度。该设置背后是内核的配置语言——一个有符号整数，负值表示停用经济界限，而窗口份额仍会在 85% 触发，标签却读作「关闭」。
- **上下文与缓存各自声明分母**。用量此前绘制两次，一次对折叠点、一次对模型窗口，393 次采样渲染中从未出现不一致，因为它本就是同一个数。现绘制一次，每个上限各占一行并各自标注分母：单一百分比无法表达「6%」指的是宿主开始整理的那个点，还是模型能够容纳的总量。
- **运行时面板按内容出现**。一次干净运行的采样中，100% 的样本显示「失败步数 0、外部请求 0、子代理数量 0」，以及两个仅用于声明自身没有内容的区块。
- **吞吐按墙钟过期而非由墙钟重新推导**。此前每秒读取四次，无论是否有 token 到达：样本从窗口前端老化而被除的跨度不变，读数因此沿平滑斜坡下滑。采样到一次运行中连续十七个读数自 87 降至 2 tok/s，其间模型没有任何产出。
- **工具派生的运行时指标来自执行记录而非卡片**。

### 设置与外观

- **设置可检索，并逐项声明生效方式与作用域**。此前查找一项设置需要预先知道它归属十四个页面中的哪一个；而改动的后果是整张表最上方的一句话，该句只覆盖三种情形中的两种。作用域由每个控件背后的端点行为确定，而非按它归档在哪一页推断——仅模型页一页即同时存在按供应商条目存储、按整机存储、以及不做存储的值。
- **外观页按访问目的排序**。此前全部控件一次呈现，顺序为语言与窗口在前、明暗与配色在后。现调整为明暗、配色、大小、壁纸在前，语言与窗口其次，字体、文字粗细与文字对比度折叠为一个展开项。
- **被拒绝的写入在发生点击的页面上呈现**。对活动内核逐一点击 121 个非破坏性按钮并检查内核拒绝时界面是否给出回应，其中一处没有：会话页的「创建隔离副本」。`run()` 已正确捕获并存储拒绝原因，但打印它的横幅被复制到了模型页与扩展页，会话页写入同一状态却没有呈现位置。横幅移至每一页共用的那一列。同一次清扫另行移除两处以渲染文案作为状态判据的代码：技能行以比较「调不到」决定标记，会话归约器以比较「等待工作区」判断所离开的状态。
- **设置页与工作区的次要部分改为按需加载**。

### 导航栏：机器、工作区、会话

- **导航栏呈现三层结构**。此前绘制「工作区」与「远程」两个区块，各有标题、添加按钮与各自对「一行是什么」的定义；而其下的层级本就只有一种——远程工作区已在使用本地工作区的类渲染，在某个目录中打开会话也是同一个意图。本地此前跳过机器这一层，现以列表中的第一台机器呈现。
- **搜索覆盖整份列表**，而非当前展开的段落。
- **远端会话标题在远端内核写入后到达**。远端内核在第一个回合结束时为会话命名，而此前没有任何路径在此之后重读该记录。

## 修复

- `grep` 的斜杠通配以搜索目标为根，而非以工作区为根。
- 回合运行期间，实心按钮是停止该回合的按钮。
- 标题栏控件重新排除在窗口拖拽区之外。
- 窗口内的内核使用所配置的语言。
- 卡片在回合中到达时转录不再跳动。
- 菜单标记当前行的方式与导航栏一致；会话行的操作为弱化呈现而非隐藏。
- 已知金额不再按零的字符串形式输出。
- 内核已给出的答案会到达设置页的读取方。
- 动效具有明确成因，挂载不作为成因。

## 门禁与工具

- **普查跟进动态 import**。`@babel/parser` 8 将 `import()` 解析为 `ImportExpression`，而普查按调用名读取该节点，该分支从未命中；设置页改为按需加载后，整棵设置子树退出产品可达图，75 个动作被记为没有生产根。
- **输入框的粘贴声明动作身份**。粘贴文件经 `attach → upload → port.attach`，构成一次证据确凿的宿主写入。
- `make check` 会打开 git 尚未记录的文件。
- 发布流水线从产生产物的作业取件。
- 本版界面文案、注释与守卫输出统一为书面中文，代码注释统一为英文。
