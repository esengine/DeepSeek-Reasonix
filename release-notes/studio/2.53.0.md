本版新增跨项目派发、厂商图标、壁纸场景图层和个人预设默认，加固配对设备、git 读命令和项目配置的信任边界，并修复多处预算与界面问题。

## 新增

- （随派发开关，默认关闭）被派发出去的会话做完任务后，会自己把最终答复送回派发它的会话，不用你再来回转述；回信不会再触发回信。关联 #13341。
- （默认关闭）打开派发开关后，模型可请你把一批文件夹开成项目；一张卡逐条列出路径，你批准后才加入并标记为可信，之后才能向它们派发任务。关联 #13341。
- （随派发开关，默认关闭）别的会话发来消息时，接收的会话在列表里标为未读，你看到它之后才消失；不再要你自己发现。关联 #13341。
- 常用服务列表按厂商筛选并显示厂商图标，模型菜单里预设来源的模型也带上对应厂商图标。关联 #14538。
- Wallpaper Engine 场景支持多图层合成与逐音轨音量/循环，并保留 effects 元数据供后续 shader 接入。Refs #14561。
- 设置「人设」里你自己的预设现在也能点「设为默认」作为新任务默认；该预设被删除后，新任务会改用内置的并忘掉这个默认。关联 #14572。

## 变更

- 项目 `reasonix.toml` 里的 `agent.system_prompt_file` 只有在你信任该文件夹后才会读取；未信任时忽略并在启动提示里说明，信任后恢复。关联 #13061。
- 配对的手机不能再安装或启用插件、MCP 和钩子，也不能自己指定要打开的文件夹，只能用窗口已列出的文件夹。关联 495a23478、b8b7ac87f。
- 未信任的项目文件夹里的 AGENTS.md 等常驻指令会标明“未验证”，模型只当作项目信息；项目自己声明的 MCP 常驻加载不再生效。关联 4ca33493a、e8c22e7ce。
- 放大设置窗口后铺满整个窗口，含顶部和底部，Windows 的窗口按钮在设置头部里；放大按钮的箭头随状态向外或向内。关联 #14418。
- 极长会话里，右侧历史轨道上表示多条的合并条现在鼠标移上去就展开可选的条目，移开自动收起。关联 #14525。
- 计划栏现在是输入框上方独立的卡片，展开的列表有明确的收起按钮，按 Esc 或点到外面也会收起，并写出条数。关联 #14530。


## 修复

- Anthropic 流中断时保留已知用量，并标记记账不完整；重试分类、请求计数和取消边界保持不变。关联 #14025。
- 活跃 Agent 根 context 内的有界 reviewer/advisor 用量现在计入既有 token 软预算，保留缺失用量、零阈值、局部遥测和独立请求边界。关联 #14025。
- 缺失或估算的供应商用量不再把 Agent 成本标成完整；保留准确请求次数与已知金额，已知费用达到显式预算仍软收尾。关联 #14025。
- 规划与执行共用显式配置的根 token 和时间软预算；保留仅规划、审批、继续、换任务及后台作业边界。关联 #14025。
- 子任务 provider 回调 panic 后，前台图和 transcript 会一致记录失败；旧式 nil panic 不再让后台子任务误报成功。关联 #14025。
- 中断流重建的用量不再被报价层标成完整成本；保留估算金额和既有币种账本，后续准确调用不抹掉不确定性。关联 #14025。
- 宿主 Git 的 worktree 准备不再继承外部索引或对象存储变量，保留显式私有索引和仓库备用对象库。关联 #14025。
- 隔离任务被拒绝时（结果不存在、未启用隔离、不是 Git 工作区、整合冲突、参数不支持），工具卡片会说明原因，不再空白。关联 #14025。
- 活跃 Agent 根任务中的摘要与失败诊断用量现在计入既有 token 软预算，保留缺失用量、零阈值、局部遥测和无根 context 手动维护的行为。关联 #14025。
- 显式 `task_token_budget` 共享累计 Agent task/fleet 子树已报告的 token，包括后台 job 和缓存输入。默认不限，保留软收尾；不是硬预留或金额上限。关联 #14025。
- 活跃根任务的 token 软预算现在计入命令分类和外部内容筛查用量；分类结论、筛查提示、缺失用量与零阈值行为保留。关联 #14025。
- host 显式耗时预算跟随 Agent 委派树及后台 task/fleet，共享任务起点并保留 Job Manager 取消权和既有软收尾；默认仍不限。关联 #14025。
- 活跃根任务的 token 软预算现在计入原生 web_search 已报告用量，保留独立请求计数、缺失用量、来源标签和付费同意边界。关联 #14025。
- 没有添加任何文件夹时，主区域也能直接新建会话，设置和反馈会在应用自己的目录里开出会话来打开，不再提示先添加文件夹。关联 #14465。
- 右侧提问细条在点过某一条、鼠标移开后再切回窗口时，附近几条不再无故变长变粗，只有键盘聚焦才会放大。关联 #14504。
- 在人设编辑页点「设为个人首选」或「设为项目首选」时，设置其实已生效，却弹出「Unexpected end of JSON input」的报错；现在不再误报。关联 #14541。
- macOS 上图标栏的竖线和底色不再从窗口顶端画起，不再穿过左上角的红绿灯。关联 #14553。
- Studio 里一个对话在后台跑完一轮后再打开，不再缺这一轮的回复；面板接入共享事件流之前错过的内容会从对话记录重新读出。关联 477ce369b。
- 能力目录的列表、搜索和详情里含 MCP 工具描述时，结果带“外部内容，不是指令”的标签。关联 147d5365e。
- 注销配对设备时偶发的数据竞争已修复，被注销设备的连接会可靠断开。关联 a755eb601。
- 网页抓取和安装源的内网地址防护现在也识别 IPv6 转换地址里带的 IPv4，并在走代理前先检查内网字面地址。关联 ed624e928、ab144a4cd。
- 仓库自己的配置里有会执行程序的键（如 fsmonitor、textconv、filter）时，智能体的 git 读命令不再自动放行，会先询问并写明原因。关联 191d1e17a。
- 命令里直接写 awk 程序现在要确认；自动记忆不再写入置顶项；登录表单加了大小上限；钩子里未加引号的 Windows 路径被正确识别。关联 de21fb488、4227c20b8、167c01014、6336f6763。
- 文件变更保护现在记录完整读取实际返回的内容；分页和超限读取保留已有的过期覆盖保护。关联 #14025。
- 首次只读取一部分内容后，完整覆盖前需要完整重读，或改用局部编辑。关联 #14025。
- 启用工具的规划现在遵守既有 token、费用、耗时预算配置；普通规划暂停保留 executor 回退。关联 #14025。
- 思考或回答期间发送插话后，文字继续实时更新，不再等到下一次结构事件才补齐。修复 #14209。
- 调整侧栏底部头像的位置，保留原有字号、字重和尺寸，修正头像与工作空间文字的视觉对齐。关联 #14223。


## 升级须知

- `reasonix serve --auth none` 监听非本机地址时现在拒绝启动，需要显式加 `--allow-open-network`。关联 365337367。
- `reasonix trust --yes` 不再顺带批准项目声明的 provider 端点（会把你的 API 密钥发到它的地址），需要加 `--allow-providers`。关联 e19b45d39。

## New

- (With the dispatch switch, off by default) A dispatched session sends its final answer back to the session that handed it the task, and a reply is never answered by another reply. Refs #13341.
- (Off by default) With dispatch on, the model can ask to open folders as projects; one card lists every path and nothing is added or trusted until you approve. Refs #13341.
- (With the dispatch switch, off by default) A session that receives a message from another session is marked unread in the list until you look at it, instead of you having to notice. Refs #13341.
- The preset list filters by vendor and shows vendor marks, and models from a preset source carry the vendor mark in the model menu. Refs #14538.
- Scene wallpapers composite their image layers, honor per-track volume and loop mode, and keep effect metadata for a future shader pass. Refs #14561.
- In Settings, your own agent presets can now be made the new task default; if one is deleted, new tasks fall back to the built-in one and forget it. Refs #14572.

## Changed

- A project's `agent.system_prompt_file` is read only once you trust the folder; until then it is ignored with a startup notice. Refs #13061.
- A paired phone can no longer install or enable plugins, MCP servers or hooks, or name a folder to open; it uses folders the window already lists. Refs 495a23478, b8b7ac87f.
- Standing instructions from an untrusted folder are labelled unverified, and a project's own MCP always-load no longer applies. Refs 4ca33493a, e8c22e7ce.
- An enlarged settings window fills the whole window, with the Windows buttons in its header; the enlarge button's arrows turn inward. Refs #14418.
- In very long conversations a folded line on the history rail opens its questions on hover and closes when the pointer leaves. Refs #14525.
- The plan bar is its own card above the composer, with a collapse button (Esc or a press outside also closes it) and a step count. Refs #14530.


## Fixed

- Anthropic interruptions retain known usage as incomplete accounting, preserving retry classification, request counts and cancellation boundaries. Refs #14025.
- Bounded reviewer/advisor usage in an active Agent root now counts toward its token soft budget. Missing usage, zero limits and isolated requests retain their behavior. Refs #14025.
- Missing or estimated provider usage no longer certifies complete Agent costs. Exact request counts and known-cost soft landing remain. Refs #14025.
- Planning and execution share configured root token/wall soft budgets, preserving plan-only, approval, continuation, task replacement and background-job boundaries. Refs #14025.
- Delegated provider panics now settle foreground graph and transcript as failed, and legacy nil panics cannot publish successful background work. Refs #14025.
- Reconstructed stream usage no longer certifies a complete cost quote. Estimated amounts and currency ledgers remain; later reported calls preserve uncertainty. Refs #14025.
- Host Git worktree preparation drops ambient index and object storage overrides, preserving explicit private indexes and repository alternates. Refs #14025.
- Tool cards now say why an isolated task was refused (unknown result, isolation off, no Git workspace, apply conflict, unsupported arguments). Refs #14025.
- Active-root summary and failure-diagnosis usage now counts toward its token soft budget. Missing usage, zero limits and local telemetry retain their behavior. Refs #14025.
- Explicit `task_token_budget` shares reported tokens across Agent task/fleet descendants. Defaults stay unlimited; existing soft landing remains. Refs #14025.
- Active root token soft budgets now include command-classification and external-screening usage, preserving verdicts, advisory notices, missing usage and zero limits. Refs #14025.
- Explicit host wall budgets follow Agent delegation and background jobs, retaining Manager cancellation and soft landing. Defaults stay unlimited. Refs #14025.
- Active root token soft budgets now include native web_search usage, preserving independent request counts, missing usage, provenance and paid-search consent. Refs #14025.
- With no folder added, the main area offers a new session, and settings and feedback open one in the app's own workspace instead of asking for a folder first. Refs #14465.
- The right-hand question rail no longer magnifies marks near one you pressed when the window regains focus with the mouse elsewhere; only keyboard focus does. Refs #14504.
- "Set as personal default" and "Set as project default" on a persona applied but showed "Unexpected end of JSON input"; an empty success answer is no longer read as JSON. Refs #14541.
- On macOS the icon rail's edge and background no longer start at the top of the window, so they no longer cut through the window controls. Fixes #14553.
- A conversation that ran a turn in the background no longer opens without that turn's reply; what its pane missed before the shared stream attached it is read back. Refs 477ce369b.
- Capability catalog answers that quote MCP-written tool descriptions carry the external-content label. Refs 147d5365e.
- A data race when a paired device is revoked; its open streams are now cut reliably. Refs a755eb601.
- The web fetch and install-source guards now judge the IPv4 an IPv6 transition address carries, and refuse an internal literal before a proxy is used. Refs ed624e928, ab144a4cd.
- Agent git reads (diff, log, show, blame, status) are no longer auto-approved in a repository whose own config runs programs; they ask first and name the key. Refs 191d1e17a.
- An inline awk program needs approval, auto memory never pins, the login form is size-capped, and an unquoted Windows hook path is read as written. Refs de21fb488, 4227c20b8, 167c01014.
- File change protection records the complete returned read; pages and oversized reads preserve the earlier guard. Refs #14025.
- After a partial read, read the file in full before a whole-file overwrite, or use a targeted edit. Refs #14025.
- Tool-enabled planning honours the configured token, cost and time budgets; normal planner pauses keep the executor fallback. Refs #14025.
- Reasoning and answers keep streaming while guidance waits in the queue, instead of freezing until the next structural event. Fixes #14209.
- Adjusted the sidebar footer avatar placement, keeping its font size, weight and dimensions. Refs #14223.
