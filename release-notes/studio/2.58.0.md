本版重新排版了手机端（标题栏、审批、输入区、模型菜单、设置），让设置更好找（搜索按相关度排序、每页有目录），并缩小了发给模型的工具定义、加快了启动和长会话的恢复与保存。

## 新增

- 记忆按「星系」归类，带重要度和遗忘曲线：常用的越记越牢，久不用的慢慢淡下去，仍能搜到（da640949c、bfc838a3c）。
- 约束类和每轮常驻的记忆永不变淡（c22dd9495）。
- 设置里的记忆页改成三栏：左边分类，中间带搜索的列表，右边详情，可改类型、星系、重要度（d0289a4d0）。
- 刚记住的记忆放在「新的」里，一键「对 / 忘掉」；忘掉是归档，不是删除（d0289a4d0）。
- 手机宽度（≤520px）重新排版：标题栏保留会话列表、居中的标题和机器状态；断线时说明正在重连（411e19d87）。
- 手机上的审批卡是两个等宽的大按钮，拒绝在左、允许在右，其余选项收在「更多选项」后面（411e19d87）。
- 手机上的输入区只留添加、模型和发送，其余控件收在一个「更多工具」按钮后面；运行中发送变成圆形暂停键（ae46c30d3）。
- 手机上的模型菜单改为贴底的面板；推理深度是一条品牌色的深度线，松手时才选定（e8b13d13d、8c71d355b）。
- 手机上的设置全屏、单列，分类变成顶部可滑动的一排，鼠标滚轮也能横向滑动（37ec85381、081f35e9d）。
- 设置搜索按相关度排序，可输入多个词或一整句；43 条常见说法（如「深色模式」「换模型」「关闭通知」）都排在前三，其中 23 条原来显示「没有匹配的设置」（4779d91c5）。
- 每个设置分类页顶部有「本页包含」目录，折进该页的设置也能一键跳到（4779d91c5）。
- 有新版本时，侧栏底部会出现「新版本 x.y.z 可用」按钮，点一下直接打开版本页；已下载待重启时也在这里提示（289033df0）。
- 更新方式默认改为「通知」：全新安装会在后台读取版本目录，发现新版本时提示，不下载也不安装；选过「手动」的会被保留（289033df0）。

## 修复

- DeepSeek 只输出思考而没有答案时，现在会提示并最多重试两次；仍无答案则明确报错，不再静默结束。关联 #14940。
- 修复在 1.x 里用过的会话提示「该待送达由更高版本写入，当前版本只能读取」的问题：队列里的消息既不能发送也不能删除（#14966）。

- Windows 上防火墙或安全软件拦截了本机入站连接时，Studio 不再等 21 秒后只报一个看不懂的 ERR_CONNECTION_TIMED_OUT，而是几秒内告诉你内核在运行但连不上它，并说明要放行 Reasonix Studio 和 reasonix-studio-host（#14970）。
- 提问卡里点一下下方的填写框，就会自动选上「其他 —— 自行填写」，不用再先点那个选项（3933dbed4）。
- 修正设置里「在输入框上方显示文件改动」的说法：这个「n 个文件已更改」标签实际显示在输入框的顶部，文案改成「输入框顶部」，和实际位置一致（7f4d00ca95）。
- 修复 Windows 上安装或更新被「Reasonix Studio 仍在运行」反复拦住的问题：机器上有别的应用留下的 `cua-driver.exe`（比如以管理员身份运行、或父进程已退出的孤儿进程）时，安装器会把它当成 Studio 本体，点多少次重试都过不去。现在只按名字匹配 Studio 自己的程序，不再匹配这个多个应用共用的驱动（f1bbea388）。
- 上下文已超过自动压缩线时点“立即压缩”，只要能腾出空间就会压缩，不再提示“无需压缩”（cee09e76b）。
- 修复在「设置 → 数据 → 存储」里更改位置时，每敲一个字符就在磁盘上留下一个半截目录的问题（比如输入 `D:\test\reasonix` 会留下 `r`、`re`、`rea` 等 8 个空目录）。现在预检只读：它在目标最近的已存在上级目录里验证可写、读取剩余空间，目录要等你点「开始迁移」后才创建；输入路径时也不再每个字符都请求一次，而是停顿后再检查（#14998）。
- 手动 /compact 在上次折叠之后只新增了少量内容时不再被拒绝；内容完全没变时仍会跳过（756c6159a）。
- Windows 启动更快（143 ms 降到 91 ms）；恢复和保存很长的会话时不再重复重放事件日志（63da66261、7c7e3ff99、868a14cad）。
- 渲染器管理的技能警告：TUI 和 Studio 的技能诊断改用渲染器管理的通知，包括斜杠补全时的首次和新增警告；#13656 的重复警告去重和非交互 stderr 输出保持不变。关联 #13655。
- 历史搜索在索引读不到来源时不再表现为「没有结果」，而是说明结果可能不完整（索引失败或仍在建立）。关联 #14947。
- ACP 的会话租约拒绝现在带机器码：`-32022`（被另一窗口持有）与 `-32023`（所有权无法证明），不再一律回 `-32600`/`-32603`。关联 #14948。

A `cua-driver.exe` left behind by another application (for example one running as administrator, or an orphan whose parent exited) was taken for Studio itself, so Retry could never succeed. Only Studio's own programs are matched by name now, not the driver other applications share (f1bbea388).
- Compacting by hand above the automatic trigger now folds whenever it frees space, instead of saying there is nothing to compact (cee09e76b).
- Typing a new location under Settings > Data > Storage no longer leaves a half-typed folder on disk for every keystroke (typing `D:\test\reasonix` used to leave `r`, `re`, `rea` and so on as eight empty folders). The check is now read-only: it proves the nearest existing parent is writable and reads its free space, and the folder is only created when you start the move, and typing no longer asks for a check on every character, only once you pause (#14998).
- A manual /compact is no longer refused when only a little was added since the last fold; an unchanged context is still skipped (756c6159a).
- Windows starts faster (143 ms down to 91 ms), and resuming or saving a very long session no longer replays the event log (63da66261, 7c7e3ff99, 868a14cad).
- TUI and Studio skill diagnostics use renderer-managed notices, including first and new warnings during slash completion; the duplicate-warning filter from #13656 and non-interactive stderr output are unchanged. Refs #13655.
- History search no longer presents an unreadable source as no matches; it says results may be incomplete because the index failed or is still building. Refs #14947.
- ACP lease refusals now carry codes, `-32022` for a session held by another window and `-32023` for ownership that cannot be proven, instead of `-32600`/`-32603`. Refs #14948.

## Removed

- Removed the absolute-size compaction limit, the threshold controls in Settings and the draggable fold handle in the context panel (7e1cdccb8).
- A fold no longer elides retained failure output and no longer makes an extra model call to choose which lines to keep (7e1cdccb8).
- Removed `task`, `fleet`, `parallel_tasks`, background sub-tasks, steering, `continue_from`, isolated worktrees and best-of-n (ad2c96347).
- Removed completion criteria, delivery receipt cards, readiness checks, the review gate and baseline checks (b364c1693).
- Removed missing-reasoning detection (be5c98c74).
- Removed `--fail-on-unverified` and `agent.host_verification`; old configs carrying them still load (8c785fa4b).
- Removed "guidance to a running sub-agent" from Settings (ad2c96347).
- Removed `task_cost_budget`, `task_time_budget_minutes` and `task_token_budget`: a task is no longer stopped by what it spends (a341d5615).
- Old configs carrying these keys are cleaned on start with a one-time notice (a341d5615).
