本版新增可自定义的对话宽度百分比，调整设置页与安装升级的体验，并修复 Windows 沙箱下 Git Bash 不可用等多处问题。

## 新增

- 「外观 → 尺寸 → 行宽」新增自定义百分比，可在 30–100% 之间按 1% 调整，对话与输入框一起生效，不影响已有预设。关联 #14649。

## 变更

- 设置页顶部的标题块（分类名、设置项数量）去掉了，导航已标明位置，第一张卡片直接出现在页面顶部。关联 #14625。
- 已安装的程序位于项目文件夹内时，「用其他程序打开」会列出它并标明原因，悬停可看是哪个文件夹，不再悄悄消失。关联 #14627。
- 安装升级时 Studio 还在运行，安装程序会连同内核一起关掉，必要时请求一次管理员权限；仍关不掉就用中文说明怎么退出。修复 #14658。
- 设置里的「图形渲染」从「外观与主题」页移到「窗口与性能」页，和其他与占用相关的选项放在一起。修复 #14719。
- 普通目录会话不再显示顶部的「原目录」徽标，独立工作树统一显示「独立工作树」并补充目录说明。关联 #14619。

## 修复

- Windows 开启沙箱后 Git Bash 每条命令都报「couldn't create signal pipe」；现在 Git Bash 在沙箱下起不来时，会话自动改用 PowerShell 并说明原因。修复 #14713，关联 #14714。
- 设置里主按钮（编辑模型后的「保存」、「新建预设」、「加入 QQ 群」）的文字与底色几乎同色、看不清的问题。修复 #14679。
- 输入框下方的执行权限、模式、模型、强度菜单展开时，不再被上方的计划条盖住一截。修复 #14720。
- 对话里「执行过程」一行的字号与同级的「思考」一行统一。修复 #14682。
- 设置按钮高度对齐、重命名对话框字体统一，项目栏的「添加项目」在长列表滚动时保持可点。关联 #14600、#14601、#14607。
- 恢复会话时，纯图片的一轮不再消失，终端会显示「附有 N 张图片」。关联 #14716。
- `reasonix doctor catalogs` 不再对记录过失败的目录打印 `ok`，而是显示 `failed` 或 `degraded`。关联 #14549。
- 会话租约无法证明时不再谎称被占用：密钥擦除拒绝改写并以错误退出，会话与任务列表显示 `unknown`。关联 #14727。
- 以 `..` 开头的根目录名现在按仓库内路径判断 gitignore。关联 #14734。
- 后台子任务的用量保留启动时的 Goal 归属，嵌套委派继承原归属；子任务恢复拒绝无法识别的持久化状态。关联 #14025。

## New

- Appearance → Size → Line width has a custom percentage, 30–100% in 1% steps, applied to the transcript and composer together; the presets are unchanged. Refs #14649.

## Changed

- The title block at the top of each settings page (section name and setting count) is gone; the navigation already shows where you are. Refs #14625.
- An installed program inside a project folder is listed in "Open with" as unavailable, with the reason and folder on hover, instead of silently missing. Refs #14627.
- During install or upgrade the installer closes a running Studio with its kernel, asks once for administrator permission if needed, and says how to quit by hand. Fixes #14658.
- "Graphics rendering" moves from the Appearance and theme page to the Window and performance page, next to the other options that affect resource use. Fixes #14719.
- Ordinary sessions no longer show the Local checkout header badge; isolated worktrees use one neutral label with explanatory tooltips. Refs #14619.

## Fixed

- With the Windows sandbox on, every Git Bash command failed; a sandboxed session now uses PowerShell and says why when Git Bash cannot start there. Fixes #14713, refs #14714.
- Primary buttons in Settings (Save after editing a model, New preset, Join the QQ group) no longer draw their label in almost the same colour as their fill. Fixes #14679.
- The permission, mode, model and effort menus under the composer are no longer partly covered by the plan bar above them. Fixes #14720.
- The "Execution" row in a conversation uses the same text size as the "Thinking" row at the same level. Fixes #14682.
- Settings button heights line up, the rename dialog uses the shared type styles, and the project header's Add project stays reachable while a long list scrolls. Refs #14600, #14601, #14607.
- A restored transcript no longer drops a turn that was only an image; the terminal says "N image(s) attached". Refs #14716.
- `reasonix doctor catalogs` no longer prints `ok` for a catalog that recorded a failure; it reports `failed` or `degraded`. Refs #14549.
- When a session lease cannot be proven, the secret scrub refuses to rewrite and exits non-zero instead of claiming the lease is held; listings show `unknown`. Refs #14727.
- A root name starting with `..` is judged as inside the repository for gitignore. Refs #14734.
- Background children keep the Goal that started them for usage accounting, nested delegation inherits it, and subagent continuation refuses unrecognised persisted states. Refs #14025.
