## 修复

- 2.53.0 里放大后的设置窗口，头部的收起、关闭、最小化、最大化按钮和搜索框点不动；现在都可以点击。修复 #14596。
- 语义路由用量在路由前就绑定根预算，计入规划与执行共享的软额度，保留缓存决定和任务边界。关联 #14595。

## Fixed

- In 2.53.0 the enlarged settings window's header buttons (collapse, close, minimise, maximise) and search field did not respond; they do now. Fixes #14596.
- Semantic routing usage is bound to the root budget before routing, counting in the soft limit shared by planning and execution, with cached decisions and task boundaries kept. Refs #14595.
