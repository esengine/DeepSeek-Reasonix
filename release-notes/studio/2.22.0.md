本版加强了项目配置的安全边界：仓库自带的配置只能收紧你的设置，项目声明的程序首次使用前需要你批准。同时新增 OpenAI Pro 模式、更完整的推理档位、四个一键服务商预设、长时间无进展提示和输入框草稿保存。

## 新增

- 在 GPT-5.6、GPT-6（OpenAI Responses 接口）上可以在推理强度菜单里打开 Pro 模式，只对当前会话生效，会消耗更多 token (#11194)
- 推理档位覆盖 GPT-5.6、GPT-6 和通义 Qwen3.8 的完整档位，菜单里选的档位会原样发给模型 (#11166)
- 新增 OpenRouter、OpenAI、Gemini 和火山方舟 Coding Plan 四个一键服务商预设 (#11193)
- 连续多轮没有可观察的进展时，输入框上方会给出提示，可以直接停止；阈值在「设置 → 会话」里调整 (#11160)
- 模型反复输出同一段文字时，输入框上方会给出提示，默认不打断也不改动对话 (#11183)
- 输入框里没发出去的文字会按会话保存，刷新页面或重新打开会话后恢复 (#9580)
- 可以在用户配置 `[tools.shell.env]` 里为 bash 工具预设环境变量 (#11163)
- 新增技能编写指南 `docs/SKILLS.md` (#11191)
- 模型服务设置里可以按模型单独设置推理档位，同一个中转接入下不同厂商的模型各用各的档位 (#11192)
- 命令行界面可以在用户配置里设置 `ui.commandmode = "vi"`，开启 vi 命令模式 (#11074)
- 工作台资源管理器新增「显示隐藏文件」按钮，默认关闭；版本库目录和 node_modules 始终不显示 (#11203)

## 变更

- 项目的 `reasonix.toml` 和 `.reasonix/settings.json` 只能让沙盒、权限和审批设置更严格，不能再放宽 (#11208)
- 项目声明的钩子、语言服务器、模型服务商、shell、ripgrep、浏览器等程序，首次使用前需要你批准；声明或相关文件变化后会再次询问 (#11208)
- 在项目里选择的「总是允许」改为保存在你的 Reasonix 主目录，不再写进仓库 (#11208)
- 沙盒可写目录在会话中保持首次授权时的位置，被替换成链接后不再授予写权限 (#11208)
- 更新下载并校验完成后由你决定何时重启，有任务在运行时会先提示；只有主动回退才会固定版本 (#11196)
- 更新没有生效时会说明原因，并给出完整安装包的下载链接 (#11196)
- 内置浏览器面板只在真正被遮挡时才暂停，并显示网页的最后一帧，不再误判页面被遮住 (#11198)
- MCP 服务向你提问时，系统通知会注明是哪个服务在问，并截短过长的内容 (#10950)
- `/memory recall` 分别列出因条数上限和字数预算而省略的记忆 (#11170)

## 修复

- 手机在同一网络直连时，工作台里的文件可以正常打开，窄屏下文件列表和文件内容轮流显示 (#11205)
- 手机直连长时间使用后卡住、切换不了会话的问题：连续收不到心跳时会自动重连并接着接收 (#11207)
- 文件列表开着时，关掉最后一个标签不再收起整个工作台 (#11204)
- 去掉速度指示前面多余的仪表盘图标 (#11202)
- 中等宽度下输入框工具栏溢出、发送按钮压住推理强度选择器的问题 (#11159)
- 点击网页元素时误报被其他元素遮挡的问题 (#11195)
- OpenAI 预设改走 Responses 接口，GPT-6 调用工具不再出错 (#11199)
- 英文界面下回退菜单的范围标签显示为中文的问题 (#11179)
- 记忆索引不可读时，恢复归档和迁移旧记忆会先报错，不再留下写了一半的状态 (#11167, #11172)
- `--continue --copy` 在没有历史会话时改为直接开始新会话 (#10945)

## 升级须知

- 项目声明的程序需要批准一次：在项目目录运行 `reasonix trust` 查看，`reasonix trust --yes` 批准；钩子也可以在钩子设置页批准 (#11208)
- 同一仓库的每个工作树、每个其他文件夹都需要分别批准 (#11208)
- `tools.shell.path`、`tools.search.rg_path` 和浏览器路径不能再指向工作区、临时目录或工具链缓存里的程序，请改为已安装的程序 (#11208)
- 只指向未批准项目服务商的模型设置会回落到你自己的设置；项目里不再生效的设置会在加载时以警告列出 (#11208)
