本版新增项目栏「最近」跨项目找会话、每日定时深色模式和可关闭的输入框提示，并修复从旧版找回会话全部被跳过、更新失败后无法下载完整安装包等多处问题。

## 新增

- 项目栏新增「最近」：按最近活动时间跨项目列出会话，完整分页、可搜索；点选后定位到所属项目并打开会话，也可选择远程环境。关联 #14319。
- 「外观 → 明暗」新增「定时」模式：每天按本机时间切换深色，默认 20:00 到次日 07:00，可跨午夜；桌面窗口的边框和底色同步变化。只有选择它时才生效。关联 #14699。
- 「外观 → 会话显示」新增「输入框提示」开关：可隐藏输入框里的任务和排队占位文字，默认显示，只保存在本机。关联 #14759。
- 文档：使用指南新增跨项目任务派发的完整流程。关联 #14603。

## 变更

- 浏览器工具的说明现在提示模型读静态网页时用 web_fetch、用完关闭标签，避免一轮留下十几个页面。修复 #14737。
- 设置里「快捷键」页的卡片顺序调整：「Esc 停止任务」紧跟发送相关设置，全局快捷键和按键表放在后面。关联 #14789。

## 修复

- 从旧版找回会话时，目标文件夹里残留没有对话文件的过期索引，会让所有会话被反复跳过、一个都导入不了；现在会清掉它们并正常导入，侧栏里的未导入列表也能显示。修复 #14804。
- 更新失败后提示里的「下载完整安装包」改为用系统浏览器打开发布页，不再落到被设置页盖住的内置浏览器里。修复 #14775。
- 侧栏里「早先版本」和「恢复副本」那一行，悬停或键盘聚焦时重新显示删除按钮 ×。修复 #14703。
- 删除配置来源文件夹后，仍可移除残留的 MCP 服务；配置损坏时会保留服务，并指出无法解析的配置文件。关联 #14738、#14739。
- 连接远程主机（如 WSL）时，读取会话列表、删除、置顶或归档不再每次都重新建立连接；连接在最后一次操作后保留 45 秒。修复 #14745。
- 从对话分叉出的分支会继承源会话的上下文压缩简报，打开后继续在压缩视图上工作。关联 #14768。
- 同一项目里并行启动的隔离任务不再偶尔因 Git 报 failed to read …/commondir 而失败。关联 #14805。
- 隔离结果应用、委派续跑和用量预算：应用时拒绝被换成目录链接的父目录，并发续跑不再重复创建转录副本，已知用量计入根预算，恢复任务时文件权限变化也会使旧证明失效。关联 #14025。

## New

- The project header gains "Recent": conversations across projects by last activity, paged and searchable; picking one locates its project and opens it, also on remote hosts. Refs #14319.
- Appearance → Light and dark gains a "Scheduled" mode: dark during a daily local-clock range (default 20:00–07:00, overnight allowed); the window frame follows. Opt-in. Refs #14699.
- Appearance → Conversation display gains a "Composer hint" switch that hides the task and queue placeholder text; on by default, remembered on this machine. Refs #14759.
- Docs: the guide now walks through cross-project task dispatch. Refs #14603.

## Changed

- The browser tool now tells the model to read static pages with web_fetch and to close tabs when done, so a turn no longer leaves a dozen pages open. Fixes #14737.
- On the Shortcuts settings page, "Esc to stop" now sits right after the send settings, with the global shortcut and the key table after it. Refs #14789.

## Fixed

- Recovering older sessions no longer skips every conversation because of stale indexes with no transcript in the destination; they are cleared and the import proceeds. Fixes #14804.
- After a failed update, "download the full installer" opens the release page in the system browser instead of the in-app browser behind the settings sheet. Fixes #14775.
- An earlier version or recovery copy in the sidebar shows its delete × again on hover or keyboard focus. Fixes #14703.
- Stale MCP servers can be removed after their source folder is deleted; a malformed config names the file and keeps the servers. Refs #14738, #14739.
- On a remote host such as WSL, listing, deleting, pinning or archiving sessions no longer reconnects every time; the link is held 45 seconds after the last action. Fixes #14745.
- A fork inherits its source's compacted context, so the branch continues on the compacted view. Refs #14768.
- Isolated tasks started in parallel in one project no longer fail now and then with Git's "failed to read …/commondir". Refs #14805.
- Isolated results and delegation: applying refuses a parent directory swapped for a link, parallel continuations no longer duplicate copies, and known usage counts toward budgets. Refs #14025.
