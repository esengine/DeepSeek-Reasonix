DeepSeek 视觉模型支持、长会话每轮开销与会话长度解耦，以及三处「当前选中的是哪一个」的可读性修复。自 2.2.0 起 30 个提交。

## ⚠️ Windows 用户：本次需手动安装

当前版本为 **2.2.0 或更早**时，自动更新会在最后一步失败，请**手动下载安装包覆盖安装**。

原因：Studio 安装在 `Program Files` 并写入 HKLM，安装包因此声明需要管理员权限，而旧版用于启动它的调用无法启动此类程序——下载与校验均完成，卡在执行环节。修复包含在本版中，因此仅对**从本版往后**的升级生效。装上 2.3.0 后自动更新会正常弹出 UAC。

macOS 与 Linux 不受影响。

## 新增

**DeepSeek 视觉模型**
- `deepseek-v4-flash-vision-exp` 可直接使用。此前 Studio 将整个 DeepSeek 端点视为纯文本，现改为按模型判定：同一连接下视觉模型可勾选「读图」，其余两个不可（端点自身会拒绝）。
- 已安装用户的模型列表冻结在配置文件中，本版启动时自动补入——仅限**仍为出厂默认**的连接，自行策展过的列表不作改动。
- 该模型同时支持工具调用与思考档位，可作为主模型使用。
- 主模型不支持读图时，提示会点名可用模型并指出配置位置（设置 › 模型 › 分工），或明确告知无任何模型支持读图。此前无论何种情况均提示「改由委派的子代理处理」，而未指定「看图」角色时图片实际在发送前已被丢弃。
- 「看图」角色不会自动指定——那等于代替用户决定将图片与账单发往未经选择的实验模型。

## 性能

- **每轮开销不再随会话长度增长**。折叠（压缩）的目的是让模型不必重读旧历史，但每轮仍会复制整份记录以读取末尾数条。2 万条消息的会话：每轮 2.3ms / 14MB 降至 0.45ms / 3.8KB，且 100 条与 2 万条耗时相同。
- 单轮请求组装成本从 2.3ms 降至 3.3µs。
- 多项目共用同一份系统提示前缀缓存，切换项目不再各占一份。

## 界面

- **`/` 与 `@` 菜单中键盘选中项的高亮强于鼠标悬停**。此前相反：选中仅有 6px 圆点，悬停为整行底色——鼠标停在列表上时，最醒目的恰好是回车不会选中的那一行。键盘接管时隐藏悬停态，鼠标移动后恢复。
- **模型列表支持搜索与直接填写**。中转站返回数百个仅差日期后缀的名称时，编辑面板此前逐行铺开（高度超过四屏，保存按钮在视口外）。搜索框与「填写列表中没有的名称」为同一输入框，已勾选项排在最前。
- **MCP 连接失败不再撑坏右侧度量栏**。端点返回的错误文本长度不受控制，此前被放入为「耗时」设计的槽位，导致服务名被压至 0 像素、整栏横向溢出 451px。现改为名称一行、原因一行（最多两行），连接失败以左侧红条标识。

## 修复

本批统一改为**按错误身份判定，而非匹配错误文本**——文本匹配在切换语言或供应商后即失效。

- 流式响应中断在发生处即被命名，不再回溯推断文本含义。
- 跨盘移动文件、启动步骤失败、插件迁移、会话停止改为读取错误码或哨兵值。
- HTTP 层每条拒绝携带点分编码；前端无法表述的编码将导致构建失败。
- 「本次改动未经任何验证」的提示会附上已执行但未被识别为检查的命令。
- 参数名错误可定位到具体层级，包括数组元素内部。

## 其它

- 最大化图标跟随窗口实际状态，而非最后一次点击。
- 新接入的订阅者不再被误判为「丢失了一段事件」。
- 更换状态目录时，写入其下的数据一并迁移；迁移中断（清单未完成即开始搬运）不会丢失文件；迁移面板会列出未取到的项及其位置。
- Studio 打包时 `hdiutil` 失败会输出原因，不再仅返回退出码。
- 更新目录地址由各发布线自行声明，不再回落到默认值（该默认地址不发布任何内容）。
