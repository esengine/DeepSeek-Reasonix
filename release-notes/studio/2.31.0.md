本版首次提供原生 Windows ARM64 版 Studio，任务运行时可让电脑保持唤醒，反馈面板新增等级显示，并修复链接标签、压缩、队列重试、钩子放行等问题。

## 新增

- 首个原生 Windows ARM64 版：发布页提供 ARM64 安装程序和便携 zip，外壳与内核均为 ARM64，不再靠 x64 模拟；ARM64 机器按自己的平台更新，增量更新暂只对 x64 提供，会下载完整安装包 (#12272, #12286, #12270)
- 任务运行期间让电脑保持唤醒：设置的外观页「窗口」新增本机开关，默认开启，只阻止系统空闲睡眠，合上盖子由系统决定，后台作业不计入 (#12283)
- 我的反馈显示已获得的等级、已采纳数、距下一级的进度和当前限额；提交或回复被限流时说明哪个时间窗用完及何时重置，`/feedback list` 同样显示。仅作显示，目前不改变任何限额 (#12319)
- 已收到的反馈被维护者审阅时，反馈面板显示「审核中」 (#12260)
- 反馈对话框新增「铺满窗口」按钮，较长的维护者回复不再挤在窄列里 (#12111, #11575)
- 模型目录加入 MiMo V2.6（pro、flash、pro-ultraspeed），未改动过的 V2.5 预设自动迁到 V2.6；小米将于 2026-10-21 停用 V2.5 (#12262)
- 设置的子代理行会指出哪些 `subagent_models` 条目优先于它，并提供「改回跟随这里」按钮；项目级条目只提示 (#12306)

## 变更

- 不再主动推送上下文占用警告：对话里不再出现「上下文已达压缩阈值」卡片，模型仍可用 `context_budget` 工具按需查询 (#12248)
- 终端界面 `reasonix tui` 首次交互运行时询问一次是否允许匿名使用统计；在 1.x 里回答过的不再询问，`DO_NOT_TRACK`、CI 和开发版不询问也不上报 (#12336)
- Studio 的每日匿名心跳失败后会退避重试，开着跨过 UTC 午夜会再发一次；在设置里关闭遥测后无需重启即停止发送 (#12333)
- 拦截类事件上的钩子无法执行（匹配正则无效、进程启动失败、载荷无法序列化）时，现在阻止该操作，不再当作没有钩子而放行 (#12261)
- 增量更新要下载的内容超过完整包一半时，直接下载完整包，不再先拉分块再失败重来 (#12247)
- 会话在等待提问或审批回答期间释放工作区写入占用，其他会话可以写这期间没人在写的路径 (#12298)
- 读取服务商模型列表的入口挪到添加模型输入框旁，标签和提示更明确 (#12279)
- 状态栏的子代理数只统计正在运行的，与后台任务数含义一致 (#12282)
- 运行中状态改为醒目的实心徽标，等待与空闲保持原样 (#12066, #12044)
- 浅色主题下警告、成功、错误色的文字改用对比度达标的文字色 (#12274)
- 在 Windows 上，位于配置工作区之外的网络共享路径（`\\host\share`），文件工具、内置浏览器和安装来源预览会在查找之前直接拒绝，拒绝提示写明原因 (f551c4bb6, 389cc40be)
- 内置浏览器对这类网络共享路径的拒绝代码由 `browser.url_refused` 改为 `browser.network_path` (389cc40be)
- 在 Windows 上，命令行里把网络共享路径当操作数的命令现在会请求批准，不再当作只读直接运行；已记住的前缀放行规则不再覆盖这类操作数 (040f77bde)

## 修复

- 压缩时摘要模型回的不是摘要（照常调用工具或继续干活）时，不再被当作摘要装入，该次压缩按失败处理；这只修了两个已查实的缺陷，压缩的其余问题仍在 #12309 跟踪 (#12322, #12308)
- 一个失败的调用不再把同一批并行调用的全部结果都留在压缩后的上下文里，压缩因此能缩到限额内；其余结果照常折叠 (#12317)
- 在内置浏览器里点链接时，新页面不再被切回代理的标签，也不再多出一个空白标签 (#12249, #12285)
- 在内置浏览器地址栏输入磁盘路径（如 `D:/x.html`）时按文件打开，不再当成以盘符为主机名的网址 (#12326, #12321)
- 停止或决定迟迟没有确认时，提示会区分内核忙、内核连不上和本窗口自己卡住，停止在内核报告空闲后即结束 (#12294)
- 状态栏余额随模型来源切换立即刷新，不再显示上一个来源的余额 (#12271)
- 暂停队列里「引导消息未被读到」的待发条目现在有「重试」按钮，不必撤回重发 (#12275)
- 在远程窗格里设置默认模型，现在记录在模型所属的那台机器上，并在失败时说明原因，不再静默无效 (#12301)
- 子代理继承的推理强度按它实际使用的模型解析，不再被映射到别的等级或让请求失败 (#12299)
- 可选扩展的辅助进程没在运行时，提示改为本地化的明确说明，不再显示被截断的英文 (#12281)
- 回合结束时，另一个终端界面里仍开着的提问或审批会随之关闭，输入框不再被卡住 (#12264)
- 终端输出被转存到文件后，bash 的会话数据提示不再像拒绝，并指引用 `read_file` 或 `grep` 读取 (#12297)
- 手机等触屏设备上，改写框和待发队列编辑框按回车换行而不是提交 (#12339, #12338)
- 切换连接后，主题导入的回执、文件夹路径和主题清单不再串到新连接上 (#12088, #12090)
- 安装来源检查拒绝 npx 会当作路径、标签或压缩包解析的 npm 包名（如 `@a/..`、`x.tgz`），也拒绝以点开头的 GitHub 属主和空路径仓库 (#11354)

## 升级须知

- 已安装 x64 版并在 ARM64 机器上运行的用户不会自动换成 ARM64 版：更新器按运行中程序的架构取包，需要手动下载一次 ARM64 安装程序 (#12286)
