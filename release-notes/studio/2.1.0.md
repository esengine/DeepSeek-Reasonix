> 这一版把界面里几处「明明在那儿却看不见、或者看见了也读不懂」的地方收拾了一遍：拖文件不再复制副本，收起面板的把手一直看得见，主机自己的话不再挤进对话。

## 拖进来的是位置，不是副本

- **任意文件或文件夹拖进输入框都能接住**。以前只认图片，拖一个 `.py` 或 `.pdf` 进去没有任何反应。
- **引用的是文件本来在的地方**，工作区里不再多出一份副本。这修掉的是「让它改一个文件，它改了副本还回报改好了」——现在它拿到的是那个文件本身。
- 工作区外的文件也能引用，路径带空格、带盘符都不再把引用截断。
- **拖歪了不会毁掉界面**：以前落在输入框以外，webview 会直接导航到那个文件，整个界面被文件内容替换，只能重开。
- 剪贴板和「添加图片」按钮仍然存字节——那两条本来就没有路径可用。

## 面板与分隔条

- **收起面板的把手静止时就看得见**：缝上一根短竖条，鼠标靠近变成箭头，收起后是边缘的一颗药丸。以前它是一个 45% 透明度的箭头，不悬停基本等于没有。
- **一个面板只有一个收起按钮**。标题栏里那个重复的去掉了（只在栏横过来、没有缝可抓的那一档保留）。
- 分隔条的拖拽热区现在正骑在接缝上，不再偏 1px。

## 界面说的话

- **主机对自己的汇报不再进对话正文**。像 `guardian enabled · model=…` 这种装配期的话，以前会以「agent 跑了个命令」同样的规格插进你正在看的那段对话；现在它归到轨迹，真出问题的警告落在输入框下方一条可关掉的横条里。
- **回合结束的验证回执默认不显示了**。它报告这一轮有什么没被验证——值得读，但每轮都来一次太吵。要看的话在开发者控制台 `localStorage.setItem('rx-turn-receipt','on')`；核对本身照跑，终端里也照样打印。
- 回执卡真显示时也能读了：分组标题、缺了什么、关于哪个文件，三种字面分得开；一条命令是等宽单行，不再把四十行 heredoc 铺成段落。
- 会话侧边栏里，**被外部程序改写留下的恢复副本折进它来自的那条对话**，不再各自占一行。

## 模型与扩展

- MCP 服务器在设置里会说明自己是什么、带了哪些工具；关掉的服务器也能从缓存里答。
- 服务端跑的 web search 会显示出来，出错时说的是服务端给的原因。
- Anthropic 兼容网关只收它自己声明过的 reasoning 字段。
- 插件的常驻进程崩了会重连，不再一直报 EOF。
- 钩子写成 shell 语法时会交给能跑它的 shell；坏掉的钩子会说是哪一个、该怎么办，而且只报一次。

## 已知限制

- **Windows 包仍未签名**，安装时会看到 SmartScreen 警告。
- 没有 windows/arm64 构建。
- 1.x 桌面版读的是另一份版本目录，不会自动升级到 Studio。
