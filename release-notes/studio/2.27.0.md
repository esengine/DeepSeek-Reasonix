本版修复 Windows 上内核因协程暴涨而崩溃的问题，让同一工作区里写不同文件的会话可以并行，并补强记忆迁移备份、递归删除保护、自动压缩失败说明，以及市场、主题、插件和 MCP 的大量使用细节。

## 新增

- 手机访问的局域网直连链接可以在用户配置的 `[serve] share_port` 里指定固定端口，不再每次随机；端口被占用时会明确提示 (#11568, #11540)
- 市场「我的包」每一行新增「发布新版本」，自动带入类型、名称、简介、仓库、标签和可见性，只需补来源 (#11566)
- 新增主题作者指南和可直接安装的纯主题示例 Paper Dawn，替换掉旧桌面时代的指南和含无效字段的模板 (#11578)
- 市场发布表单在名称或来源框里按回车即可提交；市场的种类、排序和浏览切换支持方向键，MCP 安装位置支持方向键与 Home、End (#11845, #11821, #11847)
- 扩展作者新增可安装的工具扩展示例、可运行的 stdio MCP 插件示例，以及本地测试和自定义宿主关闭的说明 (#11553, #11584, #11788)

## 变更

- 同一工作区里写入不同路径的会话现在可以并行，不再整个工作区排队等第一个写入的会话；同一路径、重叠目录和移动的两端仍会互相等待 (#11823, #11815, #11833)
- 旧版记忆文件在迁移到 V2 之前会先原样备份，迁移改写的内容不再无从找回 (#11857, #11846)
- 自动压缩失败时，卡片会说明具体原因（超时、摘要被截断、服务商出错、上下文已变化等），不再只写「这一轮什么也没折叠」 (#11869, #11838)
- 子代理继承的思考强度在执行模型不支持时自动退回该模型默认值，换回支持的模型后恢复；子代理指定与父会话相同的模型时沿用父会话强度 (#11269, #11841, #11268)
- 递归删除的目标不是工作区授权范围内的字面路径时，即使在自动或 YOLO 模式下也会被拒绝，模型会收到明确原因 (#11786, #11782)
- 只改动 `.md`、`.rst` 文档且工作区没有任何检查项时，不再要求先跑一遍验证命令 (#11780, #11776)
- 手机访问的互联网设备编号复用最小的空号，同一台手机重连不再变成「设备 3、4、5」 (#11879, #11855)
- 命令行的 `--compact-ratio` 接受 0 到 100 之间任意比例，例如 0.5，与配置文件一致 (#11854)
- 切换到已在使用的模型或思考强度时不再重建会话，切换更快 (#11546)
- 市场发布表单选择私有时，说明改为「仅自己可见、无需审核」，不再承诺审核后发布 (#11716)

## 修复

- Windows 上宿主因工作区快照遍历把协程和线程撑爆而崩溃，现在遍历受限，不再崩溃 (#11840, #11820)
- 删除保护不再因 Windows 8.3 短路径里的 `~` 把工作区外的删除误判为「目标不是字面路径」，现在会按越界目标拒绝 (#11866)
- 通过 SSH 连接远程时，引导阶段点取消会立刻中止，不再卡在打开会话 (#11622, #11619)
- 远程「从目录树打开」支持 Windows 盘符、UNC 和绝对路径，不再拼到远程主目录后面 (#11543, #11539)
- PowerShell 命令别名存在但无法启动时被跳过，并记录实际用的外壳，不再每条命令都报 `exit status 1` (#11504, #10633)
- 项目里的 MCP 条目不再丢掉用户禁用的工具，调用被禁用的工具会得到明确提示，空工具名不再被接受 (#11506, #11473)
- 第三方中转拒绝 `previous_response_id` 并返回 400 时，自动改发完整历史重试，不再反复报错 (#11803, #11797)
- 托盘菜单跟随系统语言，从访达或程序坞启动也不再回退为英文 (#11759, #11750)
- 身份服务不可达时，侧栏和账号面板一致显示「已登录」和错误，并提供重试与退出，不再弹出登录表单 (#11777, #11769)
- 界面大小不是 100% 时，会话和项目的右键菜单不再偏离点击位置或超出窗口底部 (#11729, #11727, #11773)
- 侧栏拖到很窄时文字不再挤在一起重叠，最小宽度提高到 232 像素 (#11731, #11723)
- 运行分析里点开一条记录，详情显示在被点的那一行下面，不必拖到列表最底部 (#11732, #11720)
- 安装文本插件后切换模型，插件的技能和代理、自定义技能目录不再丢失 (#11736)
- 回退对话后不再在工作目录留下 `.bak` 临时备份文件 (#11699)
- MCP 添加命令：复制的 `mcp add` 命令（含续行、绝对路径启动器）能被正确解析，空定义不再出现在粘贴预览里 (#11747, #11779, #11804, #11752)
- MCP 名称与传输：npx、uvx、Python、Node、Go 等启动方式生成的名字不再带版本号或选项值；只有路径里完整的 `sse` 段才判为 SSE，大小写不同的 HTTP 也能识别 (#11865, #11787, #11768)
- 需要认证的 MCP 服务选「仅此项目」安装后，不再被保存为全局启用 (#11749)
- MCP 检查输入在读取期间保持稳定，操作失败时显示当前的诊断信息 (#11805, #11809)
- 主题：导入期间禁用重复操作；同一地址重新导入后图片立即更新；同时选 ZIP 与散文件时给出明确提示；读取失败时保留已有主题并可重试预览 (#11810, #11811, #11814, #11812, #11813)
- 市场：安装失败可重新预览并保留失败项，登录失效时点赞回到登录入口，连续点提交审核不再重复提交，确认与发布反馈支持读屏 (#11784, #11781, #11580, #11807, #11800)
- 插件、MCP 和技能清单读取失败时显示错误和重试按钮，不再当成空列表；更新期间的禁用导航变灰，插件开关保留重载结果 (#11796, #11477, #11819)
- 插件安装失败后可通过重新预览恢复；空插件列表的指引改为设置 > 扩展 > 已安装 > 插件包 > 添加 (#11651, #11696)
- `plugin doctor` 会检查已声明的代理目录，目录被删或被换成文件时报错；声明成文件的技能、代理、命令和提示目录会给出警告 (#11745, #11689, #11790)
- 已安装插件换版本后，重复的贡献行和兼容性提示行不再残留旧内容；中文名技能显示为 `/包名:审查` 而不是 `SKILL` (#11737, #11733, #11740)
- 导出插件包时，数字开头的 MCP 服务名和残缺的 `$NAME` 引用不再让收件人填写的值失效 (#11725, #11738)
- 扩展 SDK：交互结果需显式确认，取消的请求不再写出，关闭回调和通知队列更稳，工具参数缺失与响应格式会校验 (#11850, #11802, #11798, #11793, #11828, #11835)
