本版开始建设 Studio 的扩展生态：设置里新增社区市场，可以浏览、安装和发布技能、插件、MCP 服务器与主题；登录账号后还能把配置备份到云端。同时加强了本地服务、宿主 git 和沙盒的安全边界。

## 新增

- 设置 → 扩展新增「发现」页，可浏览社区市场并安装技能、插件和 MCP 服务器；只安装经过审核、绑定了内容摘要的版本，内容与审核时不一致会拒绝安装 (#11107)
- 登录后可以从 Studio 直接发布技能、插件、MCP 服务器和主题到社区市场，并查看每次提交的审核状态 (#11112)
- 发布时可选「仅自己可见」：私有包不进入公开列表，发布者本人无需等待审核即可安装自己的包 (#11135)
- 市场支持赞和踩，每人每个包各一次；列表按下载、赞踩等综合权重推荐排序 (#11128, #11129, #11130)
- 登录账号后可选择把配置备份到云端，并在其他电脑上恢复；可按类别勾选设置、扩展、记忆和自动化，API 密钥默认不备份；未登录时不提供此功能 (#11109)
- 备份用你设置的口令加密后才上传，服务器读不到内容；恢复时会运行程序的条目需你逐项同意，审批模式、权限和沙盒设置不会被恢复 (#11109)
- 在输入框里选择技能或子代理会插入标签，而不是纯文本；行中任意位置输入 `/` 都能唤出菜单 (#11149)

## 变更

- 市场列表每行最多两行，窄屏下截断而不溢出；新增「只看可安装」筛选 (#11126)
- 本地服务默认要求身份验证，审批等改变状态的请求必须带启动令牌；`[serve]` 设置只从用户级配置读取 (#11110)
- 宿主自己运行的 git 命令不再执行仓库配置的程序；沙盒内的命令不能改写工作区仓库的 `.git/config` 和 hooks（macOS、Linux） (#11110)
- 计划里写明要改的文件而这一轮没有任何改动时，不会判为完成，并提示可选的三种处理方式 (#11095)

## 修复

- 手机上模型和推理强度选择器被发送按钮挡住、点不开的问题 (#11120)
- 手机加入正在运行的会话时，正确显示运行中状态 (#11133)
- Windows 安装在 Program Files 或与更新缓存不同的磁盘时，不再尝试无法完成的增量更新，改用完整更新 (#11121)
- DeepSeek 的 Anthropic 接口在思考模式下调用工具时不再报 400 错误 (#11061)
- 用量面板的金额与会话使用同一币种 (#11154)
- 提问卡片的标题在英文界面下正确翻译 (#11102)
- 直接打开 studio.reasonix.io 时跳转到设备选择页，而不是提示连不上内核 (#11098)
- 记忆文档或索引读取失败时报错，不再把原有内容当作空文件覆盖 (#11142, #11143)
- 恢复已归档的记忆时执行与保存时相同的校验 (#11148)

## 升级须知

- 本地服务现在默认要求身份验证。如果你用脚本或其他工具直接调用 `reasonix serve`，需要带上启动令牌 (#11110)
