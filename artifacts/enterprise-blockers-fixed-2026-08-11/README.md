# intelifar 小微企业版阻断修复与体验验收

验收时间：2026-08-11  
真实 UI：http://127.0.0.1:4388/

## 本轮结论

两项发布阻断已经关闭：

1. 只读成员不能再读取或导出全空间审计台账；后端接口、导航入口和页面跳转均执行同一权限边界。
2. 只读成员不能接入文档；服务端拒绝时，界面不会提前显示成功、不会生成假的任务编号，也不会跳入伪造进度。

同时完成以下重点优化：

- Wiki 没有内容变化时禁止创建新版本；修改后先列出变化区域，再允许发布。
- “新建资产”统一收口为“从文档提取资产”，保证资产有原文依据。
- Agent 的内部来源编号改为“查看相关资产 / 查看原文依据”等业务按钮，内部编号只保留为辅助信息。
- Agent、资产、Wiki、风险与系统页移除首屏供应商名、英文运维标签和难懂的技术提示，改用业务语言。
- 风险工作台明确只提供待人工核查的线索，不声称已经自动完成脱敏。
- 分享撤销说明明确为“阻止后续访问”，不承诺召回已加载或已复制内容。
- 系统技术拓扑默认折叠；常用业务服务状态优先展示。
