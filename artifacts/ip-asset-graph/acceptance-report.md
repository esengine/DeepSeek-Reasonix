# intelifar IP 资产关系全景验收报告

- 验收日期：2026-08-10
- 目标版本：单实例小微企业 / 售前 MVP
- 结论：PASS
- 综合评分：99.0 / 100

## 已交付能力

- 发布资产自动投影为 SQLite 图节点、别名、关系和关系证据，发布快照仍作为审计真相。
- 支持依赖、实现、派生、替代、引用、组成、相似和冲突八类受控关系。
- 模型发现关系默认为待复核；内容维护者可在真实 UI 中查看详情并确认或拒绝，变更与审计原子提交。
- 图搜索会返回直接匹配及一至两跳已确认关系，并给出路径解释。
- 权限在遍历前裁剪；Viewer 无法通过图、搜索、直接资产 URL 或关系 URL推断隐藏节点。
- 全景 UI 使用深色语义神经网络，支持 35%–240% 锚点缩放、空白拖拽、双指触控、三级信息密度、搜索筛选、一跳聚焦、关系清单和键盘访问。
