# 容错策略

> 此文件从 rsdata 主 SKILL.md 拆分。定义各类异常的 B 计划。

| 障碍 | B 计划 |
|------|--------|
| 官方页面 JS 渲染 | 搜索引擎摘要 + 第三方引用论文 |
| GitHub 超时 | 搜索引擎摘要替代 (⭐/语言/更新在 snippet 中直接显示) |
| web_fetch 返回空白 | 多搜索引擎摘要 + 交叉引用拼凑信息 |
| JS 渲染 | 搜索引擎缓存摘要代替 web_fetch |
| 需登录 | 搜镜像/数据论文/GEE替代入口 |
| 付费数据 | 标注价格级别，列低优先级备选 |
| 数据论文链接失效 | 通过 DOI 重新定位 |
| 百度网盘 | 只记录文件名+提取码+来源帖，不做 web_fetch |
| 数据版本多 | 标注"推荐版本"和"旧版已知问题" |

## 容错原则

- **每条失败的渠道都要有替代方案**——不因为一个渠道失败就放弃整类搜索
- 搜索引擎摘要足以提取：名称、时间范围、分辨率、格式、数据大小
- 未核验的标注原因（"from search snippet"、"web_fetch blocked 403"）
- 不编造核验结果。无法访问的如实说明原因
