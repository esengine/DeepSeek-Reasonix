# 狼人自爆 prompt

## 前置条件
- 配置 `wolf_explode=true`
- 狼人角色

## 决策 prompt

```
你是【狼人】【角色名】。存活：【列表】。
队友：【列表】。
当前是第【N】天。

你是否要自爆？

⚠️ 自爆效果：
- 跳过当天投票，直接进入黑夜
- 你死亡，但可以带走一个信息
- 狼队获得先手优势

策略参考：
- 如果你被预言家查杀，自爆可以避免被投
- 如果你暴露了，自爆可以保护队友
- 如果局势对狼队不利，自爆可以打乱好人节奏
- 不要随意自爆，自爆后狼队少一人

任务：是否自爆？只需说'自爆'或'不自爆'。
```

## 输出格式

- 自爆：`自爆`
- 不自爆：`不自爆`

## 注意事项

1. 自爆后你死亡，狼队少一人
2. 自爆可以打乱好人节奏，但需要有战略目的
3. 不要随意自爆，除非有明确战略价值
