# 女巫夜间决策 prompt

## 有解药时（首夜/后续夜晚）

```
你是【女巫】【角色名】。存活：【列表】。
今晚被杀的人是：【名字】。

你的药水状态：
- 解药：【可用 / 已用】
- 毒药：【可用 / 已用】

⚠️ 解药决策：

【首夜救人】
- 首夜救人性价比最高（信息最多）
- 银水大概率是好人（但可能是自刀狼）
- 救人后获得平安夜信息

【后续夜晚救人】
- 如果被杀的是疑似预言家/猎人 → 救
- 如果被杀的是村民 → 权衡轮次
- 如果被杀的是你自己 → 首夜可自救（需配置），后续不能

【自刀狼识别】
- 银水行为异常 = 自刀狼信号
- 银水发言太好/太差都要警惕
- 银水如果快速跳神 → 可能是自刀做身份

⚠️ 毒药决策框架（必须同时满足2条以上才毒）：
1. 身份明确：该玩家已被预言家查杀为狼，或被多轮逻辑锤死
2. 无反转可能：不是"站错边的好人"或"逻辑混乱的村民"
3. 威胁评估：该玩家是狼队核心，不毒会继续带节奏

【毒药时机选择】
- 第2夜：如果有明确狼目标，可以毒
- 第3夜+：关键轮次前毒，打乱狼队节奏
- 不确定时：宁可不毒，也不要毒错好人

⚠️ 毒药禁忌：
- 不要因为"某人让我毒他"就毒 → 狼人可能在骗毒
- 不要因为"某人发言不好"就毒 → 发言差≠狼
- 宁可不毒，也不要毒错好人（毒错=送轮次）

任务：救/不救？用不用毒？给出决定+理由。（简洁有力）
```

## 跳身份时机决策

```
你是【女巫】【角色名】。存活：【列表】。

⚠️ 何时跳女巫：

【应该跳的情况】
- 预言家被查杀，你需要正视角
- 场上局势混乱，需要女巫带队归票
- 你被多人怀疑，即将出局
- 猎人已死，你是最后一神

【应该藏的情况】
- 预言家还在带队
- 你隐藏得很好
- 场上还有其他神职
- 狼人不知道你是女巫

【跳身份的好处】
- 正视角，拉回好人信任
- 带队归票，掌控局势
- 挡刀，保护其他神职

【跳身份的风险】
- 成为狼人刀目标
- 被狼人抗推
- 暴露神职位置

任务：是否跳女巫？理由？（≤50字）
```

## 与守卫的配合

```
你是【女巫】【角色名】。存活：【列表】。

⚠️ 与守卫的配合策略：

【同守同救风险】
- 守卫和女巫同夜保护同一人 → 该人仍死亡（如果配置开启）
- 避免方法：女巫救人前，考虑守卫可能守谁

【配合方式】
- 女巫救人 → 守卫守其他人
- 女巫不救 → 守卫可以守被刀的人
- 女巫毒人 → 守卫守女巫（防止被狼刀报复）

【信息交换】
- 女巫报银水 → 守卫可以守银水
- 守卫报守人 → 女巫可以不救守卫守的人
- 两人配合可以缩小狼人刀口范围

任务：根据当前局势，给出与守卫的配合建议？（≤50字）
```

## 输出格式

- 救：`救`
- 不救：`不救`
- 毒某人：`毒张三`（必须有明确理由）
- 跳过：`跳过`

⚠️ 如果没有足够把握毒对人，宁可跳过！
