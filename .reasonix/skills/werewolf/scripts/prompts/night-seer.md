# 预言家夜间决策 prompt

## 首夜查验决策

```
你是【预言家】【角色名】。存活：【列表】。
第1夜，你需要决定查验谁。

⚠️ 首夜查验策略：

【查验优先级】
1. 疑似狼面大的人 → 验出查杀直接拍
2. 中置位划水牌 → 验出身份帮助判断
3. 焦点位 → 验出结果影响局势
4. 不验边角位 → 位置学无意义

【查验理由】
- 验疑似狼：直接拍查杀，压缩狼队空间
- 验划水：划水可能是深水狼，验出身份帮助判断
- 验焦点：焦点位可能是神职或狼，验出结果影响大

【博弈层次】
- L1：验你怀疑的人 → 狼人知道你会验谁
- L2：验狼人觉得你不会验的人 → 出其不意
- L3：反向验人 → 验你以为是好人的人

任务：查验谁？理由？（≤50字）
```

## 后续夜晚查验决策

```
你是【预言家】【角色名】。存活：【列表】。
你已查验：【记录，如 A=好人，B=狼人】。

⚠️ 后续查验策略：

【查验优先级】
1. 未验过的疑似狼 → 继续压缩狼坑
2. 站边摇摆的人 → 验出身份帮助归票
3. 被多人保的人 → 验出身份判断是否狼同伴
4. 不重复验同一个人

【查验理由】
- 验出查杀：直接拍，考虑是否留一轮观察
- 验出金水：用来带队、归票、组狼坑
- 验出好人：帮助判断局势

任务：查验谁？理由？（≤50字）
```

## 应对狼首跳决策

```
你是【预言家】【角色名】。存活：【列表】。
场上对跳：【悍跳狼名字】跳预言家，发了【查杀/金水】给【名字】。

⚠️ 应对狼首跳策略：

【后置位起跳（狼先跳）】
- 承认有对跳，对比发言差异
- 打爆狼点：查验逻辑、发言漏洞、视角差异
- 报你的查验，拉好人站边

【前置位起跳（你先跳）】
- 正常报查验，不要慌
- 强调你的查验逻辑和视角
- 拉好人站边，归票悍跳狼

【警徽流策略】
- 2+1公式：一个警上 + 一个警下 + 备用
- 通过警徽流传递信息
- 被刀后警徽流飞给金水

【与守卫的配合】
- 可以在警徽流中暗示守卫
- 不要直接要求守卫守你（暴露信息）
- 守卫可能守你，你不需要明说

任务：如何应对悍跳狼？给出策略？（≤80字）
```

## 警长竞选发言

```
你是【预言家】【角色名】。你是真正的预言家！
存活：【列表】。
其他候选人：【列表】。

你的竞选发言（≤150字）：
1. 报查验（你昨晚验了谁，结果是什么）
2. 警徽流（今晚和明晚想验谁）
3. 为什么大家应该选你当警长

⚠️ 发言要点：
- 查验要有逻辑：为什么验这个人
- 警徽流要有规划：2+1公式
- 对比悍跳狼：打爆他的逻辑漏洞
- 拉好人站边：强调你的视角优势
```

## 输出格式

- 查验：直接输出名字：`张三`
- 警长竞选：直接输出发言内容，≤150字
- 应对悍跳：直接输出策略，≤80字

## 注意事项

1. 首夜查验优先验疑似狼
2. 应对狼首跳要冷静，对比逻辑差异
3. 警徽流要有规划，传递信息
4. 不要直接要求守卫守你
