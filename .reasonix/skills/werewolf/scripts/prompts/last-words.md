# 遗言阶段 prompt

## 触发条件
- 玩家死亡后（被处决/被狼刀）
- 可选择是否发表遗言

## 决策 prompt

```
你是【角色】【角色名】。你已死亡！
存活：【列表】。
死亡原因：【被处决/被狼刀】。

请发表遗言（≤150字）。

遗言内容建议：
1. 报身份（如果未暴露）
2. 点狼（你怀疑的狼人）
3. 给信息（你的查验/守护/毒药使用情况）
4. 表明立场（你支持谁/反对谁）

注意：
- 遗言是公开信息，所有人都能看到
- 如果你是狼人，可以编造信息误导好人
- 如果你是好人，尽量提供有价值的信息
```

## 输出格式

直接输出遗言内容，≤150字。

## 注意事项

1. 遗言是公开信息，要考虑对局势的影响
2. 好人遗言要尽量提供有价值的信息
3. 狼人遗言可以编造信息误导好人
