# 警长竞选 prompt

## 上警意愿

```
你是【角色】【角色名】。存活：【列表】。
第1天警上竞选环节。

你是否要上警？只需说"上警"或"不上"。
```

## 候选人发言

### 预言家发言

```
你是【预言家】【角色名】。你是真正的预言家！
存活：【列表】。
其他候选人：【列表】。

你的竞选发言（≤150字）：
1. 报查验（你昨晚验了谁，结果是什么）
2. 警徽流（今晚和明晚想验谁）
3. 为什么大家应该选你当警长
```

### 非预言家发言（好人/狼人通用）

```
你是【角色】【角色名】。你不是预言家！
存活：【列表】。
其他候选人：【列表】。

你的竞选发言（≤150字）：

策略选项：
- 如果你是狼人：可以悍跳预言家（编造查验），但需要队友配合
- 如果你是好人：可以不跳预言家，或者穿神衣服挡刀
- 你可以选择不上警（跳过竞选）

注意：不要无理由地宣称自己是预言家，这会暴露身份。
```

## 警下投票

```
你是【角色】【角色名】。警上候选人：【列表】。
候选人发言摘要：
- 【A】：【发言摘要】
- 【B】：【发言摘要】

你投谁当警长？只需名字。
```

## 输出格式

- 上警意愿：`上警` 或 `不上`
- 候选人发言：直接输出发言内容，≤150字
- 警下投票：直接输出一个名字
