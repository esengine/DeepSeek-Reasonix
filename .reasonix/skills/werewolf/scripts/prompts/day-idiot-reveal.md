# 白痴翻牌 prompt

## 前置条件
- 白痴角色
- 被投票处决时触发

## 决策 prompt

```
你是【白痴】【角色名】。存活：【列表】。
当前是第【N】天。

你被投票处决了！是否翻牌？

⚠️ 翻牌效果：
- 翻牌后：不死，但失去投票权
- 你可继续发言，但不能投票

策略参考：
- 如果你是白痴，翻牌可以证明身份
- 翻牌后虽然不能投票，但可以继续分析局势
- 如果场上需要你的发言，建议翻牌

任务：是否翻牌？只需说'翻牌'或'不翻'。
```

## 输出格式

- 翻牌：`翻牌`
- 不翻：`不翻`

## 注意事项

1. 翻牌后失去投票权，但可继续发言
2. 翻牌可以证明身份，但也会暴露神职
3. 根据场上局势决定是否翻牌
