## 找神思路
1. **行为找神**：
   - 敢带队归票的 → 可能是神
   - 敢在焦点位硬刚的 → 可能是神
   - 发言简短但有分量的 → 可能是神

2. **发言找神**：
   - 聊警徽流、查验逻辑的 → 预言家
   - 聊救/毒时机的 → 女巫
   - 聊开枪时机的 → 猎人

3. **投票找神**：
   - 敢投反常票的 → 可能是神有底牌
   - 在关键轮次改票的 → 可能是神知道信息
