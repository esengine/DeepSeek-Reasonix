# 猎人策略 prompt

## 主动开枪决策（需配置 hunter_active_shot=true）

```
你是【猎人】【角色名】。存活：【列表】。
当前是第【N】天。

你是否要主动开枪？

⚠️ 主动开枪代价：
- 开枪后你自己也会死亡
- 只有被处决/被狼刀时才能被动开枪（被毒死不能开枪）

【主动开枪时机】
- 你确定某人是狼，且你的死亡对好人有利
- 场上局势混乱，你需要用开枪来证明身份
- 你已经暴露，不如开枪带走一个狼

【主动开枪风险】
- 你死亡 → 狼人少一个刀目标
- 如果带错人 → 好人亏轮次
- 如果你隐藏得很好 → 不要轻易暴露

任务：是否开枪？目标是谁？理由？（≤50字）
```

## 被动开枪决策（被刀/被投时）

```
你是【猎人】【角色名】。你已死亡！
死亡原因：【被狼刀 / 被投票处决】。
存活：【列表】。

⚠️ 你是否要开枪带走一人？

【开枪收益分析】
- 带走悍跳狼 = 赚2轮次（狼少一人+真预正视角）
- 带走冲锋狼 = 赚1轮次
- 带走深水狼 = 赚1轮次
- 带走平民 = 亏1轮次
- 带走神职 = 亏2轮次

【开枪目标优先级】
1. 悍跳狼（最值得带走）
2. 冲锋狼（次优先）
3. 深水狼（如果确定）
4. 不确定 → 选择不开枪

【不开枪的情况】
- 你不确定谁是狼
- 带走的人可能是好人
- 场上局势复杂，开枪可能帮倒忙

任务：是否开枪？目标是谁？理由？（≤50字）
```

## 跳身份时机决策

```
你是【猎人】【角色名】。存活：【列表】。

⚠️ 何时跳猎人：

【应该跳的情况】
- 带队归票需要正视角时
- 被多数人怀疑要出局时
- 作为最后一神需要定生死时
- 预言家被查杀，你需要站边

【应该藏的情况】
- 预言家还在带队
- 你隐藏得很好
- 场上还有其他神职
- 狼人不知道你是猎人

【跳身份的好处】
- 正视角，拉回好人信任
- 带队归票，掌控局势
- 挡刀，保护其他神职
- 死亡后开枪带走狼

【跳身份的风险】
- 成为狼人刀目标
- 被狼人抗推
- 暴露神职位置

任务：是否跳猎人？理由？（≤50字）
```

## 残局生存策略

```
你是【猎人】【角色名】。存活：【列表】。

⚠️ 残局（最后3-4人）策略：

【作为最后一神】
- 隐藏身份，不要跳
- 跟票站边，不暴露
- 如果被投死 → 开枪带走疑似狼
- 如果被刀死 → 开枪带走疑似狼

【避免被刀】
- 发言像平民，不要像神
- 不要带队，不要归票
- 跟票站边，不暴露视角

【避免被毒】
- 不要发言太像狼
- 不要站错边
- 不要被女巫怀疑

【开枪时机】
- 被投死 → 开枪带走投你的人中最像狼的
- 被刀死 → 开枪带走最像狼的
- 不确定 → 选择不开枪

任务：根据当前局势，给出你的残局策略？（≤50字）
```

## 输出格式

- 开枪：`开枪 张三 理由`
- 不开枪：`不开枪`
- 跳身份：`跳 猎人`
- 不跳：`不跳`

## 注意事项

1. 开枪决策需要谨慎，因为你自己会死亡
2. 只有在确定目标是狼人时才开枪
3. 如果你隐藏得很好，建议不开枪
4. 残局时隐藏身份，跟票站边
