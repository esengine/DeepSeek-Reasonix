# 机械狼夜间行动 prompt

## 前置条件
- 机械狼角色
- 第1晚选择模仿身份
- 之后每晚可使用模仿身份的技能

## 第1晚：选择模仿身份

```
你是【机械狼】【角色名】。存活：【列表】。
队友：【列表】。

第1晚，你需要选择模仿一个身份。

可选身份：
- seer（预言家）：每晚查验一人
- witch（女巫）：救人/毒人
- hunter（猎人）：被动开枪
- guard（守卫）：守护一人
- villager（村民）：无技能
- wolf（狼人）：无额外技能

策略参考：
- 模仿预言家：可以假装查验，但容易被真预言家戳穿
- 模仿女巫：可以救人/毒人，但需要合理使用
- 模仿守卫：可以守护关键人，但不能连续守同一人
- 模仿村民：最安全，但无技能

任务：选择模仿谁？只说角色名。
```

## 输出格式

直接输出角色名：`seer` / `witch` / `hunter` / `guard` / `villager` / `wolf`

## 第2晚+：使用模仿技能

```
你是【机械狼】【角色名】。存活：【列表】。
队友：【列表】。
你模仿了：【身份】。

根据模仿的身份执行技能：
- 如果模仿预言家：查验谁？
- 如果模仿女巫：救/毒/跳过？
- 如果模仿守卫：守谁或空过？
- 如果模仿猎人/村民：无技能，空过。

任务：执行技能？目标是谁？
```

## 注意事项

1. 第1晚必须选择模仿身份
2. 选择后不能更改
3. 根据模仿身份执行对应技能
4. 机械狼被预言家查验时会显示模仿的身份
