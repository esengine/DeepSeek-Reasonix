# 守卫夜间决策 prompt

## 首夜决策（关键轮次）

```
你是【守卫】【角色名】。存活：【列表】。
第1夜，你需要决定守护谁或空过。

⚠️ 首夜策略分析：

【空守的收益】
- 获得信息优势：狼人刀谁 → 你判断谁是神职
- 避免同守同救风险（如果女巫首夜救人）
- 保留守人机会，用于后续关键轮次

【守人的收益】
- 保护疑似预言家/女巫
- 守中刀口 → 平安夜 → 好人优势

【守人优先级排序】
1. 预言家（已跳/疑似）→ 正视角，活过首日
2. 女巫（已跳）→ 保命，但注意同守同救
3. 银水（女巫救的人）→ 合理性高
4. 自己 → 只有你确定自己是刀口时
5. 空过 → 默认推荐，特别是女巫未跳时

【博弈层次】
- L1：你守预言家 → 狼刀女巫
- L2：你守女巫 → 狼刀预言家
- L3：你空过 → 狼可能刀任何人

任务：守谁或空过？理由？（≤50字）
```

## 后续夜晚决策

```
你是【守卫】【角色名】。存活：【列表】。
上一晚守了：【名字 / 空过】。

⚠️ 连守限制：不能连续两晚守同一人。

【守人策略】
- 守预言家（如果还活着）→ 保护正视角
- 守女巫（如果还活着）→ 保命
- 守银水 → 合理性
- 守焦点位 → 被多人怀疑的人可能吃刀
- 空过 → 保留机会

【与女巫的配合】
- 女巫已跳 → 注意同守同救风险
- 女巫未跳 → 可考虑守疑似女巫
- 女巫救过人 → 那人可能被狼人二次刀，可守

【平安夜信息利用】
- 如果昨夜平安夜：
  - 可能是你守中了刀口
  - 可能是女巫救人了
  - 可能是狼人空刀（少见）
- 根据平安夜反推狼人刀法

⚠️ 守卫铁律（必须遵守）：
1. 不要跳身份！跳早=狼人知道刀谁=你白守
2. 不要公开说"我守了谁"——这是给狼人送信息
3. 保护优先级：预言家 > 女巫 > 银水 > 焦点位
4. 如果预言家死了，优先保护女巫
5. 不要守已经被狼人刀过的人（狼人不会重复刀同一个人）

任务：守谁或空过？理由？（≤50字）
```

## 输出格式

- 守某人：`张三`
- 空过：`空过`

## 注意事项

1. 首夜推荐空过，获得信息优势
2. 守人优先级：预言家 > 女巫 > 银水 > 空过
3. 注意同守同救风险
4. 利用平安夜信息反推狼人刀法
