# 找神篇（狼人视角·抿神技巧）

> 狼队赢不赢，看刀准不准。
> 刀准不准，看找神找得对不对。

## 核心理念

```
找神不是靠运气，是靠观察。
神职有神职的行为模式——他们知道自己有身份，会不自觉地流露。
你的任务：从发言和行为中把这些信号识别出来。
```

## 行为找神

```
### 1. 谁在带队

第一天的自然领袖往往是神。
狼人会藏，平民会跟风，神职会不自觉地想带队。
- 归票位（末置位）发言有条理 → 可能是猎人/预言家
- 主动点狼坑且语气坚定 → 可能是预言家/守卫
- 对话所有人"大家听我说" → 可能是带身份的人

### 2. 谁不怕死

神职有底牌，心态上不怕被抗推（大不了翻牌）。
- 被质疑时反应平静 → 可能是神（有底牌）
- 被质疑时过度反应 → 可能是平民（怕被推）
- 被查杀时立即跳身份 → 可能是真神，也可能是狼悍跳

### 3. 谁在保人

神职会保自己认定的人。
- 预言家保金水 → 最明显
- 女巫保银水 → 银水被质疑时女巫可能忍不住说话
- 守卫保铜水 → 守的人被刀时会流露"我猜到他会吃刀"

### 4. 投票行为

- 投票果断、不跟风 → 可能有身份
- 在关键时刻改票 → 可能是女巫/猎人在控票
- 平票PK时坚定投票 → 可能有信息
```

## 发言找神

```
### 预言家

最明显的特征：跳预言家。
如果不跳：
- 发言有"验人视角"（虽然没跳但说话像有信息）
- 在分析谁应该被验、为什么
- 对跳预言家的话题格外关注

### 女巫

- 对银水话题敏感（银水被质疑时反应大）
- 发言有"救人视角"（"昨晚死了谁"说得很自然）
- 对刀法有分析（"狼人为什么刀他"）
- 解药用过/没用过的语气差异

### 猎人

- 发言强势、不怕死（"你们出我试试"）
- 归票位常说"我归票XXX"
- 被质疑时："我是好人，不信你们出我"
  → 平民不敢这么说，猎人才敢
- 沉默的猎人：一直在划水的可能是猎人
  → 猎人不带队时可能是在藏身份

### 守卫

- 对守人话题敏感
- 会说"我觉得今晚有人要死"之类的话
- 对同守同救规则很在意
- 被质疑时可能跳守卫

### 白痴

- 喜欢抬杠、打断别人
- 被质疑时：不慌不忙、"我是白痴"
- 翻牌前：发言随意，不怕得罪人
```

## 抿神技巧（进阶）

```
### 1. 穿衣服找神

你穿某神衣服 → 看谁反应最大。
- 你跳猎人 → 真猎人可能会对跳
- 你跳女巫发假银水 → 真女巫可能会拍你
- 你不跳、但聊"我觉得守卫应该守谁" → 守卫可能接话

注意：穿衣服要穿得像，穿得不像没人理你。

### 2. 压力测试

给某人压力 → 看他的反应判断身份。
- 悍跳给某人发查杀 → 跳神的是真神，不跳的是平民
- 点某人进狼坑 → 反应剧烈的是平民（怕被推），
  反应平静的是神（有底牌）

### 3. 票型反推

- 双死之夜 → 看谁的表情/发言有"果然如此"的感觉
  （女巫知道自己毒的人会死）
- 平安夜 → 看谁意外/谁不意外
  （守卫/女巫知道原因）

### 4. 轮次分析

- 第几轮了、死了几个人、还有几个神
  → 如果有人在算轮次，他可能是神
  → 平民一般不关心轮次，神职才关心

### 5. 状态反差

- 上局活跃→这局沉默 → 藏身份了（可能是神）
- 上局沉默→这局活跃 → 拿身份了
- 突然改变发言风格 → 可能拿了特定身份
```

## 神牌特质详解

```
神牌在场上想做两件事：带队 + 藏身份。
既想带队赢，又不想被狼找到，这导致神牌发言时经常出现以下特质：

### 1. 跨轮次点评

安排几天的工作：归人、验人、跨轮次打狼坑（找后几天的狼）。
心理根源：带队方便，也便于思考技能的使用方式。
发言本体比较置身事外，像坐在评委席评分。

### 2. 潜意识不怕被攻击

- 发言只有结论，没有过程
- 打人比较笃定，不给自己留退路
- 警上警下操作：压跳、强势对话要求好人站边、改警徽流、
  做认狼之类的拉仇恨行为
- 心态措辞："铁站边"、"必定"、"一定"
- 容易责怪外置位好人

### 3. 发言状态更紧张

- 承担用对技能和好人获胜的压力
- 怕被抿到身份，发言比较紧绷
- 担心站错边导致崩盘→非常谨慎地站边和发言

### 4. 刻意的身份矛盾点

A. 觉得1不好，1是预言家，但不聊很多原因
   发言有矛盾点，但不屑于给外置位解释内心真实心理过程
   → 因为不怕被攻击

B. 发言中途突然意识到自己状态过高、爆神
   然后特意凿补一段表水式发言去做自己身份
   或本身发言看似表水，但细节和打人力度都不像平民

C. 积身份的发言：非常简短，不愿点评自己视角
```

## 排水法找平民（反推神坑）

```
找不到神的时候，先找平民。排掉平民，剩下的就是神。

### 平民的特质

平民任务：找预言家→投票狼人 + 表水避免被抗推。
一个表水好的平民不被抗推，等于给好人增加一个轮次。

1. 乱嗨的玩家 → 偏向平民（增加游戏体验）
2. 表水迹象重、措辞弱
   用大量发言和逻辑解释自己给身份定义的原因
   一般给身份不会很死，比较怕打错
3. 不会越轮次安排工作，发言状态偏轻松
4. 心态措辞："可能"、"应该"、"我觉得"
5. 心态比较"闲"，可能会闲聊场外

### 格局上的平民

1. 强势站边、大量逻辑输出，但不跳身份号票 → 大概率平民
2. 在焦点位疯狂表水但不拍身份
   拿到神的人会在需要时跳身份，防止被不会玩的抗推或吃毒
   表水很重、语气无奈无力、有情绪发言 → 平民
3. 被明好人骑脸输出，只语言表水不交身份
   人被攻击时会有情绪，如果只语言反馈不交底牌→大概率平民

### 格局上的神

神跟平民在行为上的差别：神在推人或给女巫指毒时，
不怕出到或毒到神——因为他自己是神。

1. 归票时丝毫不担心归的人里有身份，不怕推神出局 → 像神
2. 视角回转：
   A. 一直铁站边2，投票时立刻回头投1 → 可能是女巫/守卫
   B. 刀口11，看完票型后2号回头 → 回头原因可能是女巫吃到银水
3. 发言中暗示躲验，不希望留到自己警徽流
4. 从技能找神：
   A. 银水：保银水/强打银水
   B. 毒口：谁保过毒口→不是女巫；谁打过毒口→女巫面高
   C. 盾口：平安夜时，谁打过被守的人→不是守卫；
      谁保过→疑似守卫

状态和语气 > 逻辑：对于判断神民，状态和语气格外重要。

## 刀人优先级（找到神之后）
```

```
1. 女巫（有毒药，威胁最大）
2. 预言家（正视角，多活一天多验一人）
3. 守卫（能守人，影响刀人效率）
4. 猎人（可能开枪带走狼人）
5. 白痴（翻牌后只剩发言，威胁最小）

特殊情况：
- 女巫解药已用 → 女巫优先级下降，先刀预言家
- 守卫已死 → 刀人无阻碍，优先刀女巫
- 预言家已报出关键查验 → 刀掉他阻止继续验人
```
