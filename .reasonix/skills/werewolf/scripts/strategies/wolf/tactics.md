# 狼人策略手册（狼人怎么演）
## 表水技巧（被怀疑时怎么脱身）

```
1. 不要慌，不要认狼，不要沉默
2. 承认自己"发言有瑕疵"，但坚持是好人
3. 反打质疑你的人："你打我的逻辑是伪逻辑"
4. 点出你认为的"真狼坑"（点2-3个好人+1个队友做铺垫）
5. 如果被真预查杀：
   - 跳平民："我平民一个，你们出我亏轮次"
   - 跳神："我是守卫/白痴，不要出我"
   - 注意：跳神要有队友接应（队友对跳神职帮你正视角）
6. 如果被多人围攻：
   - 委屈但不认输
   - "你们这么多人打我一个，我要是狼我队友在哪？"
```

## 狼队配合

```
1. 投票配合
   - 冲票时：所有狼人一起投票，不要犹豫
   - 倒钩时：分散投票，2个冲票1个钩
2. 发言配合
   - 不能全部站同一边（太明显是狼队）
   - 至少一狼站对边（预备倒钩）
   - 一狼打队友做身份（但要控制力度）
3. 刀人配合
   - 优先刀女巫（毒药威胁大）
   - 其次刀预言家（正视角）
   - 刀民策略：让好人2选1，赌白天抗推
4. 自爆配合
   - 自爆时机：预言家报出查杀时 → 立即自爆不让报第二晚
   - 双爆收益：某些格局下双爆可以让预言家拿不到警徽
   - 自爆救队友：队友要被抗推时，自爆跳投票
```

## 高阶版型（狼队配合套路）

```
这些是大局层面的狼队配合策略，需要狼队有默契、有分工。
不是每局都能用，但用出来往往能翻盘。
```

### 版型1：找守卫→刀守卫→两狼对跳守卫

```
流程：
1. 首夜狼人抿神找到守卫
2. 刀掉守卫
3. 白天两狼对跳守卫：
   - 一狼聊爆，做成"狼人单边守卫"的假象
   - 真守卫已死，没人能正视角

关键：守卫跳出来前就抿到他。
成功后好人会以为守卫还在，狼队获得巨大信息优势。
```

### 版型2：垫飞升级版

```
流程：
1. A狼第一天给B狼发金水
2. C、D两狼同时垫飞预言家
3. 持续垫飞直到预言家出局
4. A自刀，把警徽飞给好人

效果：狼队全员站边真预，好人视角里"预言家团队全是狼"的推论不成立。
A自刀飞警徽给好人→进一步做高A的"好人面"。
```

### 版型3：三狼警下·全体倒钩

```
流程：
1. 悍跳狼自刀，且发言非常好
2. 三狼全部在警下
3. 警徽投票时全体倒钩（投给真预）
4. 警下两狼回头（改投悍跳狼），一狼继续聊爆垫飞
5. 悍跳狼留警徽流给发言好的狼队友，发金水

## 深水狼专项

```
核心任务：活到最后，不能被抗推。
关键技巧：踩队友做身份。

1. 白天发言"假意怀疑"悍跳狼队友：
   "我觉得A（悍跳狼）的警徽流有问题，视角太窄"
   "A的查杀力度不够，不像真预的视角"
   程度：点到为止，不要死打（否则队友被抗推后你成焦点）

2. 投票时适当投给队友（"弃票"或"分票"比直接投队友更安全）：
   第一轮：可以投给悍跳狼队友（假装站错边）
   第二轮：转投真预（"回头是岸"）
   
3. 如果队友被查杀/被围攻：
   不要救！不要捞狼队友！顺势踩一脚：
   "B（被查杀的狼队友）发言确实爆狼，我认不下"
   "B这个位置被查杀，我不觉得是狼踩狼"
   
4. 深水狼的反面教材（❌不要这样做）：
   ❌ 全场不说话不投票（太显眼，划水狼必被抗推）
   ❌ 死保狼队友（暴露团队面）
   ❌ 跳神/跳预言家（深水狼不需要焦点）
```
核心逻辑：
保的是那个拿到金水的狼人。
好人视角：警下多狼且狼自刀→狼人一定会冲锋而非倒钩。
所以这个拿金水的狼人反而被"反向保"了。
```

### 版型4：自刀悍跳给狼队友查杀

```
第一种打法（反向金水）：
1. 悍跳狼给狼队友发查杀
2. 警上正常发言，警下被查杀狼聊爆出局
3. 遗言继续聊爆
4. 刀死预言家
5. 女巫报出银水 → 那个反向金的狼人近乎无敌
   （好人视角：被查杀的狼已出局，真预已死，唯一剩下的就是"好人"）

要求：被查杀的狼发言非常好，避免女巫打平衡吃毒。

第二种打法（金刚狼）：
1. 狼队友聊爆出局
2. 悍跳狼继续自刀
3. 给第三个狼人做金刚狼（身份无限做好）
```

### 版型5：机械狼板子·机械猎人互换身份（绝地翻盘）

```
配置：机械狼 + 小狼，神牌剩女巫（明跳）+ 守卫 + 猎人，女巫有毒。

流程：
1. 机械狼（你）学了猎人B的身份（机械猎人）
2. 找到小狼队友A（这是关键）
3. 双爆后剩下唯一小狼和你
4. 你起跳守卫
5. 出局后带走守卫
6. 报信息：
   "我是你们大哥，我有重要信息。
   我学了A是猎人。
   我觉得B应该是我们最后的小狼同伴吧。
   最后一狼，身份也告诉你了，要不直接自爆让好人赢吧。"

效果：
- 你带走守卫（一神）
- 保你的队友A不吃毒（女巫不敢毒"被大哥认证的猎人"）
- 递话队友A谁是真正猎人（B是猎人）
- 真猎人和A对跳后，A大概率抗推真猎人
  （因为外置位所有人都会觉得"大哥不会骗小弟"）

结果：一狼换三神，绝地翻盘。
```

## 夜间刀人策略

```
禁止根据名字/名字含义/名字气场刀人。

- 刀神 vs 刀民
  神职明跳 → 刀神减轮次
  场上需要2选1 → 刀村民让好人更难判断
- 女巫解药已用 → 刀女巫收益高
- 跨轮次规划：刀预言家留女巫 → 好人失去正视角
- 自刀：首夜自刀骗药，获银水信任。配合悍跳女巫发假银水
```
