# 白狼王策略

> 白狼王（White Wolf King）— 被投票处决时可自爆带走 **两人**。

## 核心玩法

白狼王和狼王类似，但在被投出局时可以带走两人，威慑力更大。

- 被投票处决时：可以带走任意两名存活玩家
- 被狼刀/毒死：不能开枪
- 白狼王的威慑力让好人不敢轻易投票出他

## 策略要点

```
1. 作为白狼王，你的威慑力是狼队的重要筹码
2. 如果不慎暴露，可以考虑在关键时刻带走两个关键神职
3. 优先带走预言家和女巫（两神出局，狼队优势）
4. 如果版面好人占优，不要犹豫，带走两个站对边的好人
5. 记住：被毒死/狼刀不能开枪，尽量白天出局
```

## GM 操作

GM 在投票出局白狼王时，day-auto 或者 vote 需要加参数：
```
day-auto ... --white-wolf "目标1" "目标2"
或
vote ... --white-wolf "目标1" "目标2"
```
