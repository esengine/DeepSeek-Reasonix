# 狼人策略手册（狼人怎么演）

## 核心心法

```
你是演员，不是玩家。
好人在找真相，你在编故事。
你的每一句发言都要服务于你的身份设定。
```

## 核心理念

```
狼队只需要一个狼人存活到最后完成屠边，即狼队获胜。
这决定了狼人可以有多种套路搭配取得胜利。

从轮次角度：冲锋 > 倒钩（冲锋直接抢轮次）
但当悍跳狼发言差于预言家时，需要其他策略。

玩狼的核心：模仿闭眼视角。
```

## 四种典型打法

选择哪种打法取决于悍跳狼 vs 预言家的发言差距、外置位好人的站边倾向、狼队当前的轮次压力。

### 1. 冲锋

```
适用场景：预言家视角缺失、逻辑错误多、打错多个好人时。
冲锋一定要用正逻辑，不能用伪逻辑。
高境界：哪怕你站边悍跳狼，预言家仍可能认你是站错边的好人。
双标：放大真预的问题，化小悍跳狼的问题。
```

### 2. 垫飞

```
目标：站边预言家，同时让好人继续站错边。
核心任务：凑真预言家的狼坑位。
对站错边的好人用正逻辑输出，打他们是冲锋狼。
对悍跳狼队友聊无关痛痒的问题，不聊致命点。
```

### 3. 倒钩

```
适用场景：悍跳狼发言差于预言家时。
按模拟的闭眼视角聊天，站边预言家。
用正逻辑做自己的好人面、以及跟悍跳狼的不见面关系。
倒钩意味着悍跳狼出局→狼队轮次落后→必须更快找神。
```

### 4. 深水/望风

```
适用场景：预言家和悍跳狼发言差别不大，外置位好人分不清时。
用正逻辑盘双边，弱倾向性软站边。
核心：不要上焦点位。给狼队更多选择空间。
```

## 狼人讨论规范（GM 指挥狼队协作流程）

网杀中狼队有30秒团队聊天时间。分两轮进行：

### ⚠️ 首夜盲刀规则

第0晚为零信息盲刀。狼人不知道任何人的身份。
- 禁止根据名字/名字含义推测身份（"大克像神面"→禁止）
- 禁止猜身份（"刀大克，女巫可能不救"→你首夜不知道谁女巫）
- 允许随机刀、刀外置位、刀边缘位（这不需要信息）
- 首夜过后可以根据白天发言分析身份

### 第一轮：分工确认（parallel_tasks，每人独立提案）

同时问每个狼人——需要输出三项内容：
1. **你的分工**：悍跳/倒钩/垫飞/深水
2. **今晚刀谁**：目标玩家
3. **理由**：为什么这样分工+刀人

各狼独立发言，不看到队友回复。收集初始方案。

### 第二轮：方案评估（sequential task，发给悍跳狼汇总）

把第一轮的三份方案拼起来发给悍跳狼：
"你们的方案如下：
  - 狼A（倒钩）: 刀X，理由是...
  - 狼B（悍跳）: 刀Y，理由是...
  - 狼C（垫飞）: 刀Z，理由是...
现在请你评估这些方案，确认分工和最终刀人目标。"

悍跳狼输出最终决定：每个人分别打什么位置，今晚刀谁。

### 第三轮：最终确认（optional，分歧大时才需要）

如果悍跳狼的决定与其他狼的方案差异过大，
GM可以再问一次其他狼："悍跳狼决定刀X，你们有异议吗？"
多数同意则执行，多数反对则回到第二轮重新商议。

### 第二轮：团队讨论（所有狼参与，默认发言顺序）

把第一轮的三个方案拼接展示给每匹狼看，然后按顺序让每狼表态：

"你们狼队的初始提案如下：

【方案A】刀X，理由是：...
【方案B】刀Y，理由是：...
【方案C】刀Z，理由是：...

现在请你分析三个方案的战略优劣，然后给出你的最终建议。"

所有狼都看到彼此方案后，GM 综合三狼建议，取多数决执行。
如果三狼意见一致（方案相同），第二轮可跳过。

### 讨论规则

【提案阶段】每狼独立提案，不看到队友回复。禁止"我性格如此"。
【讨论阶段】每狼看到全部方案后，分析战略优劣，给出最终建议。
【决策阶段】GM 归总三狼最终建议，取多数决。平票时悍跳狼/发言权最大的狼破局。
