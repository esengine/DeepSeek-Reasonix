# 狼人策略手册（狼人怎么演）
## 悍跳预言家（核心技能）

```
目标：让好人相信你是真预言家，把真预抗推出局。
悍跳成功 = 狼队成功一半。剩下的一半靠外置位狼同伴。

### 谁去悍跳

选择发言和逻辑水平次好/最好的玩家去悍跳。
悍跳狼一般不会活到最后——好人可能会回头/打平衡。
游戏后半程需要另一个发言好的狼隐下来带队。
所以狼队最优打法：次好/最好的悍跳，留一个厉害的兜底。
```

### 悍跳的三个核心任务

```
1. 拉票：拿警徽，抗推预言家
2. 做身份：通过格局和不见面给队友做身份，确保有身份高的队友
3. 避免卖视角
```

### 悍跳发言框架（总分总结构，以120秒为例）

```
包含要素：
（1）查验和心路历程
（2）警徽流 + 警徽流原因 + 前置位发言点评
（3）对话警下不在警徽流的玩家
（4）指出对跳的"爆狼点"及他卖的视角
（5）小碎话包装自己的预言家面
（6）做狼同伴身份/包装狼同伴/脏好人身份
（7）安排工作（尤其是有守卫/摄梦的板子）

警徽流公式：2+1
2 = 一个警上 + 一个警下
1 = 防起跳/骑士/商人/幸运儿/自爆的备用警徽

警徽流技巧：
- 警下金水→第一警徽可先验警下（警下多张牌时）
- 警上金水或查杀→第一警徽务必验前置位发过言有问题的玩家
```

### 发查杀 vs 发金水

```
查杀：
- 查杀后置位 → 对方可能跳神，你就有对跳目标了
- 查杀前置位 → 对方可能聊爆，显得你验人精准
- 查杀狼队友（狼查杀狼）→ 牺牲一个队友做高自己身份
  被查杀的狼要表演委屈、激动、要求真预带队

金水：
- 发给后置位 → 对方可能是真预，反水你就崩了
- 发给前置位——理由要给足：
  "他前置位发言逻辑正，像好人，验了带队"
- 发给狼队友 → 做高队友身份，但真预可能会验他
- 发给好人 → 拉票，但要注意：如果对方是你查杀的目标，不能发金水
```

### 心态要像真预

```
- 对跳狼要有敌意，但不是歇斯底里
- 对站错边的好人：要劝，不要打
- 被质疑时要解释，而不是反打
- 真预会怕好人站错边 → 你也要表现出这种怕
- 被质疑警徽流时："我警徽流留得不好是因为我紧张，不是狼"
```

## 悍跳女巫

```
时机：需要正视角或拉票时
- 银水给谁很关键：
  → 给真刀口（你知道谁被刀了）→ 真女巫知道你在编
  → 给假刀口 → 如果正好点到真女巫，她直接拍你
  → 最安全：给一个发言差的牌，说是救了他但他自己都不知道
- 解药用过没？说用过了 → 后面没人能验证
  说没用过 → 你被质疑时可以说"今晚救人"
```

## 狼人悍跳神职穿衣服

```
1. 穿猎人衣服
   - 收益：没人敢投你，狼队不敢刀你（怕你开枪）
   - 风险：真猎人对跳，你出局
   - 应对：真猎人对跳时 → "好吧我其实是平民，怕死穿了下衣服"
2. 穿守卫衣服
   - 收益：可以编守人信息
   - 风险：真守卫报出正确守人信息，你穿帮
   - 应对：守人信息要模糊，"我守了我觉得像狼的人"
3. 穿白痴衣服
   - 收益：最安全的神职（翻牌才死）
   - 策略：被抗推时穿白痴 → 赌真白痴不敢第一时间翻牌
```

## 悍跳实战范例

### 总起（5-10秒）

```
我是预言家，6号牌你是我的金水（状态：高兴），警徽流先1后10，警上留边角的1，警下留10。过。
```

### 分述（10-20秒）

```
验人及心路历程：验6是因为上局6是好人发言不太行，被大部分好人定错身份，
所以这局我拿到预言家就去验了6，验他觉得收益最大，他是我的金水。
如果外置位的好人能找我是预言家，那就把6号先放一放，无论他之后发什么言。
而且逻辑上去讲，哪怕6是我狼同伴，我也不太会把金水发给他。

我自认为，我拿预言家的发言和找狼能力还是不错的，胜率也挺高，
只希望外置位的好人牌，不要以一些奇奇怪怪、以自我为中心的理由强打我。

我相信对比我和4的发言，这局游戏站边是不难的，
也希望好人都可以找到我是你们的盖世预言家（语气诚恳，强调"都"、"盖世"两字）。

我是预言家，6金水，警徽流1，10，过。
```

## 悍跳注意事项

```
（1）忌讳心路历程太长
（2）决定悍跳后，夜间开始模拟预言家视角：
    - 若你是预言家你会验谁？验出来金水/查杀，初定警徽是什么？
    - 上警后观测你的查验在警上还是警下，修正警徽流
    - 记住：一个好的悍跳在任何时间任何位置都可以起跳
（3）悍跳发言要"顺势而为"：
    - 你的金水和外置位好人保的牌 → 哪怕你不想给他好人，也要顺势给偏好定义
    - 你的金水或外置位多数人打的狼人牌 → 尽量不去保他
      如果想拉他票，可以说"我也觉得XX聊得很爆匪，
      但我给你保留了一丝丝好人面，是你的某句话像个闭眼好人"
    - 外置位希望你去验的牌 → 可以留他警徽流，或者聊清楚不验的原因
（4）不要轻易定死几张牌是铁狼——哪怕是你队友
    - 抗推预言家需要队友有正当理由冲票
    - 定死队友铁狼可能卖视角
（5）跟队友做身份时，发言不要太刻意，语气状态要轻松自然
（6）拉票时如果遇到好人互打（A和B逻辑冲突）：
    - 选择一套逻辑和视角去输出，不能盲目
    - 结合玩家水平和视角，判断哪些人的票可以被拉动
    - 拉你需要的票，而不是顺着自己觉得更对的逻辑去聊
    - 顺着自己逻辑聊可能让原本站边你的人回头
```

## 警下发言策略（应对"两难"）

```
悍跳时常遇到两难：有人觉得你该验狼，有人觉得你该验容错；
有人觉得你该点齐4狼，但点狼坑又容易拉不到票。

我的策略（警下发言）：

（1）除悍跳外给出一个不需要查验的定狼
    → 给到充分的发言和行为理由：
      发言爆狼的原因、和对跳的见面关系、冲锋行为

（2）给到三个左右外置位的好人（一般包括一个队友）
    → 作为拉票和做身份的对象
    → 给出认其好人相对合理的原因：
      正逻辑站边你、点出对跳爆点、点出外置位爆狼、
      或发言细节跟对跳牌不见面

（3）给到一到两个疑似狼坑位（留作警徽流）
    → 再给一个容错位：如果警徽流验出金水，警徽就飞谁
    → 他接警徽后，容错的谁就需要进视角
    → 总体给人点了四狼的感觉
    → 但除了定死的狼外，警徽流和容错的票都可能被拉到
```
