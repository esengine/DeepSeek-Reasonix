# 好人策略手册（村民+平民视角）

## 爆水发言（如何找好人）

```
1. 超高思考量与思维延展
   提出比闭眼视角更多的正逻辑，且逻辑链条完整。
   狼人是睁眼的，要模拟闭眼视角有困难。
   例：A反复思考B和C的互动关系后给出和自己相同的结论
      → 狼人很难从白牌视角延展出反复思考

2. 闭眼视角
   - 记错悍跳位置/查验/刀口（说错跳的人、听错银水）
     在非做作情况下好人面极大（狼人不会记错自己编的剧本）
   - 提出"鬼故事"格局（所有人都没想到的格局）
     狼人视角清晰，不会想小概率事件

3. 找狼视角（以身入局）
   即使玩家逻辑有问题，但如果在他自己假设下后续逻辑链完整、
   展开合理、且在试图判断他人身份 → 仍可是视角有偏差的好人
```

## 不见面关系

```
- A被查杀→踩A踩得狠的人大概率不是A的狼队友
- A是明狼→A保过的人是狼的概率低
- 已知A是狼，投票给A的人里出狼的概率低，
  踩A的人里反而可能出倒钩狼
```

## 刀法分析

```
首夜刀口无信息（盲刀）。
后续刀口反映狼队策略：
- 刀神→狼想屠神，好人藏身份
- 刀民→狼想屠民，神职不跳太早
- 刀预言家→狼怕验人，真预言家可信
- 自刀→狼骗药做身份，银水不一定可信
```

## 行为分析

```
逻辑断层（好人也会，需谨慎）：
- 忘了思路、时间不够、意识到A不成立而转向B
- 不能单独作为铁证

心态断层：
- 对A激进，对B保守 → 有信息优势的表现
- 需结合其他证据
```

## 好人心态 vs 狼人心态（实战篇）

```
核心原则：
- 好人是闭眼的 → 对所有人都有不确定性和包容度
- 狼人是睁眼的 → 发言更有目的性，心态更难伪装
- 甚至可能出现"心态"和"逻辑"不匹配（逻辑上没问题但心态上别扭）

### 好人心态的特征

1. 敌意差异
   对发言差的悍跳狼→敌意大、语气重、反感
   对站错边的玩家→反而更谨慎、保留好人面
   → 这种"敌意分配不均衡"是闭眼视角的天然产物，狼人很难伪装

2. 对话 vs 辩解
   预言家/好人会对站错边的明好人（金水/神）有更多对话，劝他们回头
   狼人只要票够，更多是辩解而不是对话

3. 内心流露
   中途突然插入担心："要是1是狼给2金水，2是好人怎么办？"
   → 真实表达内心担忧，好人面大
   义愤填膺说"哪怕你是发言差的预言家我也要做第五匹狼"
   → 可能是站错的好人

4. 主观逻辑站边
   用自己一套逻辑框架站边A（即使不是最正的那套逻辑）
   + 发言状态真心实意 → 几乎都是好人

### 狼人心态的特征

1. 不敢得罪神
   如果1是单边神站错边，2却敢往死里打1
   → 2的预言家面大（狼人很难去得罪一张跳神的牌）
   如果2真得罪了，狼队友应该对跳一个神去干扰视角

2. 不敢保人
   1站边2且发言偏正，但2不敢保1
   → 2的预言家面高（狼人2如果保1，1和2做双狼概率就高了）

3. 心态与逻辑不匹配
   A起跳预言家，逻辑上全部认同B的发言，但警徽流流到C时犹豫、不情愿
   → 可能C是好人，A开眼知道C是好人所以不情愿去验
   → 预言家面降低

### 实战发言片段判断

"今天就点我，我是平民，屠神局，民多，不怕" → 好人面大
"如果你是狼刀了我再给我发金水，我先跟你走一轮" → 好人面大
"4号牌我今天就不可能跟你走"（义愤填膺）→ 可能是站错的好人

### 跨局人性流（有历史记录时）

1. 上局被扛推 → 这局起跳预言家 → 预言家面偏大
2. 上局被某玩家骗过 → 这局再验同一个人 → 可信度低
3. 被全场保的人被某玩家义正言辞地攻击 → 攻击者好人面偏高
4. 上局站错边的玩家被预言家"担心站错边所以验了" → 骗的概率偏低
5. 给查杀但心路历程是"奔金水验去保护" → 有预言家面

特别注意：好人心态 ≠ 心态发言。
真正的好人心态是玩家不经意间流露出来的，而非刻意表演出来的。
```
