# 神职策略手册

## 预言家 — 警徽流分析

```
接查杀时的视角：
- 真预被查杀会本能想"验谁来正视角"；狼人被查杀更关注"怎么编显得像真预"
- 后置位多狼时，狼悍跳容易出现"接查杀缺失博弈视角"

金水的视角义务：
- A给警后B金水→后面起跳的C必须视角入B（不提B的金水=刻意回避）

警下视角缺失：
- 给警下查杀，留了另一张警下牌但不给压力、不对话其他警下牌→扣分

警徽流带视角（狼人痕迹）：
- 左边预验左边警下，警徽流却留右边→警下有狼同伴
- 两张明显不见面的牌同入警徽流→狼人编警徽流凑数
- 两张相似视角的牌只进A不进B，B是银水→疑似带银水视角
```

## 女巫 — 救毒策略

```
⚠️ 保命红线（最高优先级）：
1. 配置 witch_self_save_n1=开启时，首夜被刀必须自救。
2. 如果你收到"昨夜死亡: 你"的反馈且没有使用解药，视为重大失误。
3. 解药用在自己身上永远不亏——活着才能带队。

解药策略：
- 首夜救人通常性价比高（不论自刀与否，救到人就不亏）
- 银水（被救的人）大概率是好人，但不排除自刀狼
- 如果银水 later 被预言家查杀为狼 → 自刀铁狼

毒药决策框架（必须同时满足2条以上才毒）：
1. 身份明确：该玩家已被预言家查杀为狼，或被多轮逻辑锤死
2. 无反转可能：不是"站错边的好人"或"逻辑混乱的村民"
3. 威胁评估：该玩家是狼队核心（悍跳狼/冲锋狼），不毒会继续带节奏

⚠️ 毒药禁忌：
- 不要因为"某人让我毒他"就毒 → 狼人可能在骗毒
- 不要因为"某人发言不好"就毒 → 发言差≠狼
- 不要被狼人牵着鼻子走 → 你是闭眼视角，要独立判断
- 宁可不毒，也不要毒错好人（毒错=送轮次）

识别自刀狼：
- 白天有人跳女巫发不同银水 → 跳的人99%是狼
- 假银水避开真刀口太明显 → 被避开的刀口是自刀队友
```

## 守卫 — 守护策略

```
- 不能连续两晚守同一人
- 女巫已跳→守女巫需考虑同守同救
- 被多人认好的玩家更易吃刀
- 预言家是狼人优先刀目标
```

## 猎人 — 开枪策略

```
- 被动：被狼刀（非毒）或白天被投死→可开枪带走一人
- 主动（需配置）：白天任何时候亮身份开枪，猎人也会死
- 不确定时可不开枪
- 最后一神无法开枪时，平民可跳猎人挡刀
```
