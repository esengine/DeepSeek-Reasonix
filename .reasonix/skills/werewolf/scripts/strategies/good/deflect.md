# 挡刀篇（平民视角·如何替神挡刀）

> 在狼刀在先的局，挡刀几乎是每个好人除了找狼外必须思考的环节。
> 一个成功的挡刀 = 给好人多争取一个轮次。

## 核心理念

```
平民的任务不只是表水，还有挡刀。
狼人刀神 → 如果你能让自己看起来像神，狼人就会刀你而不是真神。
你一换一（平民换一刀），赚的是轮次。
```

## 爆神发言（装神）

```
### 1. 语气要刚

- 强势归票："今天必须出3，3就是狼"
- 安排工作："女巫今晚毒10，守卫守预言家"
  → 你当然是女巫/守卫——但你假装是
- 注意：语气要自然，混入通篇发言中，不要刻意突兀

### 2. 神职工作

- 安排PK："1和2PK，其他人投票"
- A和B互打却同时保A和B → 像有身份的人在操作
- 明确躲验："别验我，验我不如验XX"

### 3. 对话金水（暗穿衣服）

"1号牌，你一定一定不能归到我，你就外置位归。
我确实是好人。好吧，我再强调一遍：一定不能归我。"
→ 语气诚恳急切，让狼以为你是递话的神
```

## 明穿衣服

```
### 1.0 版本：直接跳身份

"我是守卫/猎人"
适用场景：狼刀在前，你的身份本来就偏好，
点的位置也确实爆狼。
真神也许思考你是挡刀的，不会跳身份来打你。

### 2.0 版本：逻辑输出自己是神

"藏不住了啊，能盾到1的只能是我啊。
那天平安夜，场上有谁还能盾到1啊，没有人能盾到1。
我觉得我藏着也没用了，肯定会被狼人抿到。
那我就跳出来，狼就搏一搏刀吧。"
→ 编一套只有"神"才知道的逻辑
```

## 给衣服穿（高级玩法）

```
目标：让狼人的视角从真神转移到你和另一张好人牌身上。

步骤：
1. 找到场上唯一剩下的神 → A
2. 找到一个挡刀位的好人 → B
3. 发言：

"今天肯定最后一推了，B是个枪/盾都写到脸上了。
B第一天就怎么怎么……
能盾到谁谁不只能是B吗？
现在B你还藏身份，你藏得住吗？

当然你们也可以盘我是枪/盾，我想让B穿我衣服替我挡刀。
那你们就拿刀来抿抿我好吧。
你们这狼人要是都刀错了，还找不到枪/盾，那你们狼刀也太菜了。"

目的：
- 小碎话给狼压力
- 让狼的视角转移到你和B身上，而不是真神A
- 你还有逻辑输出时，狼人要么跟盘B是神，
  要么觉得你是想让B替挡刀而你是真神
- 真神A被狼视角忽略
```

## 机械狼板子·跳大哥（绝地翻盘案例）

```
场景：场上剩两个小狼、一个大狼、最后一个猎人。
猎人一直站错边为狼号票。

操作：
猎人没有摆烂，而是自认双刀大哥。
对话一个发言爆狼的玩家（底牌是狼人）：
"我学了你，只要你们信我，按我的方式刀人。
最后一天我开双刀，狼人必胜。"

要求队友双爆。因为前三天一直站错边，
且点对学的身份是狼人，小狼都以为他是真大哥。
小狼双爆直到最后一天也没有刀他。

最后一刀没有双死 → 外置位知道他不是双刀狼。
他再交心路历程拍猎人身份，归走最后的大狼——绝地翻盘。
```
