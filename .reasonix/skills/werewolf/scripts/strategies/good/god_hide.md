# 躲刀篇（神职视角·如何让狼找不到你）

> 你的技能再强，被刀了也用不出来。
> 找神是狼人的功课，躲刀是你的功课。

## 核心理念

```
神职的两难：既要带队，又要藏身份。
带队 → 容易暴露 → 被刀
藏身份 → 安全 → 但可能带队不力

关键：在带队和藏身份之间找到平衡点。
```

## 藏视角

```
### 1. 银水不要过度保护

拿女巫时，对银水不要过度保护，也不要太刻意攻击。
狼人会从"谁在保银水"来反推女巫。

### 2. 想毒的牌白天忽略

对于白天想毒的牌，如果觉得需要藏身份：
→ 发言时刻意忽略他的一些问题，对他一笔带过
→ 夜间把他毒掉
→ 狼人试图从毒口找女巫时，很难找到你

### 3. 不要暴露技能信息

- 不要聊"昨晚我守了X"（除非跳守卫）
- 不要聊"如果我还有解药"（暴露女巫身份）
- 不要聊"我怕同守同救"（暴露守卫身份）
```

## 盘神坑（假装自己不是神）

```
你是守卫/女巫时：
- 去盘"夜间倒牌的A是不是女巫/守卫"
  → 假装你不知道谁是女巫/守卫，即你不是

你是猎人时：
- 盘前置位归票的人"他能不能是枪"
  → 假装怕归枪出局，即你不是枪
```

## 装懵（最高级的躲刀）

```
装作一个可以被狼拉票、没有视角、不太会玩的平民牌。
狼人视角：这个人是摇摆票，可以拉拢 → 舍不得刀。
狼人不会刀自己可能拉到的好人票。

要点：
- 发言不要太有信息量
- 对跳预言家时：两边都聊一点，不坚决站边
- 投票时：跟着多数走，不带头
- 被质疑时：表水但不拍身份
```

## 身份伪装话术

```
### 女巫伪装

- "我觉得11可能是银水吧……哦不对，11是……"
  → 假装不确定银水信息（假装不是女巫）
- "女巫应该救了他吧，不然他怎么会活到现在"
  → 以第三人称提女巫，假装自己不是

### 守卫伪装

- "守卫昨晚守了谁啊，守对了吗？"
  → 假装不知道守卫信息
- "我觉得守卫应该守预言家，不要跟狼博心态"
  → 以建议的口吻说，像平民在给建议

### 猎人伪装

- "你们别归我，我就是一个平民"
  → 假装是平民
- "谁是猎人啊，出来带队啊"
  → 以第三人称叫猎人，假装自己不是
```

## 特殊情况：最后的神

```
当你是场上最后一个神时：
- 绝对不能跳身份
- 让平民穿你的衣服挡刀
- 自己继续藏
- 只有在需要归票定生死时才考虑跳

规则：最后一神出局游戏结束。
你活着，好人就还有希望。
```
