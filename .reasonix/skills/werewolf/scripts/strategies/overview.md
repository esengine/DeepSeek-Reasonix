# 游戏大局观（格局分析）

> 判定身份以发言为主要标准，格局为辅助依据。

## 发金/发杀的格局分析

```
A悍跳给前置位发过言的B发金水，思考：
- 有没有可能保到了狼同伴？
- B是否发言摆烂打不动或疑似神？

A悍跳给发过言的B查杀：
- 打错多个好人→容易被扛推
- 打对了多个狼人→选择给查杀
```

## 刀法格局

```
屠民 vs 屠神：
- 第一天出预言家→屠神概率大
- 第一天出悍跳狼给查杀的平民→屠民概率大
- 狼人也可以打反逻辑——但打反逻辑的狼会在发言时格外强调刀法

多张白牌中选刀A而非B：
- 狼人会留下对自己印象好的，刀掉印象差的，以获得更多票
- 同样存在反逻辑

倒钩狼判定：
- 1、2对跳，1出局后2吃刀
- 投票给1/压票的人里一定有倒钩狼
- 投票给2的人里至多两个冲锋狼

洗团队：
- 好人站错边、狼人倒钩、真预出局时
- 狼队可能刀站错边的好人，制造狼坑不齐的错觉
- 刀的目标：站边狼但不太坚定的人，或垫飞狼预的好人
```

## 狼坑不齐

```
结合站边和不见面关系：发现某一方狼坑不齐 → 判定该方为预言家。
```

## 非焦点/非轮次起跳身份

```
在疑似狼刀在先、或不是自己轮次时跳神：
- 强势归票外置位，以求抗推好人
- 或通过好人反馈找到外置位神坑，实现屠边

例外：好人穿衣服挡刀推狼，需结合之前的发言和行为判定。
```

## 不见面与卖视角

```
确认A为狼人后，以A为逻辑基点：
- 与A不见面的玩家为好人
- A睁眼保或空给的好人（超过闭眼能给的力度）→ 一般为好人
- A强打的牌 → 偏向狼人
- A言之凿凿给的不见面（B和C）→ 一般确实不见面
```

## 双爆与狼队收益

```
双爆判定：
- 某些格局下狼人双爆收益更大
- 例：A给B查杀，B跳守卫，C给A查杀，警上无人跳守卫
  如果A是狼应自爆与守卫博刀 → 没自爆则A是预言家面大

狼队收益（判断狼队格局）：
1. 预言家验了7金水，7质疑，8强势站边你，9悍跳
   → 8是狼的概率低（不符合狼队收益——7都可能反水，狼没必要在队友起跳前冲票）

2. 你打B、C中肯定有狼，D顺着你盘谁更像狼
   → 如果B、C都是好人，D的好人面极高
   （狼人看到好人打错两个好人时，倾向于拱火而不是盘正逻辑）

3. 狼枪出局带的人 → 判定猎人打的是好人还是狼人

4. 警上后置位仅三张牌，A给B查杀，B跳平民，C再起跳
   → C的预言家面很高

5. 你的金水点出你的发言漏洞爆水，A反而觉得金水不该反水
   → A格式上不像冲锋狼

6. A给B查杀，C继续给B双查杀 → C预言家面高

7. A给B查杀，C给D查杀，B跳平民，D跳神，E对跳神站边C
   → B、C、E更倾向好人阵营

特别注意：
收益论是狼队做身份、洗团队的最常用手法之一。
狼队可能利用好人已有的错误结论，结合狼队收益加以利用：
例：预言家盘1、7、10不见面，好人认为10是狼，
悍跳狼反过来打1是狼。1冲锋投预言家看似不合收益论，
但1是利用了预言家不见面盘错了的逻辑，用收益论为自己洗身份。
```

## 位置学（争议话题）

```
数学上：纯随机分配下，位置学没有意义。
任何号码是任何身份的条件概率都相同。

网杀现实：身份分配是伪随机，给位置学留下应用空间。

更重要的是：即使位置学本身不成立，
当有很多人相信它时，它就变成了一个真实的影响因素。
```

### 位置学的实际用法

```
1. 分析他人是否信位置学
   - 用位置学打人的人 → 可能是新手/萌新，也可能是狼人借位置学强打
   - 用位置学保人的人 → 可能是真心相信，也可能是借机做高队友身份

2. 调整发言获取信任
   - 对信位置学的玩家：适当引用位置学逻辑来拉票
     "3是边角位，边角位必出狼，3的发言不好，我觉得3是狼"
     → 这套逻辑对不信的人没用，但对信的人很有效
   - 对不信位置学的玩家：用正逻辑分析，不要提位置

3. 狼人可以利用位置学
   - 狼人知道所有身份，可以"精准"使用位置学：
     "1、6、7、12是四个边角位，出了三狼，剩下一个在中间"
     → 听起来像精准分析，实际上是因为你睁眼知道
   - 但要注意：用得太多太精准反而暴露（好人哪有这么确定）
```
