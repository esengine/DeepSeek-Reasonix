# 决胜局战略指南

> 当狼人数 ≥ 好人数一半，或存活人数 ≤ 4 时触发

## 一、局势判断

### 决胜局条件
- 狼人数 ≥ 好人数（1:1 平衡）
- 存活人数 ≤ 4
- 关键神职存活（预言家/女巫）

### 局势紧迫度
- 🔴 **红色**：狼人数 ≥ 好人数（好人投错就输）
- 🟡 **黄色**：狼人数接近好人（局势紧张）
- 🟢 **绿色**：好人数量优势（但不能松懈）

## 二、博弈论应用

### 守卫 vs 狼人博弈矩阵

```
守卫的选择：守A / 守B / 空过
狼人的选择：刀A / 刀B / 刀C

                 狼刀A       狼刀B       狼刀C
守A(或空过)      A死(狼赢)   B活         C活
守B              A活         B死(狼赢)   C活
守C              A活         B活         C死(狼赢)

结论：
- 如果守卫固定守B：狼人必刀B → 守卫必输
- 最优策略：混合策略，以概率P守不同目标
- 如果守卫能猜到狼人"认为守卫会怎么守" → 千层饼
```

### 千层饼分析（Layer Cake）

```
第0层：狼人随机刀人
第1层：狼人刀最大威胁（预言家）
第2层：守卫守最大威胁（预言家）
第3层：狼人刀次要目标（女巫，因守卫守预）
第4层：守卫守次要目标（女巫，因狼会刀女巫）
第5层：狼人回头刀主要目标（没人想到）
...

实际应用：
- 高手对决：前3层最具相关性
- 普通局：前2层最具相关性
- 萌新局：只在第0-1层
```

### 女巫决胜局毒药博弈

```
场景：还剩4人，2狼 vs 1神+1民

女巫博弈：
- 救被刀的人 + 毒一个嫌疑狼
- 不救被刀的人 + 毒一个（可能只剩3人，1狼vs2好人）
- 全用或全不用

千层饼：
- L0：狼人刀神职（最大威胁）
- L1：女巫救神职 + 毒狼
- L2：狼人故意刀队友做深水狼（女巫不会毒队友）
- L3：女巫毒看起来像好人的人（反逻辑）
```

## 三、角色决胜局策略

### 狼人决胜局

**刀人优先级**：
1. 预言家（正视角，活过首日）
2. 女巫（保命，有解药/毒药）
3. 守卫（保护其他神职）
4. 猎人（死亡后开枪带走）
5. 村民（无技能）

**深水狼策略**：
- 活到最后，不被抗推
- 用正逻辑盘双边，不要上焦点位
- 发言要像闭眼好人

**倒钩狼策略**：
- 站边预言家，用正逻辑做自己好人面
- 帮真预归票狼队友
- 活到后期，找机会反水

### 预言家决胜局

**策略**：
- 尽快验出关键信息，带队归票
- 如果被查杀，可以要求守卫守你
- 警徽流传递信息，被刀后警徽飞金水

**与守卫配合**：
- 不要直接要求守卫守你（暴露信息）
- 可以在警徽流中暗示守卫
- 守卫可能守你，你不需要明说

### 女巫决胜局

**解药策略**：
- 救人优先级：预言家 > 守卫 > 猎人
- 如果被刀，考虑是否自救

**毒药策略**：
- 关键轮次前毒，打乱狼队节奏
- 不确定时宁可不毒

**跳身份时机**：
- 预言家被查杀，你需要正视角
- 场上局势混乱，需要女巫带队归票
- 你被多人怀疑，即将出局

### 守卫决胜局

**守人策略**：
- 守人优先级：预言家 > 女巫 > 猎人
- 与女巫配合，避免同守同救
- 博弈：狼人会分析你守谁，考虑反向思维

**空守策略**：
- 首夜推荐空过，获得信息优势
- 后续夜晚根据局势决定

### 猎人决胜局

**开枪策略**：
- 被投死/被刀死时开枪带走疑似狼
- 不确定时选择不开枪，保留威慑
- 开枪目标优先级：悍跳狼 > 冲锋狼 > 深水狼

**跳身份时机**：
- 带队归票需要正视角时
- 被多数人怀疑要出局时
- 作为最后一神需要定生死时

**残局生存**：
- 如果是最后一神，隐藏身份
- 跟票站边，不暴露
- 如果被投死 → 开枪带走投你的人中最像狼的

## 四、通用决胜局原则

1. **每一票都决定胜负**：谨慎投票，不要分票
2. **狼人数量 = 好人数量时**：狼人刀对就赢
3. **好人投对就赢**：但投错就输
4. **考虑对手的思考层级**：千层饼分析
5. **保持冷静**：不要被情绪左右判断

## 五、千层饼实战应用

### 场景：还剩4人，1狼+预言家+女巫+平民

**狼人视角**：
- L0：刀预言家（最大威胁）
- L1：守卫会守预言家
- L2：刀女巫（守卫会守预言家）
- L3：刀平民（没人想到）

**守卫视角**：
- L0：守预言家（最大威胁）
- L1：狼人会刀女巫（因我守预言家）
- L2：守女巫（因狼会刀女巫）
- L3：狼人会刀预言家（因没人守）

**结论**：
- 狼人和守卫都在博弈
- 混合策略是关键
- 不要固定一种打法

## 六、决胜局决策树

```
决胜局判断 → 是
    ↓
分析局势：狼人数 vs 好人数
    ↓
狼人数 ≥ 好人数 → 红色警报
    ↓
角色策略：
- 狼人：刀最大威胁
- 好人：保护最大威胁
    ↓
千层饼分析：
- 对手在第几层？
- 我在第几层？
- 最优策略是什么？
    ↓
执行策略 → 获胜
```
