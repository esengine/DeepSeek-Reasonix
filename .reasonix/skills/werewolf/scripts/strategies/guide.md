## 逻辑分类

```
正逻辑：从好人视角出发。"A是好人会怎么做？没做则可疑。"
反逻辑：从狼人视角出发。"B是狼会怎么做？没做则可能好人。"
伪逻辑：看似合理实际不成立。推理跳跃/以偏概全/忽视其他可能。

判断标准：正/反逻辑→符合概率经得起推敲；伪逻辑→存在漏洞。
```

## 选美难题

```
狼人杀是 Keynesian 选美博弈：
第一层：我的分析是什么？
第二层：对手会怎么分析我？
第三层：对手知道我知道他会怎么分析我？
第四层：……

深水狼的"90%真话"就是利用这一点——
说90%真话让好人放松警惕，在10%关键点上做文章。
高配局的关键：判断对手在哪个层级，打预期差。
```
