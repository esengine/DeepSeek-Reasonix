# ⚠️ 游戏实施说明

## 玩家标识：使用中文名字，没有编号

本策略体系原文使用 1号/2号/3号 等编号引用玩家。
**但在本引擎中，所有玩家使用中文名字（如"深哥""大克""O3"等），没有编号。**

GM 在引用任何策略文件前，务必在 prompt 中加一句：
```
注意：本局没有座位编号，玩家名字是：深哥、大克、O3……
请直接用名字，不要编造成"1号""2号"。
```

## 配置说明

所有规则开关在 `werewolf_config.json` 中，GM 通过 `config` 命令动态调整。
不要自行发明规则，不要脑补板子配置。

## 专精分配

每局开始前为每个 AI 分配专精卡片（`specializations.md`），
放入 prompt 开头，不应加载完整策略文件到 AI 上下文中。
