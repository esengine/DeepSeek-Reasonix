# 专题：语境分析

> 语境分析适用于中高端局（玩家逻辑成熟，好人狼人都有一定配置），
> 非常适合寻找逻辑爆点较少、发言好的狼人（表层逻辑不聊爆，但深层逻辑可以是狼人）。

## 核心理念

```
语境分析的核心：代入视角。
不是以自己的视角和要求判定身份，
而是代入到那个玩家的位置——他为什么会这么说？
他的语气、用词、情绪，和他已知的信息是否匹配？

好人的话和狼人的话，在逻辑上可能一样，
但在语境上不一样。
```

## 语境不见面

```
语境不见面比逻辑不见面更难伪装。
因为语境涉及语气、用词、情绪节奏——狼人可以编逻辑，
但很难同时控制语境的每一个细节。

### 案例1

1号："2号我一开始听你发言，跟3对跳预言家时，
我觉得你是想以卵击石，想挑战3号（高配玩家）高难度。
但是听着听着吧，我觉得你2号后面聊得还行，
我愿意警上先考虑你的预言家面。"
（语气一开始不屑）

分析：
- 1对2的那种质疑，很难是1、3两狼对着2预言家说出来的话
  （尤其结合不屑的语气）
- 用词"以卵击石"、不屑的语气，很难是3的狼同伴看到2辛苦起跳
  （而且发言还不错）时能对2说出来的话
- 结论：1跟3不见面，1跟2大概率不见面
- 1跟对跳2、3都没太见过 → 1的独立好人面很高

### 案例2

1号："2无论是好人还是狼人，高置位发言其实都挺亏的。"
→ 通过其心态，1、2语境疑似不见面

### 案例3

1号："2你这小办法挺好，把我给垫懵了。"
→ 1、2语境不见面
```

## 先入为主

```
好人在狼人杀里大多数都有"先入为主"的观念：
对于高置位发言的玩家，无法从逻辑层面给出确切定义时，
会从发言细节、语气、状态主观地给出一个定义。
这个定义给出后一般比较难更改，哪怕有新的逻辑支撑。

用法：
"先入为主"结合语境分析，可以帮助分析这个玩家是——
视角出现一定偏差的好人 → 还是
逻辑突然断层、睁眼在编造发言的狼人

如果一个人先入为主认为A是好人（因为A发言细节像好人），
后续即使A有逻辑问题他也倾向于解释而非改判 → 好人视角
如果一个人对A的定义可以随意切换（今天打A明天保A）→ 狼人视角
```

## 语境分析技巧总结

```
（1）语境分析适用于中高端局
    玩家逻辑成熟，好人狼人都有一定配置。
    非常适合寻找逻辑爆点较少但发言好的狼人——
    表层逻辑不聊爆，但深层逻辑可以是狼人。

（2）抓矛盾点
    判定存在矛盾点的玩家发言背后潜在的心路历程。
    分析语境：他到底是聊爆的狼人，还是语境上的好人？

（3）吞掉好人面的发言
    一般而言，不去故意做好人面，
    吞掉自己做好人身份的发言/视角/心态，
    → 都是语境上偏好的玩家。

（4）代入视角找好人
    如果场上有玩家能先于你点出：
    "A的打法不一定符合狼队收益"，
    甚至提出"可能是A对B的了解增加了她对B的敌意"，
    → 这个思路就是好人思路
    → 这个人好人面极高

    原因：
    a. 这首先是符合当下语境的一种可能情形，是正逻辑
    b. 这是狼人很难模拟的"找好人"而非"找抗推"的思路
    c. 此时无论A底牌是什么，推A才是更符合狼队收益的打法，
       狼人格式上没必要保A

（5）避免过度解读
    语境分析需要结合其他分析途径
    （视角、心态、不见面）综合判定，
    寻找深层逻辑的逻辑支撑。

（6）核心：代入视角
    不是以自己的视角和要求判定身份。
    如果你发现自己站在"上帝视角"在分析 → 停下来，
    回到那个玩家的位置重新思考。
```
