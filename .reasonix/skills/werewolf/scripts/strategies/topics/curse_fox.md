# 咒狐策略

> 咒狐（Curse Fox）— 被预言家查验时反噬而死，存活到最后则单独获胜。

## 核心机制

- **被验死**：如果预言家查验到咒狐 → 咒狐立即死亡
- **独立阵营**：咒狐不属于好人或狼人阵营
- **独赢条件**：游戏结束时咒狐存活 → 咒狐单独获胜（好人/狼人均不算赢）

## 策略要点

```
1. 你是第三方，你的唯一目标是活到最后
2. 不要暴露身份——预言家验到你你就死
3. 白天尽量低调，不要上焦点
4. 狼刀落在你身上时...自求多福
5. 跳身份要谨慎：跳预言家可能被真预查验，跳村民可能被狼刀
6. 最佳策略：做一个不起眼的划水村民
```

## GM 注意

- 咒狐的胜利判定在游戏结束时：如果咒狐存活，咒狐赢（优于好人/狼人胜利）
- 目前只实现了"被验出局"的基础逻辑，第三方独赢判定需手动裁定
