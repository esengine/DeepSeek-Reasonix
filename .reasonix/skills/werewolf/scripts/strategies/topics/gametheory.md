# 专题：狼人杀的理论模型与最优策略

> 狼人杀能不能通过建立理论模型得到最优策略？
> 答案：可以，但模型与现实的差距揭示了这游戏的本质。

## 简化模型1.0：纯随机（8平民 + 4狼人，屠城）

```
最简版本：没有任何技能，白天随机投票，夜间狼随机刀人。
来源：A mathematical model of the Mafia game (Migdał, 2013)

平民最优策略：白天所有人随机选择同一名玩家投票。
狼人最优策略：白天跟随平民投随机玩家，夜间随机刀平民。

12人局（4狼）狼人理论胜率：~71%
9人局（3狼）狼人理论胜率：~68%

结论：在毫无信息的情况下，
如果狼人可以完美模仿好人，狼人胜率极高。
```

## 简化模型2.0：+1预言家，生推

```
1预言家 + 7平民 + 4狼人。
预言家第一天起跳。狼人双爆刀死预言家。
剩下6平民 + 2狼人 → 回到1.0版本情况。
平民和狼人最优策略：随机选一名玩家出局。

狼人理论胜率：约高于1.0版本（因为预言家被刀后无信息）。
```

## 简化模型3.0：加入通信和策略

```
来源：Mafia: A theoretical study of players and coalitions
(Braverman et al., 2008) https://arxiv.org/pdf/math/0609534

允许玩家私下沟通，匿名投票。
核心策略分三阶段：

### 阶段1：预言家还活着
- 预言家随机验人（确认村民或狼人）
- 其他村民随机投票淘汰一名玩家
- 持续到特定天数或预言家被刀

### 阶段2：过渡阶段
- 预言家编制已验证为村民的列表（V列表，即金水列表）
- 加密发送给V列表每个成员
- 预言家请求村民投票淘汰自己
- 预言家出局后，V列表成员确认信息真实

### 阶段3：预言家出局后
- V列表中最小编号的幸存者随机选择V列表外一名玩家
- 所有V列表成员秘密投票淘汰该玩家
- V列表外村民弃权

意义：
策略中要求预言家先出局，再按照他的查验去投票→预防狼人悍跳。
村民可以选择放弃（预言家被刀且无人起跳时交牌）。
因为1.0版本已证明：当m/n为常数时，好人胜率趋近于0。
加入一个预言家，对局势的影响是巨大的——
也许好人必输的局有了翻盘的可能。
```

## 模型与现实的差距

```
目前最接近狼人杀游戏的模型是3.0版本。
但模型预测与实际体验有巨大差别，原因：

（1）理性假设不成立
    人不是理性的。
    哪怕玩家穷尽一生去理性思考，不同玩家对游戏的理解
    和不同的解读，都会导致不一样的结论。

（2）狼人无法完美复刻好人
    狼人无法完全复刻好人的心态、发言和行为。
    这使游戏不再是纯粹的客观推理游戏。

（3）模型过度简化
    模型只有一个预言家，无其他神职，屠城。
    实际游戏有女巫、猎人、守卫、白痴，
    还有屠边规则，信息量远大于模型。

（4）位置学和心理因素
    模型无法模拟位置学、玩家画像、跨局历史、
    情绪影响、语境分析等现实因素。

结论：狼人杀不是纯粹的数学推理游戏。
理论模型告诉我们概率的下限和上限，
但实际胜负取决于：
- 谁能更好地利用信息
- 谁能更好地伪装
- 谁能更好地理解对手
```

## 守卫-狼人博弈矩阵

### 基础矩阵（2狼 vs 守卫+预言家）

```
守卫\狼人    刀预言家    刀女巫    空过
守预言家     预言家存活   女巫死亡   预言家死亡
守女巫       预言家死亡   女巫存活   女巫死亡
空过         预言家死亡   女巫死亡   无人死亡

纳什均衡：双方都用混合策略（随机化选择）
```

### 千层饼分析（L0-L5）

```
L0（基础层）：
  狼人刀最大威胁（预言家）
  守卫守最大威胁（预言家）

L1（反向思维）：
  狼人预判守卫守预言家 → 刀女巫
  守卫预判狼人刀女巫 → 守女巫

L2（再反向）：
  狼人预判守卫守女巫 → 回头刀预言家
  守卫预判狼人回头刀预言家 → 守预言家

L3（混合策略）：
  双方都用随机策略（1/3概率选择每个选项）
  这是纳什均衡，无法被对手利用

L4（心态博弈）：
  分析对手的思考层级
  如果对手是L2，你用L3就能赢

L5（元博弈）：
  对手知道你在分析他的层级
  需要更高层的思考
```

### 实战应用

```
守卫决策树：
1. 有明确信息（预言家被查杀/女巫被刀）→ 守对应目标
2. 无明确信息 → 混合策略（随机守/空过）
3. 决胜局 → 必须混合策略，不能被读透

狼人决策树：
1. 有明确信息（守卫已跳/女巫已跳）→ 刀对应目标
2. 无明确信息 → 混合策略（随机刀/空过）
3. 决胜局 → 必须混合策略，不能被读透
```
