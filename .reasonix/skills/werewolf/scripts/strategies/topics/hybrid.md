# 混血儿策略

> 混血儿（Hybrid）— 首夜选择一名榜样玩家，与该玩家同阵营。

## 核心机制

- **首夜选榜样**：混血儿首夜选择一名存活玩家作为榜样
- **跟随阵营**：混血儿的胜利条件与榜样玩家相同
  - 榜样是好人 → 混血儿需要好人赢
  - 榜样是狼人 → 混血儿需要狼人赢
- **死亡不影响**：榜样死亡后，混血儿仍保持该阵营归属

## 策略要点

```
1. 选择榜样时，尽量选发言好、逻辑强的玩家
2. 如果你是好人阵营，做好人的本分
3. 如果你是狼人阵营，想办法帮狼人
4. 不要暴露你是混血儿——没人知道你的阵营
5. 榜样死了也不要紧，你仍然是他的阵营
```

## GM 操作

混血儿的榜样选择在 init 之后通过额外命令指定（将来实现）。
目前混血儿的阵营归属性作为村民处理，GM 需手动跟踪。
