# 专题：不见面关系分析

> 不见面关系是树立大局观、找预言家和找狼人的强有力工具。
> 尤其适用于怂狼单边预、或狼双爆刀死预言家的生推局。

## 不见面等级

```
建议对不见面划分等级：
铁不见面 > 大概率不见面 > 弱不见面

谨记：
- 最硬的不见面一定是特定语境下触发的——
  两张牌潜意识里发自肺腑的对话或默认视角关系
- 常见的不见面模板结论，尽量给到"弱不见面"
- 因为不见面只要有万能公式，就可以用来做不见面
```

## 好人的不见面分析

### 1. 发言不见面

```
（1）默认底牌好人
    超越闭眼视角能给的好人程度 → 倾向于不见面

（2）情绪发言
    A用情绪发言对话B，且情绪像发自内心而非表演
    → 铁不见面 / 大概率不见面

（3）B打A是狼，A花大篇幅给B解释
    → 弱不见面

（4）A输出B的逻辑瑕疵，却保了B
    → 弱不见面
    A保了B，却说"对B拿好人的发言还有一点不满意"
    → 强一些的不见面

注意：(3)(4)都不是铁不见面，都是狼人可以做身份的手段。
```

### 2. 行为不见面

```
（1）警上快速过麦给压力（大概率不见面）
    3发言："我是预言家，我昨晚验了……"
    然后快速过麦到4。
    如果4起跳，3、4见面可能性偏低。
    因为队友不知道你会立刻过麦，可能还在构思自己的发言，
    快速过麦后很可能导致队友发言变形。

（2）用场外/数据库打警下的玩家（大概率不见面）
    "1号你不是好人习惯上警点评吗，这局怎么龟龟索索待警下了？
    你拿狼了吧，待警下准备给队友冲锋。"
    → 数据库打场下给压力

    "难得这么久来组局玩一局，1号你是好人不可能不上警聊聊吧"
    → 场外正逻辑打警下

（3）越塔强杀/保人
    A保了B，C保B却打了保B的A：
    → C和B不见面，C和A不一定不见面
    原因：狼人看到好人保队友，没必要保队友的同时去攻打保队友的好人。
    但队友保好人的情况下，有些狼人仍会选择打自己同伴做不见面。

    A保了B，C打B是狼，同时又保A（认为A是保错B的好人）：
    → A和C不见面，但B和C不一定不见面
    原因：狼队友保了你队友B，你打B的同时一般不会去保打B的狼同伴A。
    但C可能想跟B强拉不见面，或觉得B发言确实不好，仍可能打B空给A好人身份。
```

## 狼人如何做不见面关系


## 银水相关不见面

```
A. 没有人会选择强打银水的同时，去强站边自己的队友或强保自己的狼同伴
   → 大概率不见面

B. 如果有人恰好聊到了刀口（且刀口是对的），有人去保他
   → 聊刀口的人为狼的概率偏低（拿狼聊对刀口=变相自杀）
   → 保他的人好人面更高
   → 这两张牌见面的概率几乎为零 → 铁不见面

C. A说B的发言大概率是女巫
   → A和B见面概率偏低
   → 狼一般不会给队友穿女巫衣服，容易拉起女巫仇恨送队友吃毒
   → 弱不见面
```

## 站边真预互打

```
A和B同时倒钩预言家。B发言没有大问题，但A打B是倒钩狼。
→ 一般而言不太见面。

原因：狼倒钩已经轮次落后了，更需要积身份做好人面、不上焦点。
狼在这个情况下不太能把倒钩的狼同伴和自己打到焦点位。
→ 大概率不见面
```

## 金水反馈

```
A接到B金水后，外置位去拉仇恨，去攻击站边B的牌
→ A和B见面概率偏低

A接到B金水后，警上去攻击警下的牌
（听了对跳发言，觉得他视角卖出警下谁和谁像狼）
→ A和B见面概率偏低

B在前置位胡言乱语、强打警上、得罪警下
A后跳给B金水
→ 见面可能偏低一点
```

## 疑似见面的发言（好人识别狼队友）

```
（1）两张强打的牌，或在狼队劣势局强做对立面的牌

（2）狼狼金：
    A. "2号牌，你是我金水，我拿狼不会给你洗头，我肯定不会骗你，你一定要跟我走。"
       → 路人局这两张牌见面的概率偏大
    B. 接到金水后莫名其妙想反水，尤其是在给后置位金水有力度的情况下

（3）A跟B对前置点评视角完全一致或完全不一致
    A视角缺失B置之不提
    → A和B疑似见面

（4）空给不见面：
    A空给B、C不见面时，有两种情形：
    a. 睁眼给两个好人不见面→去做自己好人面
    b. B和C都是狼→给不见面去包装自己的同伴
    → 如果能盘到是b，就是找三狼血赚

（5）高置位隔空对话：
    "7号牌，好久没跟你玩了，上警先跟你打个招呼先"
    "5号牌我今天就听你，就打5的退水流……"
    → 偏新手的局里可判断不见面
    → 中高端局里是两个狼很常见的做身份手段
    → 衍生：如果两张牌有强做不见面的迹象，他们见面的概率在增加
```

## 狼人如何做不见面关系

### 1. 夜间没有沟通过（装作）

"哇，7号牌的声音好好听，我好喜欢，7一开口不管他是不是狼，
我都想给他标个好人。"
→ 装作夜间没有和7沟通过

"哇，这7居然是个男的，他起跳前我看他这头像还以为是个女生。"
→ 闲聊场外暗示不认识

### 2. 半嘲语气做不见面

"这7不能跳吧，我上局才被你骗过，你跳了我不信啊。
你跳了就是狼，你是预言家我就当第五匹狼。"
→ 给队友压力装作不见面

"8号牌，你跳得太差了，你队友估计得被你气死了哈哈哈。"
→ 装作不在意狼同伴

"9号牌你发言发得非常好啊，发得就快告诉我你是狼人身份呢。"
→ 半嘲语气

"9号牌，你要是个好人，就离了个大谱了。"
→ 语气做不见面

### 3. 默认队友好人

"5号牌我觉得你发言是好人，但最近你站边一点都不稳，
我要跟你反着站边。"
→ 默认5是好人

"5号牌，我不能打你打太死了，一会儿万一你是好人又要打我是铁狼了。"
→ 怕得罪5做不见面

"我没有想到3会悍跳给我查杀啊。我觉得前置位最像好人是5号牌……"
→ 接查杀后用正逻辑铁保前置位发言还不错的5号狼同伴

### 4. 给队友解释

狼队友打了你是狼，你警下装作掏心掏肺地给队友解释。
或者遗言出局，就逮着某个队友对话几十秒：
"我是狼真没有必要如何如何……"
→ 让外置位好人以为你们不见面

### 5. 给队友穿神衣服

2号："1号牌感觉你不像是平民，一会儿如果你有身份的话就直接拍出来，
怕外置位推错你了。"
1号："2你想要我身份啊，我不给你，我就感觉你是狼在找身份。
今天又不是我上PK，你们狼人想知道我什么身份就夜间拿刀来抿抿。"
→ 中高端局抿队友底牌是神，是比较有效的做不见面方式

### 6. 高强度的独立面

"2号牌，你就是送给女巫的礼物，女巫今晚就把2毒了。"
"骑士，你一会儿就戳4，4这不是铁狼发言吗？"
→ 用高强度发言显示自己独立判断

### 7. 让预言家把警徽留到冲锋的狼同伴

尤其在好人大多站对边、其他三个狼同伴都处在冲锋的焦点位时，
卖掉多个队友，甚至让预言家验同伴，是自保的一种好方法。

## 狼查杀狼场景

```
A、B对跳，A给C查杀。D站B，却盘A、C狼查杀狼。

D和B、C不见面，且不见面程度偏高。
→ 因为D和BC是同伴的话，盘狼查杀狼就要出狼同伴C。
  D选择冲锋就应该去冲预言家，而不是去投自己的狼同伴。

D和A也不太见面，但程度弱一些。
→ D倒钩B的同时不出狼同伴A，去归外置位的好人C，
  不一定能拉到真预B的好感度。
→ 例外：C发言非常差时，D倒钩B可以选择抗推好人C。
```

## 警下投票不见面

```
已知警下A是狼，警下C投票给外置位非对跳的牌D。
→ C和A、C和D都存在不见面关系。

原因：两狼警下C是狼，可以选择冲锋确保拿警徽；
或者直接倒钩投票给预言家去做身份。
没必要分票投给外置位——既无法让队友拿警徽，
也做不了自己在预言家心中的好人面。

极限情况：狼习惯倒钩，真预和狼同伴发言五五开，
C不想冲也不想投预言家，最后投给警上被多人质疑的外置位好人。
此行为博得全场好感度，最后狼队获胜。
```

## 利用不见面的技巧

```
（1）判断预言家
    A、B你盘出来一定不见面。A起跳，C给B查杀。
    → 无关C发言，C的预言家面偏低。

（2）逻辑匪
    不见面盘完以后，发现只剩下唯一位置对应四个狼坑里的最后一个。
    → 那张牌狼面偏高。
    → 游戏中着重听他的发言及其卖的视角。

（3）逻辑好人
    跟两张对立阵营都没见过面的牌是逻辑好人。
    A给B查杀，或A、B对跳。
    C跟A、B都没见过。
    → 无论分不分得清A和B谁是狼，C都是逻辑好人。

（4）A、B、C互相不见面
    已知A、B不见面，A、C不见面。
    着重关注B、C是不是不见面。
    如果是 → A、B、C中至多只有一个狼。
    很便于确定外置位的狼坑位。

（5）检验不见面关系硬不硬
    除了听A发言如何聊B、定义B以外，
    最好还听听B发言时是如何反馈A的。
```
