# 专题：贝叶斯说服博弈模型

> 狼人杀的本质是一种不完全信息的动态博弈。
> 严格地说，可以化为一个**动态贝叶斯说服博弈**（Bayesian Persuasion Game）。
> 核心在于传递信号（发言）改变他人信念与行动，而非直接控制对方行动。

## 模型总览

```
从模型到狼人杀，分为三个层次：

先验概率（Prior）     → 数据库：对玩家既有的信息和印象
贝叶斯估计            → 听发言、解读发言、通过话术与投票更新身份判断
贝叶斯说服            → 发言和投票环节：通过信号影响他人的后验更新
```

## 第一步：先验概率（数据库）

```
在玩家尚未发言之前，已有的了解构成"先验信息"。

熟人局：对该玩家水平与风格的认知——
是否习惯上警？是否偏好悍跳？习惯冲锋还是倒钩？

路人局：来自玩家的战绩——阶数、胜率、投票率等。

例："这个玩家四阶居然只有这种程度的思考和发言，不太像好人"
→ 利用先验概率（阶数高→逻辑水平高）与当前发言的不匹配推断身份。
```

## 第二步：贝叶斯估计（Bayesian Updating）

```
这是狼人杀的核心。玩家通过每一轮的发言，
不断更新场上所有玩家的身份信息。

每个玩家的发言都可以帮助更新所有玩家的定义——
通过"不见面关系"、卖出的视角、狼队格局反推其他玩家的身份。

### 推理三步骤（高手版）

1. 水平评估（Type Estimation）
   判断玩家的综合水平：萌新、入门、中等、高手。
   对不同水平采用不同的估计算法：
   - 萌新：用碎话和人性层面心态分析更有效
     （水平低，很难做出一段像好人的发言细节）
   - 高手：用打法思路与语境分析更准确
     （表演成分重，但语境和思路难以完全模拟）

2. 身份估计（Identity Estimation）
   结合已有数据库和水平分类，推断身份——
   平民/狼人/各类神职的概率。

3. 信念估计（Belief Estimation）
   结合数据库和发言，整理每名玩家对其余所有玩家身份类别的估计。
```

### Harsanyi Type 形式化

```
每个玩家的 Harsanyi type 可以形式化为两个核心组成部分：

1. 自身类别：汇总该玩家所有胜负体验的"属性信息"
   = 身份 + 水平 + 打法 + 性格 + 临场状态
   这些要素决定了玩家在博弈中如何评价结果。

2. 信念：刻画玩家对其他人类型的条件分布
   = 对他人"身份 + 信念"的估计
   = 关于他人类型的概率信念
```

### 身份估计的四维度

```
第一层逻辑：视角与思考量
  努力覆盖场上大多数玩家的思考量，分析其整体视角——
  是否"睁眼"？是否缺失？
  是否因扭曲而不符合正常闭眼玩家的推理方式？

第二层逻辑：思路与语境
  代入玩家视角，整理其发言背后的整体思路与语境。
  模仿好人的思路比模仿闭眼视角更为困难，
  所以思路与语境分析能有效降低对高配玩家的身份判断错误。

第一层心态：情绪、碎话与听感
  观察小碎话或不经意的情绪是否容易被狼人伪造。

第二层心态：人性、行为动机与潜意识心理
  从潜意识中未说出口的话推断身份更接近好人还是狼人。
```

### 信息差与阵营差异

```
狼人：高信息玩家（开眼就知道所有身份）
  → 必须在白天伪装成低信息的好人
  → 目标是抗推人数占优的低信息好人

好人：低信息玩家
  → 在信息不足的情况下不断推理
  → 目标是找出并抗推人数劣势的高信息狼人

信息差 → 视角差异 → 逻辑流
获胜条件差异 → 心态不同 → 状态流/人性流
```

## 第三步：贝叶斯说服（Bayesian Persuasion）

```
在狼人杀中，贝叶斯说服的核心体现在发言环节。

作为好人：已经对场上不同玩家的身份形成概率性估计。
作为狼人：先听取前置位发言，把握整体风向，
          然后"优化"选择自己的发言内容，
          通过传递信号影响他人的后验更新，
          最终改变他们的投票取向和技能使用。

多数好人玩家遵循 truth-telling（如实披露）原则。
但在实际博弈中，完全披露不一定是最优策略。
```

### 技巧A：高阶信念（Higher-order Beliefs）

```
就是狼人杀中常见的"你知道我知道你知道"，
或者很多人说的"第几层"逻辑。

在贝叶斯博弈中：
通过他人发言反推出他们的视角，
得到每个玩家对其他玩家身份的贝叶斯估计（后验概率分布）。

你的发言需要考虑场上的主要趋势：
- 首先要被人信服你是好人，你的话才会被采纳
- 贸然给出一段别人不一定能接受的逻辑，哪怕结论是对的，
  别人也不一定会接受，甚至打你是狼
- 抑或采纳你的结论，但认为你是一个开眼的狼人
```

### 技巧B：玩家水平差异（Type）

```
评估场上好人和狼人的整体水平，选择不同的说服策略：

高配局（多数是高配玩家）：
  → 输出更多正向逻辑
  → 说明那些看似的漏洞为什么可以接受
  → 为什么只能是好人才能说出，狼人很难有这样的发言或视角

低配局（多数是新手）：
  → 与其讲大量复杂逻辑，不如用真诚的态度
  → 挑出所有观点里最有效的那个
  → 语重心长地告诉他们这个关键点
  → 往往有更高的接受度
```

### 技巧C：狼人博弈反馈（Response）

```
基于贝叶斯评估，预估"谁更像狼人"以及他们面对你行动的策略反馈。

例：你判断A为真预、B为悍跳，且B有号召力与逻辑水平。
你本可用四条逻辑为A站边，但若其中最后一条不够严谨、
较为主观、且易被高配狼人抓住利用：
→ 最优策略就是省略这条
→ 只输出前三条更稳健的正向逻辑
→ 避免给会玩的狼人以"你们是双狼"打冲锋的利用空间

本质：针对对手可能的 best response 进行前置防御——
在发言阶段做"去噪/去风险"处理，
用更难被反驳的证据推动他人的后验朝你期望方向移动。
```

### 信息设计实例

```
A被许多人认定身份偏下。你听懂他们的逻辑，
也知道这种判断带有主观性，但你凭听感认为A身份偏上。

由于A不是焦点位：
→ "我觉得A确实有你们提到的问题，看起来不太好，
   但我不打死他，警下再听听。"
→ 既不会失去玩家对你的信任
→ 也不会丢轮次（因为他不在今天的核心焦点位）
→ 降低风险：如果你判断错误而A是狼人，过度辩护会让你被反推

结论：truth-telling 不是最优策略。
根据场上形势做"信息设计"，选择性披露，才是更优解。
```

## 模型局限：说服游戏的边界

```
以上模型推导出一个结论：狼人杀是贝叶斯说服博弈，
核心是信息设计和信号传递。
但这个理解有一个根本性的裂缝。

### 守卫 vs 狼人的博弈矩阵

收益矩阵（好人方相对收益）：

             狼人刀预言家    狼人刀女巫
守预言家    平安夜+预言家    女巫阵亡
            存活价值         损失女巫价值
守女巫      预言家阵亡       平安夜+女巫
            损失预言家价值   存活价值

→ 不存在纯策略纳什均衡
→ 只存在混合策略均衡（守卫以p概率守预，狼人以q概率刀预）

### 千层饼问题

真实情况中，玩家不会测算收益矩阵再按概率投骰子。
玩家是 Naive Player（简单型玩家）：
- 对核心收益点做粗略比较
- 推测狼人更可能的刀法
- 基于推测做一个"确定性"的选择

这时你的最优策略取决于你认为狼人觉得你在第几层：
- 第一层（守预言家）→ 狼人可能刀女巫
- 第二层（猜到狼人会刀女巫→守女巫）→ 狼人可能刀预言家
- 第三层？第四层？

真相：实际对局中，只有前两层的信念最具相关性。
更高层次的"反反逻辑"几乎不会真正进入玩家的决策空间。

### 说服模型的裂缝

即便你拥有足以说服全场的口才——
如果找不到狼人，你最终呼吁投出去的仍然是好人。
在狼人眼中，你反而成了好人团队的小丑。

从概率上，你更多是好人。
要想把游戏玩好，核心仍然在于：

  找到狼人。

如果存在口才极强、能够带节奏的狼人，
作为好人想要获胜，就必须识别他们，抵御他们的操纵。
不能被他们的语言所迷惑。

反过来，当你能够从更深层次的视角和心态分析中
识别出他们是狼人时——

对于狼人而言，这个游戏也就不再是一个
单纯依靠口才的说服游戏。

结论：贝叶斯说服模型描述了游戏的"表层机制"——
信息如何传递、信念如何更新。
但游戏的"深层本质"仍然是：
谁能更准确地识别身份，谁就赢了。
说服只是手段，识别才是核心。
```
