# 技能触发顺序设计

> 参考三国杀的阶段触发机制，严格指定触发顺序

## 夜间阶段（串行执行）

```
┌─ 阶段1: 守卫守护 ─────────────────────────────┐
│  触发: 每夜                                    │
│  约束: 不能连续两晚守同一人                      │
│  结果: 设置 guard_protected 标记                │
└────────────────────────────────────────────────┘
         ↓
┌─ 阶段2: 狼人刀人 ─────────────────────────────┐
│  触发: 每夜                                    │
│  约束: 默认不能刀队友（wolf_self_kill=false）    │
│  结果: 确定 kill_target                         │
└────────────────────────────────────────────────┘
         ↓
┌─ 阶段3: 女巫行动 ─────────────────────────────┐
│  触发: 有人被刀时                               │
│  分支:                                         │
│    有解药 → 问救不救（同夜不能用两瓶药）          │
│    解药已用 → 问毒不毒                          │
│    都没了 → 跳过                                │
│  结果: 设置 witch_saved / poisoned 标记          │
│  特殊: 毒药无视守卫防御                          │
└────────────────────────────────────────────────┘
         ↓
┌─ 阶段4: 死亡判定 ─────────────────────────────┐
│  触发: 自动                                    │
│  逻辑:                                         │
│    1. 被毒 → 直接死亡（can_hunter_shoot=false）  │
│    2. 被刀 + 守卫守护 → 死亡（同守同救=死）      │
│    3. 被刀 + 女巫救 → 存活                      │
│    4. 被刀 + 无守护无救人 → 死亡                 │
│  结果: 更新 alive 状态                          │
└────────────────────────────────────────────────┘
         ↓
┌─ 阶段5: 预言家查验 ───────────────────────────┐
│  触发: 每夜（即使被刀仍可查验）                  │
│  结果: 输出查验结果（好人/狼人）                 │
└────────────────────────────────────────────────┘
         ↓
┌─ 阶段6: 夜间死亡遗言 ─────────────────────────┐
│  触发: 有人夜间死亡时                           │
│  条件: 首夜 或 night_kill_last_words=true        │
│  顺序: 死亡 → 遗言 → 猎人开枪（如果被刀）       │
│  注意: 被毒死的猎人不能开枪                      │
└────────────────────────────────────────────────┘
```

## 白天阶段（串行执行）

```
┌─ 阶段1: 发言 ─────────────────────────────────┐
│  触发: 每天                                    │
│  顺序: 奇顺偶逆（警长决定起始位置）              │
│  约束: 白痴翻牌后仍可发言                       │
└────────────────────────────────────────────────┘
         ↓
┌─ 阶段2: 投票 ─────────────────────────────────┐
│  触发: 发言完毕后                              │
│  约束: 白痴翻牌后不能投票                       │
│  结果: 确定被处决者（或平票进入再投）            │
└────────────────────────────────────────────────┘
         ↓
┌─ 阶段3: 处决 ─────────────────────────────────┐
│  触发: 有最高票且非平票时                       │
│  子阶段:                                       │
│                                                                   │
│  ┌─ 3a: 白痴翻牌 ──────────────────────────┐  │
│  │  触发: 被处决者是白痴且未翻牌             │  │
│  │  询问: 是否翻牌？                         │  │
│  │  结果: 翻牌→不死，失去投票权              │  │
│  │        不翻牌→正常死亡                    │  │
│  └──────────────────────────────────────────┘  │
│         ↓                                       │
│  ┌─ 3b: 处决者遗言 ────────────────────────┐  │
│  │  触发: 被处决者死亡后                     │  │
│  │  内容: 可以发表遗言（不限字数）            │  │
│  │  顺序: 先遗言，再问猎人/狼王开枪          │  │
│  │  趣味: 增加戏剧性，让死者有机会反击       │  │
│  └──────────────────────────────────────────┘  │
│         ↓                                       │
│  ┌─ 3c: 猎人/狼王开枪 ─────────────────────┐  │
│  │  触发: 被处决者是猎人/狼王                │  │
│  │  询问: 是否开枪？带谁？                   │  │
│  │  条件: 猎人被毒杀不能开枪                 │  │
│  │  结果: 开枪→带走一人（被带走者也有遗言）  │  │
│  │        不开枪→游戏继续                    │  │
│  └──────────────────────────────────────────┘  │
│         ↓                                       │
│  ┌─ 3d: 被带走者遗言 ──────────────────────┐  │
│  │  触发: 猎人/狼王开枪带走一人后            │  │
│  │  内容: 被带走者可以发表遗言               │  │
│  │  趣味: 被带走者也有机会反击或揭露信息     │  │
│  └──────────────────────────────────────────┘  │
│         ↓                                       │
│  ┌─ 3e: 机械狼开枪 ────────────────────────┐  │
│  │  触发: 被处决者是机械狼（非模仿模式）      │  │
│  │  询问: 是否开枪？带谁？                   │  │
│  │  结果: 开枪→带走一人（被带走者也有遗言）  │  │
│  └──────────────────────────────────────────┘  │
└────────────────────────────────────────────────┘
         ↓
┌─ 阶段4: 警长传徽 ─────────────────────────────┐
│  触发: 警长死亡时（包括被处决、被开枪带走）      │
│  询问: 警长要传给谁？                          │
│  结果: 传给指定玩家，或警徽流失                 │
└────────────────────────────────────────────────┘
         ↓
┌─ 阶段5: 胜负判定 ─────────────────────────────┐
│  触发: 每次死亡后                              │
│  逻辑:                                         │
│    好人胜: 狼人全灭                             │
│    狼人胜: 狼人数 >= 好人数                     │
└────────────────────────────────────────────────┘
```

## 遗言系统设计

### 遗言触发时机

| 死亡类型 | 是否有遗言 | 触发时机 |
|---------|-----------|---------|
| 被投票处决 | ✅ 有 | 处决后立即 |
| 被猎人开枪带走 | ✅ 有 | 开枪后立即 |
| 被狼王开枪带走 | ✅ 有 | 开枪后立即 |
| 被机械狼开枪带走 | ✅ 有 | 开枪后立即 |
| 被狼刀死 | ⚠️ 条件 | 首夜或配置开启 |
| 被女巫毒死 | ❌ 无 | - |

### 遗言顺序（增加趣味性）

```
被处决者遗言 → 猎人/狼王开枪 → 被带走者遗言
```

**设计理由**：
1. 被处决者先说遗言，有机会揭露信息或反击
2. 猎人/狼王听到遗言后决定是否开枪、带谁
3. 被带走者也有遗言机会，增加戏剧性

### 遗言内容限制

- 被处决者遗言：不限字数，可以说任何信息
- 被带走者遗言：不限字数，可以说任何信息
- 注意：遗言不能影响游戏机制（只是信息传递）

## 特殊技能触发时机

| 技能 | 触发时机 | 前置条件 | 结果 |
|------|---------|---------|------|
| 守卫守护 | 夜间阶段1 | 每夜 | 保护目标免受狼刀 |
| 狼人刀人 | 夜间阶段2 | 每夜 | 击杀目标 |
| 女巫救人 | 夜间阶段3 | 有解药+有人被刀 | 目标存活 |
| 女巫毒人 | 夜间阶段3 | 有毒药+已过首夜 | 目标死亡（无视守卫） |
| 预言家查验 | 夜间阶段5 | 每夜 | 获知目标身份 |
| 白痴翻牌 | 白天阶段3a | 被处决时 | 不死，失去投票权 |
| 猎人开枪（被动） | 白天阶段3c | 被处决时 | 带走一人（被毒杀不能） |
| 猎人开枪（主动） | 白天任意 | hunter_active_shot=true | 带走一人（猎人也死） |
| 狼王开枪 | 白天阶段3c | 被处决时 | 带走一人 |
| 机械狼开枪 | 白天阶段3e | 被处决时 | 带走一人（非模仿模式） |

## 关键交互规则

1. **同守同救**: 守卫和女巫同夜保护同一人 → 该人仍死亡
2. **毒杀禁枪**: 猎人被毒死不能开枪（can_hunter_shoot=false）
3. **女巫自救**: 仅首夜可自救（witch_self_save_n1=true）
4. **守卫连守**: 不能连续两晚守同一人
5. **女巫双药**: 同夜不能用两瓶药（救/毒二选一）
6. **遗言顺序**: 被处决者遗言 → 开枪 → 被带走者遗言
