# Reasonix 工具自我测试计划

**测试日期**: 2026-06-07  
**测试目录**: `my-test/20260607_142457/`
**测试目的**: 系统性验证 Reasonix 代理各项核心工具能否正常工作，发现失败时报告并分析原因（不修改）。

## 被测工具清单

本测试覆盖以下工具类别：

| 类别 | 工具 | 说明 |
|------|------|------|
| 目录/文件列表 | `ls`, `glob` | 列举目录内容、按模式查找文件 |
| 文件写入 | `write_file` | 创建/覆盖文件，自动创建父目录 |
| 文件读取 | `read_file` | 读取文件内容，支持行偏移 |
| 文件编辑 | `edit_file`, `multi_edit` | 精确字符串替换、批量原子编辑 |
| 文件搜索 | `grep` | 正则搜索文件内容 |
| 文件/符号删除 | `delete_range`, `delete_symbol` | 按锚点删除范围、按 AST 删除 Go 符号 |
| Shell 执行 | `bash` | 执行任意 shell 命令 |

## 判定标准

- **PASS**: 输出与预期一致，无异常
- **FAIL**: 工具返回错误、抛出异常、或行为与预期不符
- **WARN**: 工具能工作但行为有细微差异（如输出格式不同）

每个 FAIL 需记录：
1. 错误信息
2. 可能原因分析
3. 是工具实现缺陷还是外部环境问题
