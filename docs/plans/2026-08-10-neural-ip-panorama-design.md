# intelifar 可缩放 IP 神经网络全景设计

## 1. 目标

将当前以白色资产卡片为主的关系图升级为可缩放、可平移的 IP 神经网络全景。视觉上借鉴知识图谱产品的“无限画布、发光节点、密集连接”体验，但不复制任何具体产品界面。最终视图必须继续回答企业用户的实际问题：哪些资产最关键、关系是否已确认、某项资产的一跳影响是什么，以及结论能否回到证据。

## 2. 方案比较

### A. WebGL 三维力导向图

视觉冲击最强，也能承载大量粒子；但会增加渲染依赖、显卡兼容性、截图不确定性和无障碍成本。三维遮挡还会降低关系复核效率，不适合当前小微企业版本。

### B. Canvas 二维力导向图

在几千节点下性能良好，但节点、关系和焦点状态需要另建可访问 DOM，现有键盘与 E2E 契约需要大幅重写。

### C. 原生 SVG 语义神经网络（采用）

保留现有确定性布局、权限裁剪、关系点击和键盘访问，在 SVG 内增加相机变换、语义缩放、神经节点、关系辉光与深色空间画布。当前 API 将单次全景限制在 100 个节点和 200 条边，SVG 足以稳定承载，同时不增加第三方依赖。

## 3. 视觉层级

- 外层继续使用 intelifar 的浅色企业工作台，网络画布使用深蓝黑空间，不把整页改成娱乐化“赛博屏”。
- 节点由卡片改为发光核心：大小反映直接关系数，颜色反映资产类型，外环反映当前选择或核心程度。
- 已确认关系使用低亮度连续曲线和局部辉光；待复核关系使用虚线，始终保持状态可辨认。
- 标签随缩放分层：远景只保留核心节点与简短名称，中景显示资产类型，近景补充编号与置信度。
- 右侧检查器继续提供权属、密级、证据和一跳聚焦，避免仅靠图形传达关键业务信息。

## 4. 相机与交互

相机状态由 `x`、`y`、`scale` 组成，缩放范围为 35%–240%。滚轮以指针位置为锚缩放；拖拽空白画布执行平移；双指触控同时支持平移与缩放；按钮提供等价操作；“适配全景”恢复初始视野。节点、关系、检查器和筛选器不参与画布拖拽。

缩放不会改变后端查询或权限边界。聚焦一跳、类型筛选、关系筛选和搜索仍重新生成一个受限子图，然后将相机恢复到适配位置，防止用户落在空白视区。

## 5. 可访问性与降级

- 节点与关系继续是可聚焦 SVG 元素，保留 `role`、完整中文 `aria-label`、Enter/Space 和 Escape 操作。
- 图下方继续提供等价关系清单，确保不依赖颜色、精细指针或空间认知。
- 画布提供明确的缩放百分比与当前层级文字；所有按钮有可读名称。
- `prefers-reduced-motion` 下关闭辉光脉冲与过渡；高对比焦点环不依赖动画。
- 移动端不再使用固定 900px 宽画布和平移补偿，改为自适应容器与触控相机，避免页面级横向溢出。

## 6. 验收标准

1. 滚轮、缩放按钮和触控可在 35%–240% 内改变相机，并保持锚点稳定。
2. 拖拽空白画布会改变平移状态，点击节点仍打开资产检查器。
3. 远、中、近三种语义层级正确切换标签密度。
4. 已确认与待复核关系可视状态、点击命中和复核流程均保持有效。
5. 键盘聚焦、关系清单、移动端无横向溢出和权限裁剪测试全部通过。
6. 交付新的桌面与移动端真实 UI 截图。
