# Semantica 第二阶段实施计划

## Task 1：持久化状态机

**输出：** `semantic_reviews` 表、确定性候选指纹、白名单字段裁剪、列表和决定方法。

**验证：** 先编写失败测试，覆盖重复检查幂等、终态不可改判、跨工作空间不可见、审计同事务提交。

## Task 2：管理员接口

**输出：** 复核列表、一次性决定接口，以及体检结果与复核记录的关联。

**验证：** 管理员可操作；编辑者和只读成员返回 403；无效决定返回 400；已决定返回 409。

## Task 3：系统页与待办中心

**输出：** 可恢复的复核列表、状态标签、决定确认对话框、管理员待办入口。

**验证：** DOM 契约测试和浏览器交互测试覆盖两个决定分支、错误提示、刷新恢复和移动端布局。

## Task 4：完整验证与交付证据

**输出：** 真实 UI 截图、E2E 报告、更新后的交付说明。

**验证：** 运行 Node/Python 测试、Astro 构建、真实 Semantica E2E、浏览器 E2E、`npm audit`、凭据扫描和 `git diff --check`。
