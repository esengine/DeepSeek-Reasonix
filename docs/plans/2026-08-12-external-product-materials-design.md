# intelifar 对外产品材料设计

## 沟通目标

潜在客户读完后应相信：intelifar 能把分散在长文档中的知识产权内容转化为可检索、可追溯、可治理、可安全复用的企业知识资产。潜在投资人读完后应看到：产品已形成从解析、结构化、证据链、关系网络到受控任务代理的一体化能力，并具备沿文档量、团队数和治理深度扩展的产品基础。

## 采用方案

采用“一套事实底座、两种阅读深度”。DOCX 作为完整产品说明和会后留资材料，PPTX 作为 15 分钟现场演示主线。两者只陈述当前代码、真实 UI 和自动化测试已经验证的能力，不使用虚构客户、收入、市场规模、节省比例或投资回报数字。

## 核心叙事

1. 企业重要知识仍被锁在 PDF、Word、PPT、图片和历史资料中。
2. intelifar 不止生成摘要，而是形成“文档 - IP 资产 - 原文证据 - Wiki - 关系网络 - 治理记录”的连续链路。
3. MinerU 负责版面与内容解析，DeepSeek 负责受约束的结构化分析，Semantica 在本地提供语义治理建议；所有正式变化仍经过权限和人工复核。
4. 可缩放 IP 全景网络和受控 IP 任务助手让企业能够从“查一份文档”升级到“理解资产之间的影响”。
5. 权限、版本、脱敏分享、审计、备份和能力边界使产品具备小微企业可直接使用、并向企业基础设施适配的基础。

## 视觉系统

- 品牌：intelifar，字母 f 不大写。
- 主色：`#6557FF`；深色：`#171827`；辅色：`#18A889`、`#F2B84B`；正文深灰：`#202234`。
- DOCX：`narrative_proposal` 预设，`editorial_cover` 首页结构；中文字体使用微软雅黑，英文使用 Arial。
- PPTX：16:9，深色封面和收尾、浅色内容页；以真实产品截图为主要视觉证据，只保留一张简洁技术架构图。

## 内容边界

- 产品已验证能力与建议部署路径分开表达。
- “建议”“候选”“待复核”不得写成已确认事实。
- 任务助手不是 coding agent，不执行系统命令，不自动发布或修改正式知识。
- 当前小微版能力与大型企业需要适配的统一身份、集中审计、外部恶意文件扫描、异地备份和高可用责任分开说明。

## 验收标准

- DOCX 和 PPTX 均可独立理解，并有明确下一步行动。
- 真实截图可辨认，无拉伸、模糊或过度裁切。
- 文档逐页渲染检查；PPT 每页渲染并检查溢出与重叠。
- 不出现虚构数据、客户名称、收入或投资承诺。
