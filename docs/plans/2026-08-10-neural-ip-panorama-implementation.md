# 可缩放 IP 神经网络全景实施计划

## Step 1：建立相机数学契约

- Output：`asset-graph.mjs` 导出缩放限制、锚点缩放、平移和语义层级纯函数。
- Test：单元测试覆盖上下限、缩放锚点不漂移、平移和三级标签阈值。

## Step 2：升级 SVG 视觉结构

- Output：深色空间背景、关系辉光层、圆形神经节点、缩放层级标签和画布状态浮层。
- Test：契约测试确认节点仍保持可访问角色、关系状态类和既有检查器接口。

## Step 3：接入相机交互

- Output：滚轮锚点缩放、空白拖拽、双指缩放、按钮缩放、适配全景和相机状态播报。
- Test：浏览器 E2E 实际触发按钮、滚轮和拖拽，断言相机变换与缩放层级变化。

## Step 4：响应式与说明

- Output：移除移动端固定宽度补偿，增加触控提示、减弱动画规则和中文手册说明。
- Test：390px 视口无页面级横向溢出，节点与关系仍可操作。

## Step 5：全量验收与截图

- Output：桌面全景、近景节点、移动端和最终结构截图，更新验收报告。
- Test：运行 `npm test`、`npm run build`、`npm run test:e2e`、`npm run test:e2e:modules` 和凭据扫描，并人工查看最终截图。
