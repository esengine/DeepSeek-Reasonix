# 会话级 Agent 预设

Studio 的「Agent 预设」把人设、工具、技能、MCP、扩展、Hook 和自定义命令
组合在一起。模型、推理强度与均衡/交付档位继续独立设置。
运行时复用 Reasonix，不加载 Harness 的 Cordis 插件。

## 选择和修改

首次提交前，在输入框顶部左侧打开 Agent 模式菜单；列表显示来源
和能力说明，分隔线下的「管理 Agent 预设…」打开管理页。接纳首条消息后，会话保留原绑定；
排队、待回答和后台工作期间也不能切换。锁定后可用其他组合新建会话。
清空或回退已开始的组合会话不会解除锁定。

入口只显示模式名与箭头，来源和锁定信息保留在菜单和无障碍说明中；运行状态、
耗时与 token 信息位于右侧，窄屏时换行。

管理页上方只展示两张内置模式卡片，下方单独管理自定义预设：

| 模式 | 行为 |
| --- | --- |
| 标准模式（`builtin:general`） | 创建会话时继承当前配置，处理日常代码、文件与资料任务；保留原稳定标识以兼容默认选择。 |
| 精简模式（`builtin:minimal`） | 使用简短人设、终端（`bash`）和图片读取（`view_image`），保留原生上下文压缩，需要支持读图的模型。 |

精简模式不装载自定义技能、命令、MCP、扩展、Hook 或子 Agent，保留回答和提问
所需的宿主控制工具。终端仍能修改文件和访问网络，继续遵守已有权限与沙箱；
精简模式不是只读模式。图片能力不可用或所选工具被禁用时会明确报告依赖错误。

代码审查、资料研究不再作为内置目录项提供；已有会话继续保留原绑定版本。
如果旧默认指向已移除的内置项，目录会提示用户明确选择新的默认项，不自动替换。

内置项只读，复制后才能修改。每类模块支持「绑定时继承当前配置」或
「仅使用所选项」；显式空列表表示禁用。编辑器提供本机模块目录，导入先预览
缺失依赖，不会安装依赖或启动程序。

保存产生新的定义版本，已存在的会话继续使用原先解析的人设、参数和资源。
页面分别显示定义版本和当前会话绑定版本。并发保存冲突时保留草稿并提示重载。

## 存储与兼容

| 内容 | 位置 |
| --- | --- |
| 用户声明 | `<用户状态根>/agent-presets/definitions/<id>.json` |
| 项目共享声明 | `<工作区>/.reasonix/agent-presets/definitions/<id>.json` |
| 定义版本和显式默认选择 | `<用户状态根>/agent-presets/` |
| 本机授权记录和保留文件 | `<用户状态根>/trusted/agent-presets/` |

状态根遵守存储迁移设置。身份使用 `builtin:`、`user:`、`project:` 前缀；项目
绑定同时记录工作区。同名项按身份和来源并列显示。项目文件不能设置默认值，
项目默认组合必须由用户主动选择，并保存在个人状态中。

声明使用 `schemaVersion: 1`，保存采用原子替换和预期版本校验。

导出不包含凭据值或扩展二进制。MCP 参数包括 `args`、`url`、`env`、`headers`、
`callTimeoutSeconds`、`startupTimeoutSeconds`；扩展参数包括 `args`、`env` 和
`timeoutMillis`。

参数名会校验；env/headers 覆盖值只允许 `${NAME}` 引用。
预设不能替换已安装扩展的可执行入口。

继承项只在绑定时解析一次。技能、Hook 和扩展代码使用保留副本，后续源文件
修改不会改写旧版本。凭据继续由原有凭据或配置机制提供。MCP 连接与进程状态
按会话隔离，扩展使用独立运行副本。原有信任、撤销、授权和沙箱规则继续生效。

Hook 保留直接引用的文件，并为常见脚本格式保留同目录依赖。脚本目录受资源
大小限制，不能包含凭据文件或符号链接；建议将代码放在独立目录，凭据使用
环境引用。外部解释器和服务继续遵守原有平台及授权契约。

绑定只进入本地会话元数据，不发送给 provider。组合会话使用原生事件日志
schema 4，旧程序会明确拒绝。无绑定历史仍走兼容路径，不套用当前默认组合。
无法授权或装配原绑定时，可以只读查看历史，不能继续执行。删除声明不会
删除已有会话所需的绑定版本。

原生导出使用 `reasonix-native-session` version 2 封装，包含权威日志中的绑定
和保留资源，可在「设置 → 存储」导入。导入不创建本机授权，不启动程序。
配置备份 version 3 同时包含个人预设声明及个人默认选择。

MCP 在绑定时锁定工具契约。刷新或重连后若工具目录不兼容，会阻止继续执行，
不会静默替换 schema。扩展及包内 MCP 采用私有运行副本，关闭和装配失败时
释放对应临时目录。Hook 命令中的凭据必须改用环境引用。

非空旧用户人设会幂等迁移为个人默认组合，保留四个字段且不删除旧配置。
`/persona` 适配个人默认组合，不再维护另一份可独立修改的权威人设。
迁移中断后会复用已写入版本，遇到已有个人身份时保留原声明。

## 各入口

CLI 使用 `--agent-composition builtin:minimal` 或 `--agent-composition user:my-agent`。
交互会话的 `/agent` 列出目录，`/agent user:my-agent` 在首次提交前选择组合。
`/preset` 仍表示均衡/交付档位。ACP 增加独立的 `agent_composition` 选项，开始
对话后只保留当前选择。远程会话使用远端目录、凭据和资源。

HTTP 路由、请求字段与稳定错误代码见 [接口说明](AGENT_COMPOSITIONS.md#entry-points)。
`/status` 和会话运行时列表返回 `agentComposition`。导入返回定义与依赖诊断，
需要用户检查后另行保存。错误代码在 Studio 中提供中英文翻译。

预设名称、版本和诊断不进入缓存前缀。切换到另一套组合首次使用时可能产生
冷缓存；编辑预设不会重写正在运行的会话前缀。
