## 提交记录

### `412e87a`：增加安全的源码跟踪引用拉取

- 问题：原有 `source-update --check` 只能发现上游 `main-v2` 前进，不能在本地安全更新跟踪引用；直接自动合并或构建会把未审查源码带入散装版。
- 方案：新增显式 `source-update --fetch`，只接受官方 origin、只在工作树干净时执行、只更新 `refs/remotes/origin/main-v2`。
- 逻辑：先核验源码根目录、当前分支、当前 HEAD、origin 身份和 `git status --porcelain --untracked-files=all`；通过后执行限定 refspec 的 `git fetch --no-tags`。不执行 checkout、reset、merge、rebase，不替换桌面端或 CLI 产物；本地贡献提交继续保留，后续整合与构建另行审查。
- 结果：增加干净工作树、脏工作树、异常 origin 和 CLI JSON 契约回归；网络可用时能更新本地跟踪引用，当前代理不可用时返回 `check-failed`，不误报为“无更新”。
