# 桌面输入区控件

[English](COMPOSER_CONTROLS.md)

通过 **+** 菜单添加内容，或启用计划、目标、交付模式。默认采用常规执行
和标准交付。已启用的模式显示为可移除标签；移除交付标签会恢复标准，
不会改变计划或目标模式。权限仍由独立的询问／自动／Yolo 菜单控制。
模型和思维力度分别选择；模型不支持时隐藏思维力度入口。
底部信息栏不再重复显示模型名称，本轮费用保留两位小数，费用详情仍保留
原有精度。

圆环打开用量详情。**本轮耗时**扣除等待审批和用户回答的时间，并在控制器
记录的完成时间停止；重试时间仍计入本轮。等待、重试和结束后保留本轮
token 与吞吐指标，流式传输中的 token 为估算值。**会话耗时**单独展示
会话累计值。新一轮开始时重置本轮指标；这些实时指标不是持久化历史报告。
每个回合的完成指标只结算一次，后续后台作业状态更新不会覆盖它们。

输入区默认高度为 140px，并保留手动调整的高度。运行时使用适配主题的
边框动画，减少动态效果设置下显示静态边框。审批、回答和重试提示仍然可见。

底部信息栏将工作区和分支合并为一项：显示当前分支名，悬停提示同时展示
工作区路径和分支。非 Git 工作区显示工作区名称，旧配置列表自动去重。
旧配置如果只显示模型，迁移后仅保留工作区与分支。
首次升级默认使用图标版，后续手动选择的文字版或图标版会保留。旧版本
重写配置可能移除升级标记，再次升级时会重新应用图标版默认值。
