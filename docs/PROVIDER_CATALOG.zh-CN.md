# 服务商目录

桌面预设目录按品牌显示一个入口。依次选择接入方式、账号平台和 API 格式来确定一个
具体预设，仅展示后端登记过的组合。OpenCode Go 和 Zen 保留为不同接入方式，
模型专用路由在对应接入方式内选择。

添加时继续使用原有预设 ID、密钥引用、模型参数和安装冲突检查。浏览目录不修改
已安装连接；自定义地址、连接名称和历史会话引用保持不变。添加后可编辑地址和
模型，也可通过“自定义供应商”创建使用独立名称与密钥的另一条连接。

API 格式明确显示 Anthropic Messages、Chat Completions 和 Responses。
用户主动切换格式时，已知预设地址跟随对应的已登记路由；自定义连接的标准请求
后缀可以联动更新，自定义路径和含查询参数的精确 URL 保持不变。切换协议可能
改变请求序列化与服务端缓存复用。

## 新增服务商

OpenAI（Responses 和 Chat Completions）、Anthropic、Google Gemini（OpenAI
兼容入口）、SiliconFlow、OpenRouter、Groq、Mistral AI、Yolo-Auto、
本地 Ollama、LM Studio。
示例模型名可编辑，不代表账号一定有权限或本地已安装；添加后请获取或填写实际模型。
Anthropic 预设不启用服务端原生工具。此次目录扩展不包含 Gemini 原生协议、仅支持
OAuth 的服务、Azure 部署配置等专用接入流程。

## 来源与维护

配置根据服务商官方资料独立维护，没有复制 Cherry Studio 实现。官方资料链接
见 [英文版来源清单](PROVIDER_CATALOG.md#sources)。

品牌图标来自 MIT 许可的 LobeHub Icons，固定版本与完整许可位于
`desktop/frontend/public/provider-icons/`。缺少图标的品牌使用名称首字，运行时
无需访问第三方图标服务。

`internal/config/provider_catalog.go` 维护品牌、平台和套餐元数据，协议与默认
地址从预设真实配置读取。修改后在仓库根目录执行：

```sh
go run scripts/generate-provider-catalog.go
```

| 契约 | 兼容行为 |
| --- | --- |
| 已保存 TOML 与密钥 | 浏览不写入；下述 MiMo 一次性模型升级保留密钥引用与已有选择 |
| 原有预设 ID | 保留 |
| 桌面 `ProviderPresetView.catalog` | 新增展示字段，旧客户端忽略 |
| 新前端连接旧后端 | 已知 ID 使用生成的目录回退，未知预设仍可独立访问 |
| 模型请求前缀 | 不加入目录元数据 |

## MiMo 按量 API 与 Token Plan

先选择**按量 API**或 **Token Plan**。按量 API 使用 `MIMO_API_KEY`，不显示地区选项；
Token Plan 使用 `MIMO_TOKEN_PLAN_API_KEY`，再选择中国、新加坡或欧洲服务集群。
切换集群时，若目标预设支持当前协议，则保留协议选择。Token Plan 仅限受支持的
AI 编程工具使用，其密钥和额度与普通 API 相互独立。

新建连接默认使用 `mimo-v2.6-pro`，同时提供 `mimo-v2.6-flash`，保留 V2.5 模型 ID。
配置版本 12 会为符合条件的官方 V2.5 连接一次性追加 V2.6 模型，保留原默认模型、
模型顺序、自定义价格、密钥引用与未知字段。第三方端点和自定义请求 URL 不参与升级。
模型与迁移标记在配置编辑锁内原子写入；用户之后删除模型，重启不会再次补回。

| 字段或格式 | 旧数据行为 | 新版读取 | 上一版（配置版本 11）读取 | 结论 |
| --- | --- | --- | --- | --- |
| `models`、`default`、模型引用 | 保留 V2.5 顺序和默认选择 | 仅一次追加 V2.6，不切换默认模型 | 可读写模型 ID，保持原默认 | 兼容 |
| `config_version = 12` | 旧版本可触发启动迁移 | 防止删除后重复追加 | 保存时保留标记 | 兼容 |
| `prices`、`vision_models`、未知字段 | 保留用户价格与显式视觉选择 | 扩展已知预设视觉列表，补齐 V2.6 价格；迁移保留未知数据 | 可读取原有字段和规范嵌套价格表 | 未增加持久化字段类型 |

官方参考：[Token Plan](https://mimo.mi.com/docs/zh-CN/tokenplan/Token%20Plan/subscription)、
[API 定价](https://mimo.mi.com/docs/zh-CN/price/pay-as-you-go)、
[API 速率限制](https://mimo.mi.com/docs/zh-CN/api/guidance/rate-limit)。

## 连接显示名称

可选字段 `display_name` 仅用于界面；`name` 仍是连接、模型引用与凭据关联的稳定标识。
列表、详情、模型选择器优先显示连接名称，空值回退到原名称。新预设使用预设标题初始化显示名称。
相同显示名称不会合并连接；字段不加入模型请求或提示词，也不修改历史会话。

| 场景 | 行为 |
| --- | --- |
| 旧配置无新字段 | 保留原显示，无需迁移 |
| 当前版本保存、重启 | 保留名称和原模型引用 |
| 旧前端未传 displayName | 当前后端保留已有名称 |
| 显式空字符串 | 清除名称，恢复回退显示 |
| 旧版程序读写新配置 | 连接仍可读；旧写入器可能丢失显示名称 |

接入详情通过标题旁的编辑按钮重命名；Enter 保存、Esc 取消，失焦不提交。
独立重命名接口仅更新显示名称，配置编辑器不提交该字段，避免旧草稿覆盖新名称。

内置连接与自定义连接共用详情编辑器：内置配置仅提供初始参数，协议、地址、密钥与模型均可后续修改。
详情不再用“内置／自定义”区分页面结构；服务能力仍由实际端点及模型元数据决定。

模型编辑采用单一勾选列表，手动添加通过模型弹窗输入单个 ID。获取模型补充候选项，不改变已有勾选或自动保存；上下文覆盖收在每个模型的设置中。
刷新模型仅验证模型发现接口，不代表推理调用已验证；不再提供重复的独立检查按钮。密钥独立保存，检查和获取模型不会自动保存密钥，也不会因更换密钥而自动启用模型。

密钥默认显示配置状态；点击“更换”展开输入，“⋯”提供来源、共享说明与清除操作。刷新和添加模型集中在模型标题旁。

### 紧凑连接编辑器

连接配置使用对齐表单；模型选择、刷新和添加集中在同一区域。添加和编辑共用模型弹窗，可设置上下文窗口、最大输出 token 与图片输入能力，并恢复继承或自动识别。文本输入和输出固定勾选；视频和 PDF 在请求链路支持前置灰。应用弹窗只修改配置草稿，保存连接后持久化。连接标题与保存栏固定占位，目录与配置内容独立滚动，模型列表不再嵌套滚动。底部保存栏区分未修改、未保存和保存失败；失败不会清空草稿。密钥继续单独保存，不随模型草稿提交。

本地隔离预览：启动前端后打开 `/dev/provider-layout-preview.html`。预览使用真实组件和内存数据，不操作实际连接或凭据。视觉检查见仓库根目录 `design-qa.md`。
