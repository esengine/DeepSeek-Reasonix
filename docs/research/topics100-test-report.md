## 信息模型更新（2026-08-03）

1. **L2 语义阈值**：当前 `DefaultSemanticThreshold`（0.35）在同批近义命中下主题
   正确率 100%（抽样）——维持，不因"想多命中"调低（防误命中是更高优先）。
2. **并发能力**：retrieve_info 工具无状态 + SaveKnowledge 线程安全（hammer 100 轮
   验证）→ 支持 8+ 并发真实使用，agent 层可并行发检索。
3. **时效话题**：新闻/财经/天气类查询命中缓存后需 `信息截至` 标注（FreshUntil），
   用户要求最新时 ForceRefresh——当前已实现，本次测试 66 WEB 中部分为时效刷新。
4. **护栏边界**：PanicMode 破壁引导在 10 条敏感话题上零误伤（未把正常提问当恐慌），
   PanicScore 词表保守性验证通过。
5. **成本**：34% 缓存命中 + 0 失败 = 一次 100 话题测试的边际成本约 66 次 web_search；
   同批话题第二次跑预期 90%+ 命中（L1 精确）。
